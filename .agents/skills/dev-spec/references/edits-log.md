# Журнал правок человека в спеках на разработку

Один на все спеки. Ведёт агент при разборе (`/spec-edits`, `SKILL.md` → «Правки человека»);
новая запись сверху. Охват: **общая** — как писать любую спеку, **частная** — факт или смысл этой
спеки. «Причина» — слова человека как есть; «Закономерность» — ключ из `edit-patterns.md`, один и
тот же для правок одного смысла, как бы они ни были сформулированы. Тип «Просьба» — комментарий
человека просит агента доработать спеку, генератор или прототип; в «Выводе» — что сделано.
Счётчики — в `edit-patterns.md`.
