# Каталог эталонов: тайловые иллюстрации ДС

Все 32 тайловые иллюстрации ДС (`design-system/assets/illustrations/<имя>.svg`, 195×140) — утверждённая
основа: по ним сняты числовые пороги автопроверки (`check-thresholds.json`, метрики каждого эталона —
в его поле `refs`, пересборка — `illustration-gen.mjs --calibrate`) и из них взяты мотивы каталога
(`illustration-gen.mjs --motifs`). Эталоны только читаются — ни один файл в `design-system/assets/` инструмент не меняет.

Утверждены не значит «все одинаково удачны»: пороги заданы по процентилям, а не по крайним значениям, поэтому
выбросы (сейчас `sales-projects` по центру, `settings` по высоте) пороги не размывают. Колонка «Мотив» — что из
каталога уже рисует такой предмет; «—» — мотива нет, кандидат в каталог.

## Что из этого следует для композиции

| Наблюдение | Как учтено |
|---|---|
| У 24 из 32 один главный предмет, у 5–6 — главный и один-два спутника, остальные — плоские знаки | Раскладки `solo`, `pair`, `trio`, `diagonal`; россыпь мелких предметов в эталонах не встречается |
| Предметы заполняют кадр: ширина 100–190, высота 93–140, закрашено 28–53 % | Пороги `check-thresholds.json`; сцена из описания не раздувается сверх 42 % (`renderBalanced`) |
| Площадок и плит почти нет, объект стоит сам | Основание `none` по умолчанию; плита, диск, радарный диск — только по описанию |
| Центр рисунка у большинства около (87–100, 69–79) | Центровка в `render()`, проверка центра в автопроверке |

## Кандидаты в каталог мотивов

Повторяются в эталонах и ещё не нарисованы: папка (6 эталонов), калькулятор, весы, календарь, лупа, ручка,
ноутбук, портфель, пазл, лист с графиком, галочка и круг-знак. Добавлять по запросу человека, по образцу
мотивов в `tooling/motifs.mjs`.
