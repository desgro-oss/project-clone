## 3. Сценарии (Scenarios)

Участие страницы в бизнес-сценариях: строка на сценарий, сценариев — от
одного до нескольких. Роль — одна или несколько сразу: точка входа / звено
цепочки / завершение. Имена сценариев не выдумываются: известные из ТЗ и
бизнес-контекста пишутся, неизвестное — `не решено (ДД.ММ.ГГГГ)` и строка в
«Открытых вопросах». Страница вне сценариев — «Не применимо: …».

| Сценарий | Роль страницы | Переходы (откуда → куда) |

## 10. Состояния (States)

### Loading
Тело таблицы — строки-скелетоны (`.tc--skeleton`), тулбар и футер на месте;
сводка — Tile со скелетоном ReadOnlyField.

### Empty
`.dtable__empty`: «Ничего не найдено» + «Сбросить фильтр».

### Error
Alert тона `error` над таблицей, текст — раздел 11.

### Disabled
Нет прав на редактирование: кнопки действий скрыты, таблица только на чтение.

Свои состояния экрана — отдельными подразделами того же вида.

## 12. Данные (Data dependencies)

### API — что нужно от бэкенда

Имена полей — те же, что в typedef демо-данных (подраздел Mock): из DTO, когда
он известен, иначе придуманы в стиле API и помечены `invented`.

| Поле | Тип | Обязательное | Смысл и источник |
|---|---|---|---|
| `dealId` | число | да | номер сделки |
| `counterpartyName` | строка | да | наименование контрагента |
| `amount` | число | да | сумма, 2 знака |
| `currencyCode` | строка | да | код валюты ISO 4217, `RUB` |
| `statusCode` | перечисление | да | значения — паспорт `CurrentPortfolioDidTable` |

Имена методов и хуков API здесь не придумываются: их выбирает разработка.

### Mock — демо-данные прототипа

| Файл | Глобальная переменная | Тип | Источник имён |
|---|---|---|---|
| `../data/deals.js` | `window.MOCK_DEALS` | `DealRsDto[]` | invented — заменить, когда придёт DTO |
| `../data/deals-store.js` | `window.DealsStore` | — | помощник: выборка, фильтр, тоны статусов |

### Permissions — роли, права, флаги

| Роль | Просмотр | Действия |
|---|---|---|
| Менеджер сделок | все сделки подразделения | создание, редактирование своих |
| Риск-менеджер | все сделки подразделения | только просмотр |

## 14. Доступность (Accessibility)

- `<main>` для контентной области, `<nav aria-label="Хлебные крошки">`,
  `<nav aria-label="Главное меню">`;
- заголовок страницы — единственный `h1`;
- сортировка колонки объявлена через `aria-sort`;
- у всех кнопок-иконок есть `aria-label`;
- порядок в DOM совпадает с порядком чтения;
- контраст — не ниже WCAG AA (обеспечивается токенами ДС).
