# Page: HomeBoard — Главная

## 1. Назначение (Purpose)

Рабочее пространство Аналитика ДИД: вкладки «Мой дашборд» / «Мои проекты». Дашборд объединяет профиль сотрудника, встречи, задачи и новости; проекты доступны доской и таблицей.

## 2. Адрес и навигация (Route)

[ПРЕДЛОЖЕНИЕ] В режиме «Стало» все группы меню сворачиваются кликом по тексту заголовка, без дополнительных иконок. Заголовок — нативная кнопка с типографикой и цветом текста раздела (`--text-inactive`), `aria-expanded`, `aria-controls`, подписью «Свернуть / Развернуть раздел» и управлением Enter / Space. Скрываются все пункты и вложенные подразделы группы, включая иконки в rail; заголовок остаётся в развёрнутой панели. По умолчанию всё раскрыто, выбор хранится в sessionStorage только концепта (`ibp-redesign-v2-nav-groups`) и переживает переходы и пересборку меню. Режим «Было» сохраняет исходное поведение. Общие локальные стили — `pages/NavSections.css`, подключает `data/nav-links.js`; файлы ДС не меняются.

## 3. Раскладка (Layout)

Layout screen--app без крошек → профиль → Tab M «Мой дашборд / Мои проекты» → выбранная панель (решение пользователя 20.10.2026: крошек на главной нет, вкладки — после карточки пользователя). Профиль с фотографией, ФИО, должностью и десками сотрудника (несколько, readonly-чипы Chip S: «Недвижимость», «Строительство»), контактами и тремя действиями с иконками — «Новая встреча» и «Новая задача» (outline), «Новый проект» (единственная accent, открывает ту же форму, что и «Новый проект» вкладки проектов) — общий для обеих вкладок и не прокручивается; прокручивается содержимое панели. Отступы: сверху 24px — как поля слева и справа; профиль → вкладки → панель — по 12px; между карточками дашборда по вертикали и горизонтали — 16px; нижнего поля экрана нет — прокручиваемая панель дашборда доходит до края экрана, последний ряд отделён 24px внутри прокрутки. По умолчанию открыт дашборд; параметр `home=projects` открывает проекты. Выбор меняет URL без перезагрузки; фильтр и вид проектов при переключении сохраняются. Стрелки, Home/End и roving tabindex обслуживает Tab ДС.

Дашборд: профиль → крупные показатели из исходных демо-данных → встречи, задачи и новости в трёх равных колонках 4/4/4 (ниже 1200px все три карточки полной ширины). В профиле должность «Управляющий директор» и табельный номер 21492411. Нижние переходы «Все встречи...», «Все задачи...», «Все новости...» — единый стиль без счётчиков и иконок; в шапках карточек стрелки. Отдельного заголовка «Мой дашборд» и подзаголовка нет по решению пользователя; заголовок «Мои проекты» сохранён. У встреч SegmentControl «Мои встречи / Встречи моего деска» меняет список и локальные счётчики; верхние KPI остаются личными. Дизайн и локальная адаптивность описаны в `HomeDashboard.md`. Контент вместе с профилем прокручивается внутри панели `.ds-scroll`, табы закреплены сверху. На низком окне вся главная прокручивается вертикально.

Проекты: без PageHeader — раздел называет вкладка, «+ Новый проект» стоит в профиле над вкладками (решение пользователя 20.10.2026) → управление доской (фильтр, Доска / Таблица, IconButton M `settings`) → Kanban B2 / Table. Сводка, строка плана квартала и подборка недели закомментированы по прежнему решению пользователя и места не занимают.

Доска — flex:1,min-height:0; прокрутка принадлежит viewport, у колонок её нет. По просьбе пользователя viewport доходит до правой и нижней кромки экрана: отрицательные margin-right / margin-bottom компенсируют только соответствующие токены Layout; поля шапки сохранены. Трек занимает 100% доступной ширины. Открытые колонки делят её поровну через flex:1 1 var(--kb-col-w), свёрнутые сохраняют штатные 48 px. Раскрытие Pipeline или отказа сужает остальные открытые колонки, свёртка расширяет их. Это локальное изменение фиксированной геометрии Kanban ДС по прямому решению пользователя; высота и растяжение по вертикали остаются штатными. Для O открытых и C свёрнутых колонок ширина открытой — (ширина трека − C × 48) / O.

Под каждой колонкой — sticky-итог объёма в млн RUB: паттерн `.pm-colsum` из `apps/pretrade/drafts/pipelineManager-v02/pages/PipelineManagement.html`, локально `.lead-colsum`. Цвета, типографика, отступы — токены ДС. В свёрнутой колонке итог скрыт. Суммируются только отображаемые по фильтру лиды; неизвестные объёмы не оцениваются, их количество показано отдельно.

| Шестерёнка рядом с «Доска / Таблица» в режиме «Таблица» | Настройка видимости колонок штатным TableSettings; сохранение настроек таблицы. Собственной шапки «Лиды» со счётчиком и шестерёнкой у таблицы нет — решение пользователя 20.10.2026 |

| Передать | Проверка документов и полей; одна сделка в локальном Pipeline; повторное действие не создаёт дубль |

## 8. Состояния (States)

### Загрузка (Loading)
Нет асинхронного запроса: локальные скрипты загружаются последовательно.
### Данных нет (Empty)
EmptyState: в колонке нет лидов, лиды по фильтру не найдены.
### Ошибка (Error)
Неизвестный ID — EmptyState; ошибка формы — пояснение, запрещённый переход — SnackBar.
### Недоступно (Disabled)
Переход / передача disabled при невыполненных критериях; финалы — только возврат или открыть сделку.

## 13. Открытые вопросы и допущения (Open questions)

По просьбе пользователя дашборд допускает локальные компоненты и художественные отклонения от ДС; цвета, типографика и базовые интервалы остаются на токенах ДС. Источники — dashboard-app и визуальные референсы пользователя от 20.10.2026. Сводка проектов, план и B1 сохранены в комментариях; их возврат требует нового решения о дизайне.

Группировка по деску использует только деск ответственного — решение пользователя. В демо явно известен деск сотрудника 04127 (`D-SMB-NR6`, ТЗ MS0014 §3); для остальных сотрудников связь не задана и показывается «Без деска». Дески источника не подменяют деск сотрудника.

B1–B4 одобрены для прототипа. КФЮЛ и потенциалы РД отсутствуют в адаптере до решения вопроса 10; ссылки не выдуманы. Механизм ранжирования — демонстрационный отбор по плану и зоне ответственности, без бизнес-скоринга. Документы отмечаются флагами, загрузок нет. Возврат из Pipeline сохраняет связь с созданной сделкой. Автодвижение по внешним событиям выключено. Объединение дублей и новый Проект не входят в выбранный первый вариант. Приёмка: статический сенсор и JS-DOM со всеми рантаймами ДС. Фактический overflow, CSS и геометрия требуют ручного браузерного просмотра. Исторические архивы сделок источников сохраняются в режиме Было; Архив единого реестра содержит решения нового процесса. Группы продуктов и их объёмы берутся из источника; неизвестное распределение не выдумывается.
