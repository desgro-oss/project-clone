# Концепт: NewsPage — Новости

## Назначение

Новости о клиентах аналитика за последние 3 месяца: лента слева, полный текст выбранной новости справа. Страница открывается с главной (`HomeBoard`), крошки — «Главная / Новости». Пункт меню — «Главная».

## Блоки и компоненты ДС

| Блок | Состав |
|---|---|
| Крошки | Breadcrumbs: «Главная» → `HomeBoard.preview.html?mode=after`, текущая — «Новости» |
| Шапка | PageHeader: «Новости», подзаголовок «Отображаются до 100 новостей за 3 месяца» |
| Вкладки | Tab M: «Мои клиенты» (`?scope=my`) · «Клиенты моего деска» (`desk`) · «Избранные клиенты» (`fav`) |
| Рабочая область | Splitter ДС: слева V2NewsListTile (34%, 25–60%), справа V2NewsArticleTile; уже 900px рабочей области — панели друг под другом (лента 40% высоты), сплиттер скрыт |

## Поведение и состояния

| Триггер | Результат |
|---|---|
| Открытие | Вкладка из `?scope=` (по умолчанию «Мои клиенты»), выбранная новость — `?id=`, если она есть во вкладке, иначе первая |
| Вкладка | Лента — новости вкладки (не больше 100); выбранная остаётся, если есть и в новой вкладке, иначе первая. Наборы — как у карточки «Новости клиентов» главной: мои — `isMyClient`, деск — все, избранные — `isFavorite` |
| Клик по строке ленты | Новость выбрана (`aria-current="true"`), справа её текст; вкладка и новость пишутся в адрес без перезагрузки (`replaceState`) — ссылку можно отдать |
| «Смотреть источник» | Button Outline S с `link-external`: адрес источника в новой вкладке. В демо — главная страница домена, не сама статья (решение пользователя 27.10.2026) |
| Пустая вкладка | EmptyState в ленте «Новостей нет» и справа «Новость не выбрана» |
| Loading / Error | Асинхронного запроса нет — данные в `data/news.js`; не моделируются |

Переходы с главной (решение пользователя 27.10.2026): «Все новости...» и стрелка в шапке карточки «Новости» — на вкладку текущей области карточки; клик по новости карточки — на эту новость; карточка-счётчик «Новости моих клиентов» — на «Мои клиенты».

## Допущения

- Данные — `data/news.js` (`MOCK_NEWS`, Source: invented): тот же набор, что на главной; 20 новостей с 14.07 по 08.10.2026, полный текст по абзацам демонстрационный. Срез — 9 октября 2026, как у дашборда.
- Источники в демо — домены `dzen.ru`, `zarya.by` (как в макете), `interfax.ru`, `rbc.ru`; публикации вымышлены.
- Дата — «27 августа 2026»; в макете «27 Августа, 2026» — приведено к русской записи даты (допущение агента).
- Скругление тайлов — штатное Tile ДС (8px); в макете карточки скруглены сильнее.
- Рамка и подложка Splitter сняты: тайлы стоят карточками на фоне страницы, как в макете и на `MeetingsProtocolsPage` (решение пользователя 20.10.2026).
- Уже 900px рабочей области панели встают друг под другом; ширину панели «a» Splitter ДС пишет инлайном (`flex: 0 0 N%`), поэтому раскладка экрана перебивает её `!important` (допущение агента 27.10.2026).

## Открытые вопросы

- Кто входит в «Клиентов моего деска»: в прототипе, как и на главной, — все новости набора; правило отбора по деску — не решено (27.10.2026).
- Порядок и лимит: «до 100 новостей за 3 месяца» — что показывать, если новостей больше 100 (сначала новые?) — не решено (27.10.2026).
