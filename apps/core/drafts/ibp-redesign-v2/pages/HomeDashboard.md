# Дашборд и профиль сотрудника (HomeDashboard)

## Назначение (Purpose)

Главная рабочего пространства сотрудника: оценить нагрузку, увидеть ближайшие встречи, срочные задачи и события клиентов. Табы находятся вверху, профиль расположен внутри дашборда; на вкладке «Мои проекты» профиля нет.

## Подключение (Implementation mapping)

| Артефакт | Подключение |
|---|---|
| Стиль | `pages/HomeDashboard.css`, после ДС |
| Скрипт и локальные данные | `data/home-dashboard.js`, после рантаймов ДС |
| API | `window.IBPHomeDashboard.mount({ profileHost, dashboardHost })` |
| Профиль | `profileHost` — отдельный контейнер, например `#home-profile`; имя — `h2` |
| Дашборд | `dashboardHost` — содержимое панели вкладки; отдельные заголовок и подзаголовок отсутствуют по просьбе пользователя |
| Формы | При первом `mount` добавляются в `body`, вне скрываемых панелей |
| Фото | `refs/home-profile-anna-kim.jpg`, извлечено из исходного `mock-profile.js` |

| Блок | Состав | Ширина при ≥1600 / 1200–1599 / 900–1199 / <900 |

Диаграмма встреч считает реальные записи на семь дней с 09.10.2026. Составная полоса задач показывает количество «В работе / Выполнено / Остальные» из 14 моих задач; числовая расшифровка находится в доступном названии визуализации. Исторические тренды и неподтверждённые проценты не добавлены.

## Поведение и состояния (Behavior / States)

| Триггер | Результат |
|---|---|
| «Скопировать телефон» | `DSCopy.write` использует Clipboard API и запасной `execCommand` исходной ДС; подтверждение — подсказка и SnackBar. Если API среды не позволяет копирование, SnackBar выводит телефон для ручного копирования |
| Почта | `mailto:` с исходным контактом |
| «Открыть профиль» | Modal «Личный кабинет» с ФИО, табельным номером 21492411, должностью «Управляющий директор», десками, телефоном и почтой в ReadOnlyField |
| «Новая встреча» | Форма клиента, темы, даты, начала, окончания. Обязательные поля проверяются браузером; окончание должно быть позже начала |
| «Создать встречу» | Запись добавляется в память дашборда, список и показатели пересчитываются; окно закрывается, появляется сообщение |
| Переключение области встреч | «Мои встречи» — `isMine`; «Встречи моего деска» — весь набор встреч исходного демо-деска. Отменённые и прошедшие встречи исключены; локальные счётчики обновляются, верхний KPI остаётся личным. Выбор сохраняется при смене вкладки и создании записи |
| «Новая задача» | Форма задачи, срока, приоритета, необязательных клиента и сделки |
| «Создать задачу» | Запись со статусом «Ожидает исполнения» добавляется в память; включается область «Мои задачи»; список и показатели пересчитываются |
| Переключение области задач | Меняется набор и счётчики списка, включая исполнителя в области деска. KPI остаются личными, как указано в их подписях |
| Переключение новостей | «Мои» — `isMyClient`; «Деск» — все; «Избранные» — `isFavorite`; список раскрытия сбрасывается |
| «Все новости...» / стрелка в шапке новостей | Показывает все записи текущей области; «Свернуть новости...» или повторный клик стрелки возвращает три. Кнопки сообщают состояние через aria-expanded |
| Нижние переходы карточек | Единый стиль hd-text-link, подписи «Все встречи...», «Все задачи...», «Все новости...» без счётчиков и иконок |
| Строки встреч/задач, стрелки, ссылки «Все…» | Соответствующий существующий реестр концепта: `MeetingsProtocolsPage.preview.html` или `TasksPage.preview.html` |
| Loading / Error | Асинхронного запроса нет; данные включены в скрипт, отдельные состояния не моделируются |
| Empty | Исходные детерминированные выборки непустые; внешняя замена данных API не предусмотрена |
| Disabled | Формы используют нативную проверку обязательных значений; слой, Esc, focus trap и закрытие принадлежат `DSModal` |

## Источники данных и допущения (Data dependencies / Assumptions)

- Имена полей и содержимое перенесены из `dashboard-app/data/mock-profile.js`, `mock-meetings.js`, `mock-tasks.js`, `mock-news.js`. Источник вымышленный, отмечен `Source: invented` в JSDoc; контракт API отсутствует.
- Сегодня — **9 октября 2026**, как в исходном дашборде. Подпись «Демо · 9 октября 2026» явно обозначает срез; числа не притворяются актуальными на системную дату.
- Фотография — точная локальная копия исходного портрета. При ошибке загрузки — инициалы «АК».
- Пользователь разрешил авторскую композицию вместо буквального использования тайлов ДС. Приняты крупные KPI, три равные колонки 4/4/4 для встреч, задач и новостей, сиреневые и мятные градиенты, собственные списки и минидиаграммы; значения стилей опираются на токены ДС. Ниже 1200px все три карточки занимают полную ширину. Состояния штатных компонентов не переопределяются.
- Должность и табельный номер профиля изменены по явному запросу пользователя от 20.10.2026; внутренний employeeId сохранён отдельно от employeeNumber.
- Новые записи живут до перезагрузки и не синхронизируются с отдельными реестрами: их схемы и идентификаторы отличаются. В форме это ограничение указано до сохранения.
- У исходных новостей `url: '#'`; фиктивные внешние ссылки не показываются. Отображается весь доступный текст новости.
- Исходные M-0101/T-1001 отсутствуют в реестрах концепта. Строки открывают существующую страницу реестра без ложного параметра `id`.

## Открытые вопросы (Open questions)

Финальный маршрут карточек встреч/задач и единая схема данных главной и реестров определяются при переносе в продукт. Серверного сохранения и реальной публикации новостей у концепта нет.
