## Описание (Purpose)

Левая панель страницы «Новости»: строка на новость — дата · домен источника, заголовок, анонс в две строки, клиент. Выбранная строка подсвечена.

## Бизнес-смысл (Business context)

| Вопрос | Ответ |
|---|---|
| Зачем существует | Быстро просмотреть, что пишут о клиентах, перед разговором с ними — не решено (27.10.2026), со слов человека: переход «Все новости» с главной |
| Кто заполняет и когда | не решено (27.10.2026) — источник новостей в продукте не определён |
| Кто пользуется результатом | Аналитик ДИД |
| Бизнес-правила | до 100 новостей за 3 месяца (подзаголовок макета) |

Источники: макет Pixso «Новости» (item 2605:122131), решение пользователя 27.10.2026

## Раскладка (Layout)

```
Tile headless (высота панели, тело прокручивается .ds-scroll)
└── строки-кнопки: дата · источник / заголовок / анонс (2 строки) / клиент
```

## Компоненты (Components)

Tile `--headless`; EmptyState M (`empty-folder`) для пустой вкладки. Строка — своя кнопка на токенах; состояния наведения, фокуса и выбора — токены строки Entity ДС.

## Поля (Fields)

| Поле | Тип | Источник |
|---|---|---|
| Дата | «8 октября 2026» | `publishedAt` |
| Источник | домен, прописными, `--primary` | `sourceDomain` |
| Заголовок | Body M Strong | `title` |
| Анонс | Body M, две строки с многоточием | `summary` |
| Клиент | Body XS, иконка `building-02` | `clientName` |

## Права (Permissions)

Аналитик ДИД — просмотр.

## Состояния (States)

Данные есть — строки; пусто — EmptyState «Новостей нет». Загрузки и ошибки в прототипе нет (данные в скрипте).

## Обязательность заполнения (Required)

—

## Переполнение (Overflow)

Анонс — две строки с многоточием, клиент — одна строка с многоточием; много новостей — прокрутка тела тайла.

## Поведение (Behavior)

Клик, Enter или Space по строке → `onSelect(item)`; страница выделяет строку (`aria-current="true"`) и показывает новость справа.

## Данные (Data dependencies)
