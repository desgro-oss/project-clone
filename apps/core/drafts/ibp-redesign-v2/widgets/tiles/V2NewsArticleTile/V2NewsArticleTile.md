## Описание (Purpose)

Правая панель страницы «Новости»: заголовок новости, дата · домен источника, полный текст по абзацам и кнопка «Смотреть источник».

## Бизнес-смысл (Business context)

| Вопрос | Ответ |
|---|---|
| Зачем существует | Прочитать новость о клиенте целиком и перейти к первоисточнику — не решено (27.10.2026), по макету |
| Кто заполняет и когда | не решено (27.10.2026) |
| Кто пользуется результатом | Аналитик ДИД |
| Бизнес-правила | не решено (27.10.2026) |

Источники: макет Pixso «Новости» (item 2605:122131), решение пользователя 27.10.2026

## Раскладка (Layout)

```
Tile headless (высота панели, тело прокручивается .ds-scroll)
└── заголовок H5 / дата · источник / абзацы (ширина до 72ch) / «Смотреть источник»
```

## Компоненты (Components)

Tile `--headless`; Button Outline S с иконкой `link-external` (ссылка `<a target="_blank">`); EmptyState M «Новость не выбрана».

## Поля (Fields)

| Поле | Тип | Источник |
|---|---|---|
| Заголовок | H5 Strong | `title` |
| Дата | «8 октября 2026» | `publishedAt` |
| Источник | домен, прописными, `--primary` | `sourceDomain` |
| Текст | Body M, абзацы | `body[]` |
| Ссылка | адрес источника | `url` |

## Права (Permissions)

Аналитик ДИД — просмотр.

## Состояния (States)

Новость выбрана — текст; не выбрана (пустая вкладка) — EmptyState. Загрузки и ошибки в прототипе нет.

## Обязательность заполнения (Required)

—

## Переполнение (Overflow)

Длинный текст — прокрутка тела тайла; при выборе другой новости прокрутка возвращается наверх.

## Поведение (Behavior)

«Смотреть источник» открывает `url` в новой вкладке (`rel="noopener noreferrer"`); в демо это главная страница домена, не сама статья (решение пользователя 27.10.2026).
