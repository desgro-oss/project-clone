## Описание (Purpose)

Общий список главной и страницы «События»: строка Entity с иконкой типа, временем и чипом, заголовком, «поле: было → стало» и связанными объектами. Выбранная строка подсвечена штатным состоянием Entity.

## Бизнес-смысл (Business context)

| Вопрос | Ответ |
|---|---|
| Зачем существует | Видеть, что изменилось в моих проектах и у моих клиентов, без захода в каждую карточку (решение пользователя 27.10.2026) |
| Кто заполняет и когда | Система — журнал изменений проектов, сделок, клиентов, задач и встреч; источник в продукте не решён (27.10.2026) |
| Кто пользуется результатом | Аналитик ДИД |
| Бизнес-правила | Клиент проекта при создании проекта автоматически попадает в «Мои клиенты» — это тоже событие (ответ человека 27.10.2026) |

Источники: решение пользователя 27.10.2026

## Раскладка (Layout)

```
Tile headless на странице / без Tile в embedded-варианте главной (тело прокручивается .ds-scroll)
└── entity-list (на странице зазор 16px, поля тела 16/20px; embedded — paint-поля тела по 16px, paint-зазор 8px)
    └── Entity M interactive: иконка / время · тип / заголовок / изменение / объекты
```

## Компоненты (Components)

Tile `--headless` только в standalone; embedded убирает классы Tile с корня и тела. Entity M `--interactive`, `--selected` у выбранной строки; ведущая иконка `--neutral` с глифом типа из `IBPR_EVENTS.type`; Chip S; EmptyState M. Hover и focus — из Entity, внешних переопределений состояний нет.

## Поля (Fields)

| Поле | Тип | Источник |

Данные есть — Entity-строки, выбранное — штатная подложка Entity. Empty — «Событий нет». Loading / Error не моделируются; Disabled — только просмотр событий, выбор доступен.

## Переполнение (Overflow)

Label — одна строка с усечением и штатным Tooltip; Subheaders — клэмп Entity. На странице много событий — прокрутка тела тайла; главная передаёт не больше 10.

## Поведение (Behavior)

Клик, Enter или Space по строке → `onSelect(item)`; вызывающий экран выделяет строку и показывает V2EventDetailsTile справа. Главная сохраняет выбор при смене фильтра, пока событие входит в видимые 10, иначе выбирает первое; страница работает с полной выборкой.

## Данные (Data dependencies)

`data/events.js` → `window.IBPR_EVENTS.all()` (EventRsDto, Source: invented 27.10.2026).

## Для разработчиков (Implementation)

`LcEventsListTile.render(host, { items, selectedId, onSelect, embedded })`. По умолчанию `embedded: false`: самостоятельный Tile страницы. `true`: содержимое общей карточки главной; корневые local-классы и `data-widget` сохраняются.

## Осознанные отклонения (Deviations)

По просьбе пользователя о равных полях строк в embedded-варианте локальный layout-класс задаёт Entity `padding: var(--space-16)` со всех сторон; остальные размеры и состояния остаются в ДС. `width:auto` компенсирует сочетание штатных `width:100%` и margin `-8px -10px`: при ширине списка L paint bounds становятся `[-10, L+10]`, а не `[-10, L−10]`. Поля scroll-body `24px 26px` (токены `16+8`, `16+10`) оставляют по 16px до paint-box на четырёх краях; gap списка 24px оставляет между соседними paint-box 8px (`24−8−8`). На странице сохранены прежние Tile, поля тела и gap; ширина строки также `auto` для симметрии.
