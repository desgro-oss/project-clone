# V2EventsListTile — журнал изменений

Формат записи: что изменилось · почему · по какому требованию. Без «почему» правку через
месяц откатывают обратно. Новая запись — сверху.

Правка вида, поведения или состава — новая версия: `## М.ммм — ДД.ММ.ГГГГ`. Правка только
описания версию не меняет — запись без номера: `## Паспорт — ДД.ММ.ГГГГ`. Приведение к
новым правилам ДС — тоже отдельная запись с новой `rulesVersion`.

## 1.002 — 27.10.2026

Добавлен embedded-вариант без Tile-оболочки для главной; ширина строк компенсирует штатный отрицательный margin Entity. Встроенные строки имеют равные поля 16px и отдельный зазор 8px между подложками. *Почему:* две вложенные рамки и несимметричные поля списка мешали восприятию карточки. *Требование:* скриншот и правка пользователя MS0019a, 27.10.2026. Цвета и состояния Entity ведёт ДС; самостоятельный Tile страницы сохранён.

## 1.001 — 27.10.2026

Строки переведены на Entity M со штатными hover, focus и выбранным состоянием, ведущая иконка обозначает тип; список повторно используется на главной. *Почему:* одинаковое представление выбора и подробностей с EventsPage. *Требование:* четыре правки карточки «События», решение пользователя 27.10.2026 (MS0019).
