## Описание (Purpose)

Общие подробности главной и страницы «События»: тип, что случилось, дата и автор, «Что изменилось» (поле, было, стало) и «Связано с» — ссылки на проект, сделку, клиента. Состав и рендер на обоих экранах едины.

## Бизнес-смысл (Business context)

| Вопрос | Ответ |
|---|---|
| Зачем существует | Видеть, что изменилось в моих проектах и у моих клиентов, без захода в каждую карточку (решение пользователя 27.10.2026) |
| Кто заполняет и когда | Система — журнал изменений проектов, сделок, клиентов, задач и встреч; источник в продукте не решён (27.10.2026) |
| Кто пользуется результатом | Аналитик ДИД |
| Бизнес-правила | Клиент проекта при создании проекта автоматически попадает в «Мои клиенты» — это тоже событие (ответ человека 27.10.2026) |

Источники: решение пользователя 27.10.2026

## Раскладка (Layout)

```
Tile headless на странице / без Tile в embedded-варианте главной (тело прокручивается .ds-scroll)
└── тип / что случилось H5 / дата · автор / Что изменилось: 3 ReadOnlyField / Связано с: ссылки
```

## Компоненты (Components)

Tile `--headless` только в standalone; embedded убирает классы Tile с корня и тела, поля scroll-body — по 16px. Chip S типа; ReadOnlyField «Поле» во всю ширину, под ним «Было | Стало» в две колонки (колонка не уже 240px; у узкого тайла — друг под другом); Link accent M; EmptyState M «Событие не выбрано».

## Поля (Fields)

| Поле | Тип | Источник |
|---|---|---|
| Тип | Chip S | `typeCode` |
| Что случилось | H5 Strong | `title` |
| Дата · автор | Body XS | `occurredAt`, `authorId` («Система» — `SYSTEM`) |
| Поле / Было / Стало | ReadOnlyField; нет значения — прочерк | `field`, `from`, `to` |
| Связано с | вид объекта + ссылка | `entities` → `IBPR_EVENTS.entityHref` |

## Права (Permissions)

Аналитик ДИД — просмотр.

## Состояния (States)

Событие выбрано — подробности; нет поля изменения — блок «Что изменилось» скрыт; не выбрано или выборка пуста — EmptyState. Loading / Error не моделируются; Disabled — только просмотр, ссылки доступны.

## Обязательность заполнения (Required)

## Переполнение (Overflow)

Длинный текст — перенос; при выборе другого события прокрутка возвращается наверх.

## Поведение (Behavior)

Ссылки «Связано с» открывают страницу проекта (`Lead`), сделки (`Opportunity`, источник Pipeline) или клиента (`ClientInfoPage`).

## Данные (Data dependencies)

`data/events.js` → `window.IBPR_EVENTS` (EventRsDto, Source: invented 27.10.2026).

## Для разработчиков (Implementation)

`LcEventDetailsTile.render(host, { item, embedded })`; `item: null` — пустое состояние. По умолчанию `embedded: false`: самостоятельный Tile страницы. `true`: содержимое общей карточки главной; корневые local-классы и `data-widget` сохраняются.
