## 1.003 — 21.10.2026

**Закрепление колонок.** В шапке у колонок тогл `.th__pin` (TablePin ДС), первая колонка закреплена по умолчанию — раньше она была серой (фон Pinned) без иконки и без возможности открепить. *Требование:* решение пользователя 21.10.2026.

## 1.002 — 20.10.2026

**Тулбар над таблицей, без тайла; источник «Лид» — ссылка.** Фильтр и «Краткий отчет» вынесены в зону `.dtable-toolbar` над таблицей; тайл-подложка снята — карточка у Table своя (`.dtable`), двойной рамки больше нет. Встречи, назначенные из лида (`sourceType: UNIFIED_LEAD`), получили подпись «Лид» в «Источнике встречи» и ссылку на страницу лида в «ID источника» — как в предпросмотре V2MeetingsProtocolsDetails; раньше там были «–» и ID обычным текстом. *Почему:* «как в ДС» — вариант Table «тулбар над таблицей»; разнобой ссылок в одной колонке. *Требование:* решение пользователя 20.10.2026.
