# V2MyClientsTable

## Описание (Purpose)

Реестр клиентов по ТЗ MS0014 §4.7 — одна таблица на все места, где виден список клиентов: вкладки раздела «Клиенты» и вкладка главной «Поиск клиентов» (решение пользователя 26.10.2026). Новая колонка добавляется в этот виджет и появляется везде сразу — таблицы не расходятся.

Общие колонки (16): Клиент · Приоритет (чип) · Полное наименование · ИНН · Статус (чип «Активен») · Дата (чип квартала с `calendar`) · Компания роста (чип `trend-up`) · Цели клиента (чип «Цели зафиксированы» с ⓘ) · Отрасль · Макроотрасль · Подотрасль · Сегмент · ТБ · ГОСБ · ГКМ · CRM ID; по наведению — «в избранное». Колонка сопоставляется с полем по ключу (ревью MS0014, Б6).

«Поиск клиентов» шире на атрибуты БТ «Поиск клиентов» от 21.10.2026 (решение пользователя 26.10.2026) — 33 колонки: Холдинг — после «Полного наименования»; Компания роста ДИД, Ключевой клиент, Приоритет A–D, Зона проблемности ([[Зона проблемности|чип по цвету]]) — после «Целей клиента»; ГКМ холдинга, [[Спонсор]] — после «ГКМ»; в конце, млн RUB: Выручка (ФНС), EBITDA ([[ФОК]] SB0140), Долг и Чистый долг (ФОК SB0121), [[ОСЗ]] в Сбере, [[ЧОД]] 2025, ЧОД 2026, Портфель ДИД, Pipeline ДИД. Те же атрибуты — в фильтре поиска.

Фильтр — модалка TableFilter по макету «Modal / Filter / My Clients» (решение пользователя 26.10.2026): разделы «Основная информация» (Клиент, Полное наименование, Холдинг, ИНН, [[ГКМ|Главный клиентский менеджер]], CRM ID, ТБ, ГОСБ), «Команда» (Дески клиента, Команда клиента — множественный выбор с чипами под полем), «Отрасль» (Отрасль, Макроотрасль, Подотрасль, Сегмент). На «Поиске клиентов» добавлены: в «Команде» — ГКМ холдинга, Спонсор; разделы «Признаки клиента» (Приоритет, Приоритет A–D, Зона проблемности, Компания роста, Компания роста ДИД, Ключевой клиент), «Финансы» и «ДИД» (суммы от–до). Бейдж раздела в навигации — число заполненных полей.

Выборки: «Поиск клиентов» — полная база клиентов банка, главная таблица; «Мои клиенты» — те клиенты базы, которых пользователь отметил избранными (решение пользователя 26.10.2026); «Клиенты ДИД» — пустое состояние с текстом макета. Строки по умолчанию упорядочены по приоритету от максимального к низкому. На «Поиске клиентов» при первом показе вкладки стоит предфильтр «Приоритет: Максимальный, Высокий» — видны только они, фильтр снимается в модалке или крестиком чипа «Применено» (решение пользователя 26.10.2026).

## Раскладка (Layout)

Первая колонка поиска с действиями — без видимого заголовка, ширина 52px: поля TableCell по 16px + IconButton M 20px. Стейт-слой 32px целиком внутри ячейки. Подпись «В работу» сохраняется только для настроек таблицы. Прежняя ширина этой колонки в сохранённом виде однократно приводится к 52px; остальные настройки сохраняются.

```
колонка, ритм 12px (Table, вариант «тулбар над таблицей»)
├── .dtable-toolbar: Фильтр · «Краткий отчет» · «Добавить клиента» (кроме поиска) · SegmentControl S (таблица / дерево) · IconButton M settings
└── обёртка без подложки (карточка — сама .dtable)
    └── dtable (fill, без своего тулбара)
        ├── Table: 16 колонок (на «Поиске клиентов» — 33, первая «В работу»), «в избранное» — .tc__hidden в конце строки, поверх строки справа
        ├── пустое состояние: иллюстрация · заголовок · текст · «Добавить клиента»
        └── Pagination
```

## Поведение (Behavior)

- «Клиент» → ClientInfoPage.
- «Фильтр» → модалка с разделами; клик по разделу в навигации доводит панель до него. Текстовое поле — подстрока, одиночный выбор — равенство, множественный — хотя бы одно из выбранных, «От / До» — число в границах (пустая граница открыта). В поле выбора можно набирать — список сужается. Чип под полем множественного выбора снимается крестиком. «Очистить фильтр» очищает поля модалки, «Применить» отбирает строки и показывает чип «Применено: N» (N — число заполненных полей); крестик чипа сбрасывает всё. У каждой вкладки свой фильтр: при возврате на вкладку возвращаются её значения, при первом показе «Поиска клиентов» — предфильтр «Приоритет: Максимальный, Высокий». В поле одиночного выбора можно набрать подпись опции целиком — это тот же выбор, что клик по строке.
- «Краткий отчет», пагинация — общий рендер.
- Порядок по умолчанию — приоритет от максимального к низкому (ранг, не алфавит подписи: опция колонки `sortValue`), шапка колонки показывает направление; на вкладке без колонки, по которой сортировали, — снова порядок по приоритету. Клик по сортировке любой колонки упорядочивает весь набор, а не только текущую страницу (опция `sortAll` общего рендера; на `.tbl` нет `data-sort-rows`); цикл и вид шапки — Table ДС. Третий клик (сброс) возвращает исходный порядок выборки — тот же порядок по приоритету.
- Шестерёнка `settings` (IconButton M neutral, последняя в тулбаре) → штатная модалка ДС «Настройка таблицы» (`data-table-settings`): видимость, порядок и закрепление колонок. Вид таблицы — колонки, ширины, сортировка — хранится на время сессии (`data-table-persist`, опция `persist` общего рендера) и возвращается после каждой перерисовки: смена страницы, сортировка, фильтр, вкладка, «в избранное». Ключ один на главной и в разделе «Клиенты» — настроенные колонки совпадают в обоих местах: `ibp-v2-clients` у «Моих клиентов» и «Клиентов ДИД», `ibp-v2-clients-search` у «Поиска клиентов» (колонок больше — свой вид). В виде «дерево» шестерёнки нет: у дерева свои колонки.
- «в избранное» (по наведению на строку): клиент не в избранном — `bookmark-add` «Добавить в избранное», в избранном — `bookmark-minus` «Убрать из избранного». Клик меняет отметку в сторе, строка перерисовывается, Toast «Клиент … добавлен в «Мои клиенты»» / «… убран из «Моих клиентов»». На вкладке «Мои клиенты» снятый клиент уходит из списка.
- «Взять клиента в работу» — первая колонка поиска, IconButton M neutral `folder-arrow-forward-02`: добавить в «Мои клиенты», показать Toast. У добавленного клиента — активная кнопка `folder-close-x-02` с подписью «Отменить взятие клиента в работу»: убрать из «Моих клиентов», показать Toast и вернуть исходную иконку. Выбор сохраняется между страницами через существующий стор. Решения пользователя 27.10.2026.
- «Добавить клиента» (тулбар и пустое состояние) → `onAdd`: на странице «Клиенты» — вкладка «Поиск клиентов». На самом поиске и без `onAdd` (главная) кнопки в тулбаре нет.
- SegmentControl → таблица или дерево V2MyClientsHierarchicalTree той же выборки; виджет переключает их сам, если страница передала хост дерева (`tree`); без него переключателя нет.
- ⓘ целей — по клику ничего (Р6).

У строки со скрытым действием последний ребёнок — `.tc__hidden` (так велит TableCell), поэтому замыкающий разделитель `.tc--separator` из строки выпадает, а шапка его сохраняет. Последний трек строки остаётся без ячейки: нижняя граница строки и подсветка наведения и выбора не доходят до правого края; чем уже таблица после скрытия колонок, тем заметнее разрыв. Повторяется на каждом рендере, пока в хранилище есть запись колонок (`restore` → `commit`). Правка ДС — только по согласованию с человеком, не решено (26.10.2026).
