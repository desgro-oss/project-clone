# V2MyClientsTable — журнал изменений

Формат записи: что изменилось · почему · по какому требованию. Новая запись — сверху.

## 1.002 — 21.10.2026

**Закрепление колонок.** В шапке у колонок тогл `.th__pin` (TablePin ДС), первая колонка «Клиент» закреплена по умолчанию — раньше она была серой (фон Pinned) без иконки и без возможности открепить; закрепление переживает сортировку, фильтр и пагинацию (общий рендер registry-table). «Статус» 110 → 130px, «ГОСБ» 90 → 120px: в шапке теперь две иконки, и подпись в одно слово рвалась посреди слова. *Требование:* решение пользователя 21.10.2026.

## 1.001 — 20.10.2026

**Тулбар вынесен над таблицей.** Фильтр, «Краткий отчет», «Добавить клиента» и переключатель вида стоят в зоне `.dtable-toolbar` над тайлом; таблица — без своего тулбара; SegmentControl — размер S, в высоту кнопок. Скрытое действие «в избранное» стоит поверх строки у правого края (TableCell, «Скрытые действия») — раньше блок уходил в новый ряд сетки строки, высота строки удваивалась, иконка всплывала под названием клиента. *Почему:* «как в ДС» — вариант Table «тулбар над таблицей». *Требование:* решение пользователя 20.10.2026.

## 1.000 — 10.10.2026

**Компонент создан.** *Почему:* реестр был таблицей страницы с колонками по русской подписи (ревью MS0014, Б5, Б6); вынесен в виджет на общем рендере. *Требование:* docs/tasks/MS0014a-ibp-redesign-frontend-names.md.
