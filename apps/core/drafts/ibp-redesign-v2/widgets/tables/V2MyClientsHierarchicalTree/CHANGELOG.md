# V2MyClientsHierarchicalTree — журнал изменений

Формат записи: что изменилось · почему · по какому требованию. Новая запись — сверху.

## 1.004 — 26.10.2026

**Шеврон холдинга по ДС.** Глиф `.tc__twisty` — `chevron-right`: TableCell ДС сам поворачивает его на 90° у раскрытого узла. С `chevron-down` раскрытый холдинг показывал стрелку влево, свёрнутый — вниз, наоборот (Б40). *Почему:* замечание приёмки; дерево теперь видно и на главной. *Требование:* правило ДС TableCell (tree).

## 1.003 — 26.10.2026

**Дерево той же выборки, что реестр.** `render(host, { rows, onView })`: дерево группирует клиентов открытой вкладки V2MyClientsTable — «Мои клиенты» (избранные) или «Поиск клиентов» (вся база); показывает и перерисовывает его виджет реестра. Виджет стоит и на главной, во вкладке «Поиск клиентов». «Добавить клиента» помечена `data-mc-add`: ведёт на поиск, на самом поиске скрыта. *Почему:* таблица поиска и таблица раздела «Клиенты» должны быть одинаковыми. *Требование:* решение пользователя 26.10.2026.

## 1.002 — 21.10.2026

**Закрепление колонок.** В шапке у колонок тогл `.th__pin` (TablePin ДС), первая колонка закреплена по умолчанию — раньше она была серой (фон Pinned) без иконки и без возможности открепить. *Требование:* решение пользователя 21.10.2026.

## 1.001 — 20.10.2026

**Тулбар вынесен над таблицей.** Фильтр, «Краткий отчет», «Добавить клиента» и переключатель вида стоят в зоне `.dtable-toolbar` над тайлом; таблица — без своего тулбара; SegmentControl — размер S, в высоту кнопок. Сделано вместе с V2MyClientsTable, чтобы тулбар не прыгал при смене вида. *Почему:* «как в ДС» — вариант Table «тулбар над таблицей». *Требование:* решение пользователя 20.10.2026.

## 1.000 — 10.10.2026

**Компонент создан.** *Почему:* дерево холдингов было веткой скрипта страницы; вынесено в виджет с именем фронтенда (MS0014a, 4.2). *Требование:* docs/tasks/MS0014a-ibp-redesign-frontend-names.md.
