## Описание (Purpose)

Отчет финансовых метрик (МСФО или РСБУ) по [[ФИ]] сделки: по каждому
рассчитанному ФИ — группа строк-метрик, по колонкам — даты, в которые у какого-либо ФИ сделки
есть финансовое событие (выдача, погашение, начисление процентов, фиксация [[ЭПС]]/[[ВБС]] и т. п.).
Даты общие для всех ФИ отчета, группы прокручиваются вместе — одна таблица на отчет; у ФИ без
события на дату ячейка пустая (ответ человека 20.10.2026, вопрос 10 задачи RE0033). ФИ,
который не удалось рассчитать, в отчете не появляется (вопрос 4 задачи).

Виджет вшивается на страницу дважды: на вкладку «МСФО» и на вкладку «РСБУ». Какой это отчет,
знает не виджет, а данные: страница передает готовый отчет — `FinMetricsReportRsDto` с кодом
`IFRS` или `RAS`. Сам виджет не читает стор.

Над таблицей — тулбар: кнопка «Фильтр» (TableFilter) и, если фильтр применен, один чип
«Применено: N», где N — число ФИ, выбранных в фильтре. Окно фильтра виджет не открывает:
кнопка шлет событие, окно открывает страница. Чиплиста параметров и «+N» нет — на макете
устаревший вариант (ответ 30 задачи).

Отчет пуст, когда в нем нет ни одной группы (например, у ФИ нет отчётности РСБУ): колонок дат
и шапки нет, по центру «Нет данных», кнопка «Фильтр» заблокирована (ответ 28 задачи).

Где виджет стоит на странице, какую высоту ему дает страница и сколько колонок он занимает —
решает страница, не он.

## Поля (Fields)

Отчет приходит как `FinMetricsReportRsDto` (`data/mock-fin-metrics-calc.js`); имена полей — как в
описании типа.

| Поле | Смысл | Тип, единица | Источник | Обязательное |
|---|---|---|---|---|
| `reportCode` | какой это отчет (`IFRS` или `RAS`); скрипт кладет его на корень в `data-report` | код | `FinMetricsReportRsDto.reportCode` | да |
| `dates` | колонки — все даты событий всех ФИ отчета; шапка `ДД.ММ.ГГГГ`, колонки общие | массив ISO-дат | `FinMetricsReportRsDto.dates` | да (пустой массив у пустого отчета) |
| `groups[].financialInstrumentName` | имя ФИ в строке группы, жирным | строка | `groups[].financialInstrumentName` | да |
| `groups[].currencyCode` | валюта ФИ в строке группы, приглушенно, кодом (`RUB`) | код ISO 4217 | `groups[].currencyCode` | да |
| `groups[].financialInstrumentId` | ключ группы и фильтра | строка | `groups[].financialInstrumentId` | да |
| `groups[].rows[].metricName` | «Наименование метрики» — первая закрепленная колонка | строка | `groups[].rows[].metricName` | да |
| `groups[].rows[].metricCode` | ключ метрики в фильтре | строка | `groups[].rows[].metricCode` | да |
| `groups[].rows[].values[дата]` | значение метрики на дату: `1 500 000,00` (неразрывный пробел между разрядами, запятая, обычный минус); `null` — пустая ячейка | число, единица — валюта ФИ | `groups[].rows[].values` | нет |

Значение фильтра `FmFilterValue = { fiIds: string[], metrics: { [fiId]: string[] } }` — его
хранит страница, виджет только применяет:

| Правило | Что видно |
|---|---|
| `fiIds` пуст | фильтра нет: все ФИ и все метрики; чипа нет |
| `fiIds` непуст | только ФИ из `fiIds`; чип «Применено: N», N — число ФИ |
| у ФИ из `fiIds` есть `metrics[fiId]` | у этого ФИ только строки с этими `metricCode` |
| у ФИ из `fiIds` нет `metrics[fiId]` или он пуст | все метрики ФИ |
| после фильтра у ФИ не осталось строк | группа не рисуется (допущение, вопрос 4) |

Порядок строк — порядок отображения: группы в порядке отчета, метрики в порядке отчета. Значения
не сортируются.

## Поведение (Behavior)

| Триггер | Результат |
|---|---|
| Клик по «Фильтр» | с корня виджета уходит событие `fmtableaction` с `detail: { action: 'FILTER' }`; кнопка сама окно не открывает (у нее нет `data-modal`). Окно открывает страница |

| Клик по шеврону группы | группа сворачивается или раскрывается (рантайм ДС, событие `treetoggle`) |
| Горизонтальный скролл тела | первая колонка («Наименование метрики») остается слева, под ней и над ней — сепаратор 8px |
| Перетаскивание правой границы шапки | меняется ширина колонки (рантайм ДС) |
| Перетаскивание за подпись шапки | колонка переносится (рантайм ДС); закрепленная колонка переносится вместе с закреплением |
| `render(root, report, filter)` | перерисовка тулбара (чип, блокировка «Фильтр») и таблицы |

### Связанные артефакты

| Триггер | Тип | Что внутри | Что меняется после | Кто ещё вызывает |

### Применение фильтра

Фильтр применяет сам виджет, в `render`; страница хранит значение и перерисовывает. Пустой
отчет определяется по `report.groups.length === 0`, а не по результату фильтра: если фильтр скрыл
все группы непустого отчета, «Нет данных» показывается, но «Фильтр» остается доступным.

## Данные (Data dependencies)

### API — что нужно от бэкенда

Отчет по коду `IFRS` или `RAS` целиком: даты событий всех ФИ и по каждому рассчитанному ФИ — метрики
со значениями по датам (поля — раздел «Поля»). Нерассчитанный ФИ в отчет не входит. Состав метрик по
типам ФИ, единицы метрик и периодичность дат — не решено (см. «Открытые вопросы»). Имена методов
API не придумываются: их выбирает разработка.

## Осознанные отклонения (Deviations)

| Правило | Как сделано | Почему |
|---|---|---|
| Локальные компоненты, тип «таблица»: корень — Tile ДС (обычно `tile--headless`) | корень — `section` без Tile | на макете таблица стоит прямо на фоне вкладки, с тулбаром над ней; карточки нет |
| Нет готового компонента «группа строк» | группа ФИ — дерево строк TableCell: `data-node` у строки группы, `data-parent` у метрик, `.tc--tree`, `.tc__twisty` | решение при постановке этапа Э4 (21.10.2026): ближайший штатный способ сворачиваемой группы в ДС |
| Пустое значение ячейки — прочерк `.tc__empty` | `null` — пустая ячейка без прочерка | решение агента 8 задачи RE0033: нет события у ФИ на дату — это норма, прочерки на каждой такой ячейке зашумили бы отчет |
| Закрепленная колонка по ДС снабжается кнопкой `.th__pin` (открепить) | кнопки нет, колонка закреплена всегда | решение при постановке этапа Э4: «Наименование метрики» не должна уезжать; на макете у колонки есть булавка — вопрос 7 |
| Пустое состояние Table: иллюстрация `empty-folder`, заголовок, пояснение | только заголовок «Нет данных» | макет: «Нет данных» по центру без иллюстрации и пояснения |
| Макет: у пустого отчета шапка с «Наименование метрики» и датами | шапки нет, колонок дат нет | ответ 28 задачи: колонок дат нет на всех вкладках; шапка вместе с ними |
| Строка группы использует `.tc__text` без модификаторов | имя ФИ жирным: `.lc-financial-metrics-table__group-name.tc__text { font: var(--type-body-s-strong) }` | на макете имя ФИ выделено; в ДС для ячейки такого модификатора нет — свое правило на токене ДС (Body S Strong), записано здесь |
| Макет: первая колонка на одном кадре подписана «Наименование» | «Наименование метрики» | на остальных кадрах и листах подпись «Наименование метрики» |
| Макет: чиплист параметров, «+99», кнопка «Фильтр» XS | кнопка S и один чип «Применено: N» | ответ 30 задачи: на макете устаревший вариант |
| Макет: числа с точкой на листах МСФО и РСБУ, KPI | `1 500 000,00` | решение агента 8 задачи RE0033: как на остальных листах |
| Перестановка колонок за подпись шапки (в ДС включена всегда — `TableReorder.js`) | выключена: у подписей шапки стоит атрибут `data-grab`, по контракту рантайма такие подписи он не берёт; ширина колонок меняется как обычно | колонки дат идут по хронологии — порядок менять нельзя (человек, 21.10.2026). Шестерёнки «Настройка таблицы» нет — в её модалке порядок тоже переставляется |

## Открытые вопросы (Open questions)

Решение человека 29.09.2026: вопросы не закрываются догадкой и не удаляются, пока человек не
разберёт каждый; ответ записывается у вопроса с датой. Вопросы 1–2 перенесены из задачи RE0033
(`docs/tasks/RE0033-deal-financial-metrics.md`, вопросы 9 и 11).

1. **Состав метрик МСФО и РСБУ по типам ФИ** (акции, РЕПО, дебиторская задолженность,
   дополнительная доходность и т. д.) — точной информации пока нет, человек вернется с
   ответом (20.10.2026; RE0033, вопрос 9). На макете — 13 строк РСБУ для кредита; состав МСФО
   придуман по чипам окна фильтра. Допущение прототипа (решение агента 16 задачи, 21.10.2026):
   набор метрик одинаков для всех типов ФИ.
2. **Фильтр отчета** (RE0033, вопрос 11, часть про таблицу):
   — общий фильтр у всех вкладок или у каждой свой — не решено; в прототипе у каждой вкладки
   свой чип, индикаторы свои (ответ 30);
   — сохраняется ли фильтр между заходами на страницу — не решено; в прототипе нет, виджет
   значение не хранит — его хранит страница;
   — «+99» в чипах — снято: чиплиста параметров нет (ответ человека 21.10.2026, вопрос 30).
3. **Фильтр скрыл все группы** — какой текст показывать: в ДС для пустой таблицы различаются
   «нет данных» и «ничего не найдено»; в прототипе везде «Нет данных» (допущение
   21.10.2026, макета нет), «Фильтр» остается доступным.
4. **ФИ, у которого после фильтра не осталось ни одной метрики** (в фильтре выбраны метрики,
   которых нет в отчете) — группа не рисуется, чтобы не оставлять пустой заголовок (допущение
   21.10.2026, макета нет).
5. **Единицы значений** — числа показаны в валюте ФИ, код валюты стоит в строке группы; в
   шапке колонок единиц нет. У метрик, которые по смыслу не суммы (проценты, ставки), единицы не
   заданы — не решено (21.10.2026).
6. **Пустая ячейка и 0,00** — отчет различает «нет события на дату» (пусто) и «значение
   ноль» (`0,00`); различает ли это бэкенд — не решено (21.10.2026; допущение прототипа: `null` —
   пусто).
7. **Закрепление первой колонки.** На макете у колонки есть булавка (можно открепить);
   в прототипе колонка закреплена всегда, кнопки нет — решение при постановке этапа (21.10.2026).
   Нужна ли кнопка — не решено.
8. **Настройка таблицы** (шестерёнка `data-table-settings`: видимость, порядок и закрепление
   колонок) — по ДС это стандарт таблиц; на макете ее нет, в прототипе не добавлена. Нужна ли —
   не решено (21.10.2026). Порядок колонок менять нельзя (даты по хронологии, 21.10.2026), поэтому
   такая модалка была бы без перестановки — рантайм ДС этого не умеет.
9. **Сворачивание групп** — по умолчанию все раскрыты; запоминать ли состояние между заходами
   на страницу — не решено (21.10.2026). При смене фильтра свернутые группы остаются
   свернутыми (допущение).
10. **Ошибка получения отчета и права видеть отчет** — вид не нарисован на макетах, в
    прототипе нет — не решено (21.10.2026).
