# Карточка финансового инструмента (FinInstrumentCard)

## Описание (Purpose)

Один [[ФИ]] сделки — карточкой-тайлом. Подчасть тайла «Финансовые
инструменты» (`FinInstrumentsTile`): тайл рисует ею свой список и управляет действиями,
карточка отвечает только за вид. Основа — Tile ДС с аккордеоном (не Card): с 23.10.2026
карточка не имеет собственных наведения и нажатия, шапка — TileHeader M, контент
12/20/24/20. Своя страница в витрине — чтобы были видны все виды и состояния макета
«Card-Fininstrument» (решение человека 17.10.2026, задача RE0028).

Баланс, валюта, сумма, дата подписания и список инструментов карточка показывает по узлам
дерева продуктов, прикреплённым к ней. Правила живут в сторе ФИ `FinInstrumentsStore`
(`data/fin-instruments-store.js`), карточка их не дублирует.

Виды — типы ФИ: Кредит, Акции, Доп. доходность, РЕПО, Дебиторская задолженность. От типа
зависят подпись суммы (сумма лимита · стоимость покупки · цена исполнения) и целевой IRR
(только у акций).

**Компонент отдаёт эталон разметки, а не готовую карточку.** Корень фрагмента — скрытый
контейнер с `<template>`: карточек в тайле много и состав полей у них разный, а через метку
`ds-include` передаются только `id`/`class`/`state`/`mode`. Карточки по данным рисует
`FinInstrumentCard.js` — тот же приём, что у карточки контрагента окна КНР.

Пара во фронтенде — `DealFinancialInstrumentTile` (`features/`), карточка группы
`DealFinancialInstrumentsGroup` (README модуля, «Имена фронтенда»).

## Состояния (States)

Макет «Card-Fininstrument» — матрица: тип ФИ × развёрнута / свёрнута × пять колонок
(Не заполнено · Не заполнено, просмотр · Заполнено · Заполнено, просмотр · Ошибка).
Колонка «Ошибка» снята: в системе у карточки ошибки не бывает (решение человека 17.10.2026).
Состояние карточки ставит `FinInstrumentCard.js` атрибутом `data-state` на корне.

| Состояние | Есть в продукте | Вид |
|---|---|---|
| Загрузка (Loading) | нет у карточки | карточки-заготовки рисует тайл |
| Данные есть = Заполнено (`data`) | да | значения, контрагенты с риск-метрикой, признаки, коды RWA, строки инструментов со счётчиком |
| Заполнено частично | да | та же разметка, что «Заполнено» (`data`): прочерки на месте пустых значений, пустые необязательные блоки свёрнутой части не показываются |
| Данных нет (Empty) = Не заполнено (`empty`) | да | карточка создана, узлов и параметров нет: прочерки, «Тип отчетности» заполнен; развёрнутая — «Нет связанных инструментов», без счётчика у «Инструменты» |
| Ошибка (Error) | нет | у карточки ошибки не бывает — состояние макета снято (решение человека 17.10.2026) |
| Обновление | нет у карточки | спиннер «Обновление» рисует тайл в своей шапке |
| Редактирование доступно | да | `data-mode="edit"` |
| Только просмотр | да | `data-mode="view"` |
| Нет права видеть | не решено (19.09.2026) | решает экран, не компонент |

## Обязательность заполнения (Required)

- Компонент обязателен к заполнению целиком: не решено (19.09.2026) — как у тайла.
- Обязательные поля: тип, тип отчётности (окно создания) и наименование (окно изменения).

## Переполнение (Overflow)

| Случай | Правило |
|---|---|
| Длинный текст в поле | значения сетки — одна строка с усечением и тултипом (ReadOnlyField); контрагент — две строки с усечением; заголовок — клэмп Tile |
| Много строк или записей | строки инструментов идут столбиком, карточка растёт по высоте; своего скролла нет |
| Узкая ширина | колонки сетки сжимаются, значения усекаются; признаки и коды RWA переносятся в следующий ряд. Своих брейкпоинтов нет |
| Полная ширина | сетка растягивается пропорционально |

## Для разработчиков (Implementation)

### Параметры метки

Метка `<ds-include>` вшивает только эталон (скрытый `<template>`), параметров у неё нет:
