# LoanExternalDataTile — журнал изменений

Формат записи: что изменилось · почему · по какому требованию. Без «почему» правку через
месяц откатывают обратно. Новая запись — сверху.

Правка вида, поведения или состава — новая версия: `## М.ммм — ДД.ММ.ГГГГ`. Правка только
описания версию не меняет — запись без номера: `## Паспорт — ДД.ММ.ГГГГ`. Приведение к
новым правилам ДС — тоже отдельная запись с новой `rulesVersion`.

## 1.001 — 02.11.2026

**Общий компонент, потребители.** Категория витрины «НКЛ» → «Общие»; потребитель «tranche» — плюс
поле «CRM ID продукта» (решение 26.10.2026 «не добавлять» отменено); состав полей зависит от
потребителя: `render(tile, { consumer, … })` и `setConsumer(tile, consumer)`, потребители — список
`CONSUMERS` в JS, новые добавляются строкой. *Почему:* ЕТС и Техинфа у транша и НКЛ общие, у транша
свой третий идентификатор; переключение расширяемое — потом добавятся другие потребители.
*Требование:* задача RE0049, решение человека 02.11.2026.

## Паспорт — 27.10.2026

Категория витрины «Сделка» → «НКЛ». *Почему:* виджеты страницы НКЛ собраны в своём разделе витрины. *Требование:* поручение человека 27.10.2026, задача RE0041.

## 1.000 — 26.10.2026

**Компонент создан.** Тайл «Техническая информация» страницы договора займа: «ГФО ID» и «ГФО ID фондирующего кредита», правка в окне. *Почему:* идентификаторы договора должны быть видны и правиться на странице договора. *Требование:* задача RE0041, макет дизайнера 26.10.2026.
