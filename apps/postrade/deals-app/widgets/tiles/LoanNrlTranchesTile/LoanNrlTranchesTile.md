# Транши

## Описание (Purpose)

Тайл страницы договора займа ([[НКЛ]]), раздел «Транши». Показывает ровно те [[Транш|транши]], что висят под этим договором в дереве продуктов сделки, строками ProductRow — в том же виде, что в тайле «Продукты сделки»: заголовок-ссылка с номером и названием («1.1.1.1. Транш»), дата подписания договора и сумма лимита с кодом валюты. Заголовок ведёт на страницу транша. У строки в режиме правки есть меню ⋮ с пунктами «Погасить» и «Удалить»; в шапке — кнопка «Добавить транш».

Сам тайл данных не меняет: добавление, погашение и удаление делает страница через дерево продуктов и его окна (погашение, подтверждение удаления), а тайл только шлёт события `loanaction` и перерисовывается. «Добавить транш» добавляет транш сразу, без окна, как ⊕ у договора займа в дереве продуктов (решение агента 1, задача RE0041).

Заголовок раздела «Транши» над тайлом рисует страница, не компонент. Место на странице и ширину (6 колонок из 12) задаёт страница.

**Откуда данные в прототипе.** Строки во фрагменте `LoanNrlTranchesTile.html` — пример с макета. На странице договора их заменяет `LoanNrlTranchesTile.js` (`PostTileLoanNrlTranches.render`): страница собирает список из `LoanAgreementStore.tranches()` и отдаёт тайлу (дата — ISO, сумма — число; в строки они форматируются при выводе).

## Поля (Fields)

| Поле | Смысл | Тип, единица | Источник | Обязательное |
|---|---|---|---|---|
| `id` | идентификатор узла транша в дереве продуктов | строка | `LoanAgreementStore.tranches()` | да |
| `number` + `name` | номер места в дереве и название — текст заголовка-ссылки («1.1.1.1. Транш») | строки | то же | да |
| `repaid` | транш погашен: в строке статус погашения, в меню вместо «Погасить» — «Отменить погашение» | boolean | то же (`repaidAt` узла) | да |
| `repaidAt` | дата погашения транша, ГГГГ-ММ-ДД; в строке «Дата фактического погашения ДД.ММ.ГГГГ» | string \| null | `repaidAt` узла | нет |
| `canRemove` | транш можно удалить; `false` выключает «Удалить» (например, транш прикреплён к [[ФИ]]) | boolean, по умолчанию `true` | `ProductTreeStore.canRemove` | нет |
| `dateISO` | дата подписания договора; на экране `ДД.ММ.ГГГГ`, пусто — «–» | дата, `ГГГГ-ММ-ДД` или null | то же | нет |
| `amount` | сумма лимита; на экране `800 000,00`, пусто — «–» | число или null, валюта — `currencyCode` | то же | нет |
| `currencyCode` | код валюты — аффикс суммы (`RUB`) | код ISO 4217 | то же | нет |

Порядок значений в строке — порядок отображения: дата, затем сумма. Пустое значение — «–» на своём месте, пара с места не уходит. Порядок строк — порядок траншей в дереве. Смысл суммы лимита и даты подписания договора у транша — как в тайле «Продукты сделки» (подписи те же).

## Поведение (Behavior)

Компонент не открывает собственных окон: все действия уходят событием `loanaction` (всплывающее, с корня тайла, `detail = { action, id }`), что делать по нему — решает страница.

| Триггер | Событие | Что делает страница |
|---|---|---|
| «Добавить транш» (шапка, пустой тайл) | `ADD_TRANCHE` | добавляет транш под договором сразу, без окна, как ⊕ у договора займа в дереве продуктов (решение агента 1, RE0041); тайл перерисовывается |
| Заголовок-ссылка строки | `OPEN_TRANCHE { id }` | открывает страницу транша |
| Пункт «Погасить» | `REPAY_TRANCHE { id }` | открывает окно погашения дерева продуктов (`RepaymentModal`) |
| Пункт «Отменить погашение» | `UNDO_REPAY_TRANCHE { id }` | открывает то же окно в режиме отмены погашения |
| Пункт «Удалить» (если не выключен: `canRemove: false` — пункт `aria-disabled`, события нет) | `DELETE_TRANCHE { id }` | открывает подтверждение удаления дерева продуктов (`ProductTreeConfirmModal`); после подтверждения транш уходит из дерева |

### Связанные артефакты

| Триггер | Тип | Что внутри | Что меняется после | Кто ещё вызывает |
|---|---|---|---|---|
| Пункт «Погасить» | Модальное окно погашения (`widgets/modals/RepaymentModal/`) | погашение транша | транш получает фактическую дату погашения, в строке появляется статус погашения, в меню «Погасить» заменяется на «Отменить погашение» (его окно — то же, отмена снимает дату); по правилам страницы погашение договора переводит тайлы страницы в просмотр | тайл «Продукты сделки» |
| Пункт «Удалить» | Подтверждение удаления (`widgets/modals/ProductTreeConfirmModal/`) | подтверждение | транш уходит из дерева и из тайла; плановая дата погашения договора пересчитывается | тайл «Продукты сделки» |

Состав окон и их правила живут в паспортах этих артефактов, здесь не дублируются.
