# TrancheNrlSummaryTile — журнал изменений

Формат записи: что изменилось · почему · по какому требованию. Без «почему» правку через
месяц откатывают обратно. Новая запись — сверху.

Правка вида, поведения или состава — новая версия: `## М.ммм — ДД.ММ.ГГГГ`. Правка только
описания версию не меняет — запись без номера: `## Паспорт — ДД.ММ.ГГГГ`. Приведение к
новым правилам ДС — тоже отдельная запись с новой `rulesVersion`.

## 0.001 — 02.11.2026

**Компонент создан.** *Почему:* три хедлесс-тайла раздела «НКЛ» страницы транша
(инлайн-разметка `pages/Tranche.html`, строки 70–90) стали локальным компонентом — один

лимита), состав вариантов по образцу `CounterpartiesTile`; в «Контрагента» добавлена
риск-метрика RiskMetric (решения человека 02.11.2026). Данные — от родительской НКЛ
(`LoanAgreementStore`), состояние одно — «данные есть». Вид перенесён с утверждённой
инлайн-разметки без изменений. *Требование:* `docs/tasks/RE0049-tranche-page.md`, этап Э1.
