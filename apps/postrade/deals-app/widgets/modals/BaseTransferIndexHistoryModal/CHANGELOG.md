# BaseTransferIndexHistoryModal — журнал изменений

Формат записи: что изменилось · почему · по какому требованию. Без «почему» правку через
месяц откатывают обратно. Новая запись — сверху.

Правка вида, поведения или состава — новая версия: `## М.ммм — ДД.ММ.ГГГГ`. Правка только
описания версию не меняет — запись без номера: `## Паспорт — ДД.ММ.ГГГГ`. Приведение к
новым правилам ДС — тоже отдельная запись с новой `rulesVersion`.

## Паспорт — 02.11.2026

Категория витрины «НКЛ» → «Общие»; добавлен `artifactOf` — тайл «ЕТС» (TransferRateTile): окно встаёт под-пунктом аккордеона «ЕТС» в меню витрины. *Почему:* истории и схемы ЕТС — одно целое с тайлом «ЕТС», в меню витрины они собираются под одним аккордеоном; тайл «ЕТС» с Э3 общий для НКЛ и транша, поэтому категория — «Общие» (решение человека 02.11.2026). *Требование:* задача RE0049, этап Э5.

## 1.000 — 27.10.2026

**Окно создано** по макету дизайнера «История изменения базового индекса» (27.10.2026): таблица (Table ДС) с колонками «Дата изменения», «Базовый индекс (БИ)», «Значение, %», сортировка по каждой колонке, пагинация (размер страницы 50 по умолчанию), «Нет данных» при пустой истории, «Закрыть» в подвале; окно доступно и в режиме просмотра. Строки и сортировку ведёт скрипт окна (`PostModalBaseTransferIndexHistory`): на открытии читает `LoanAgreementStore.baseIndexHistory()`. *Почему:* страница «Единая трансфертная ставка» показывает историю изменения БИ справкой из меню ⋮ шапки. *Требование:* задача RE0041, ответы человека 26.10.2026 (вопросы 10–12).
