# Окно «Перенос инструмента» (InstrumentTransferModal)

## Описание (Purpose)

Окно переноса инструмента в другой продукт этой же сделки. Открывается пунктом «Перенести»
в меню инструмента в тайле «Продукты сделки».

- Пояснение: «Выберите продукт, в который вы хотите переместить 1.1.1. Договор займа» —
  номер и название инструмента.
- «Откуда» — продукт ДИД и продукт, где инструмент сейчас; строка продукта выключена.
- «Куда» — все продукты ДИД сделки и их продукты. Текущий и неподходящие продукты
  выключены. Строка продукта ДИД сворачивается шевроном справа.
- Клик по доступному продукту выбирает его: подложка и зелёная рамка (состояние ProductRow
  «выбрана», как на макете). Выбрать можно один продукт; клик по другому переносит выбор.
- «Сохранить» становится доступна после выбора. Во время сохранения — индикатор на кнопке.

Крестик, Esc и клик по подложке закрывают окно без изменений.

Место на странице задаёт страница: скрим вшивается отдельной меткой `<ds-include>` в конце
`body`.

## Бизнес-смысл (Business context)

| Вопрос | Ответ |
|---|---|
| Зачем существует | Перенести инструмент в другой подходящий продукт или продукт ДИД этой же сделки (ответ человека 30.09.2026, 3). Окно — артефакт тайла «Продукты сделки»; бизнес-смысл самого дерева продуктов — в его паспорте |
| Кто заполняет и когда | Тот, у кого есть право править дерево продуктов, пока сделка редактируема: пункт «Перенести» есть в меню инструмента только в режиме правки тайла. В статусах «Активная», «Погашена», «Ожидает подтверждения» и «Подтверждение изменений» страница ставит тайлу просмотр при любой роли. Какая роль вправе править дерево — не решено (19.09.2026) |
| Кто пользуется результатом | Дерево продуктов в тайле «Продукты сделки» (номера пересчитаны). Производные поля записи сделки пересчитываются и сохраняются, их читает реестр «Текущий портфель ДИД» (продукты, балансы, валюты) |
| Бизнес-правила | Переносят только инструмент: у транша пункта «Перенести» нет. Инструмент уходит вместе с траншами и связью с [[ФИ]]. Подходит продукт, в состав которого входит тип инструмента, в том числе продукт другого продукта ДИД — это допущение агента, не решение человека (задача RE0001, вопрос 41). Без выбора продукта перенос не сохранить. Перенос возможен только внутри этой же сделки |

## Обязательность заполнения (Required)

- Выбор продукта обязателен: без него «Сохранить» недоступна.
- Что отдаёт наружу: инструмент в новом продукте; производные поля записи сделки
  пересчитываются и сохраняются.

## Для разработчиков (Implementation)

### Параметры метки

Метка `<ds-include>` атрибутов не несёт. Инструмент передаёт скрипт.

| Атрибут | На корне окна (`.modal`) | Значения | Смысл |
|---|---|---|---|
| — | `data-state` | `data` · `updating` | `updating` — идёт сохранение |

### Скрипт окна

`InstrumentTransferModal.js`, глобал `PostModalInstrumentTransfer`:

| Функция | Что делает |
|---|---|
| `open(instrumentId)` | открыть окно для инструмента |
| `use(instrumentId)` | нарисовать без открытия — для витрины |
| `listHTML(targets, section)` | разметка «Откуда» (`from`) и «Куда» (`to`) из `ProductTreeStore.moveTargets` |
| `select(productId)` | выбрать продукт — для витрины |
| `mirror(scrim)` | `data-state="updating"` → `.modal--saving` и `btn--loading` |

Выбор — радиогруппа: клик, Пробел и Enter выбирают строку, стрелки переходят по доступным
строкам; в порядке Tab — выбранная (или первая доступная). «Сохранить» —
`ProductTreeStore.moveInstrument(id, productId)` и `commit`.
