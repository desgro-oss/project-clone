# TrancheLoanLimitsModal — журнал изменений

Формат записи: что изменилось · почему · по какому требованию. Без «почему» правку через
месяц откатывают обратно. Новая запись — сверху.

Правка вида, поведения или состава — новая версия: `## М.ммм — ДД.ММ.ГГГГ`. Правка только
описания версию не меняет — запись без номера: `## Паспорт — ДД.ММ.ГГГГ`. Приведение к
новым правилам ДС — тоже отдельная запись с новой `rulesVersion`.

## 0.001 — 02.11.2026

**Компонент создан.** Окно ручной правки валюты и суммы лимита транша: ширина три
колонки, «Валюта» — выбор из списка, «Сумма лимита» — поле суммы без постфикса валюты.
*Почему:* валюта транша обычно совпадает с валютой НКЛ, но не всегда — значение
заполняется вручную; постфикс валюты у суммы убран по решению человека.
*Требование:* задача RE0049, решение человека 02.11.2026 («Валюта транша (3.2)»).
