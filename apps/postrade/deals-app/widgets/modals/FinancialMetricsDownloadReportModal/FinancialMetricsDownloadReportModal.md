## Описание (Purpose)

Окно перед скачиванием файла XLSX со всем отчётом финансовых метрик сделки (МСФО, РСБУ, KPI и
фиксации ЭПС/ВБС): файл содержит данные К2, поэтому окно предупреждает об ограничениях и просит
подтвердить выгрузку. Открывается пунктом «Выгрузить в XLSX» кебаба над вкладками страницы:
кебаб стоит выше вкладок и вкладками не управляется, поэтому окно одно на всю страницу и не знает,
какая вкладка открыта (ответ 12).

Вид окна зависит от сети, из которой открыта страница (ответ 21, как в расчёте FV, RE0012):

- **Сигма** — сеть банка с выходом в интернет: файл шифруется, окно просит выбрать сотрудников,
  которым он будет доступен;
- **Альфа / Омега** — внутренние сети без интернета: шифрования нет, окно только предупреждает.

В продукте сеть определяется по логину (на каждую сеть свой логин). В прототипе её переключает
адрес страницы: по умолчанию Альфа, `?net=sigma` — Сигма.

Заголовок и пара кнопок «Отменить» / «Выгрузить» у обоих видов одинаковые, вид с шифрованием
отличается только блоком выбора сотрудников (ответ 31, решение агента 11).

│   ├── ряд из двух добавлений: InputAutocomplete «Сотрудник» + Button outline M «Добавить» ·
│   │   InputText «Сотрудник вне штата (по e-mail)» + Button outline M «Добавить»

Собственный CSS виджета — только зазоры тела, ряд добавлений и список в предупреждении, на
токенах ДС. Ширину окна переключает скрипт: `modal--w8` у вида с шифрованием, `modal--w6` у вида
без шифрования.

## Обязательность заполнения (Required)

- Компонент обязателен к заполнению целиком: нет — вид без шифрования не требует ничего; вид с шифрованием требует хотя бы одного отмеченного получателя.
- Обязательные поля внутри: нет, см. «Поля».
- Что показывает, когда обязательное не заполнено: «Выгрузить» выключена, текста ошибки нет.
- Что отдаёт наружу (признак для экрана или формы): `opts.run(ctx, recipients)` — контекст, переданный в `api.open`, и отмеченные получатели (в виде без шифрования — пустой список).

## Поведение (Behavior)

Открывает окно страница: `PostDealDownloadReportModal.bind(scrim, { employees, run })` один раз при
загрузке, `api.open({ encrypted })` — по пункту кебаба. Вид выбирает аргумент `encrypted`.

| Триггер | Результат |
|---|---|
| Выбор сотрудника из списка автокомплита | ФИО встаёт в поле, «Добавить» становится доступной |
| Набор текста в поле «Сотрудник» | список сужается до совпавших ФИО; «Ничего не найдено», если совпадений нет |
| «Добавить» у «Сотрудника», Enter в поле | строка попадает в таблицу отмеченной |
| Верный адрес в «Сотрудник вне штата (по e-mail)» | «Добавить» доступна; Enter в поле — то же, что «Добавить» |
| «Добавить» у e-mail | строка попадает в колонку своего домена: адрес с `omega` или `alfa` — во внутренний, остальные — во внешний; ФИО и должность — «—» |
| Повторное добавление | дубль не создаётся: строка отмечается и подсвечивается |
| Чекбокс строки, «выбрать всех» | отмечают и снимают получателей; «Выгрузить» доступна, пока отмечен хотя бы один |
| «Выгрузить» | окно закрывается, страница получает `run(ctx, recipients)` и имитирует выгрузку (0,6 с; повторный запуск в это время игнорируется): снек «Файл выгружен» либо, при `?download=fail`, снек ошибки |
| «Отменить», крестик или Esc | окно закрывается, ничего не запускается |
| Повторное открытие | добавленные получатели остаются, пока открыта страница |

## Открытые вопросы (Open questions)
