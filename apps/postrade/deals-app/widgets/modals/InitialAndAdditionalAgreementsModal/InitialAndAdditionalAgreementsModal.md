# Окно «Договор»

## Описание (Purpose)

Артефакт тайла «Договор и дополнительные соглашения». Не компонент: сам по себе не существует и в
плоском списке витрины его нет — он принадлежит своему тайлу. Заголовок окна — «Договор».

Окно решает одну задачу: ввести два реквизита договора — «Номер договора» и «Дату подписания».
Плановой даты погашения в окне нет: её берёт готовой тайл (у договора займа — по траншам).

Окно самодостаточно: на открытии читает `LoanAgreementStore.get().contract`, «Сохранить»
проверяет дату, зовёт `LoanAgreementStore.setContract({ contractNumber, contractSignDate })` и
закрывает окно. Тайл перерисовывает страница по событию стора
(`PostModalInitialAndAdditionalAgreements.bind`, `InitialAndAdditionalAgreementsModal.js`).

Окно нарисовано только для типа «НКЛ». Окон для других типов продукта нет и в этой задаче они не
делаются (решение человека 26.10.2026).

## Поведение (Behavior)

| Триггер | Результат |
|---|---|
| Открытие | поля заполняются из записи договора; несохранённый ввод прошлого открытия сбрасывается |
| Правка поля даты при показанной ошибке | ошибка пересчитывается и снимается, когда ввод стал верным |
| «Сохранить» | в просмотре (`isEditable()` ложно) — только закрытие; иначе: дата заполнена и не существует — ошибка у поля, окно открыто, фокус на поле; иначе `LoanAgreementStore.setContract` и закрытие. Пустая дата сохраняется пустой |
| Крестик, Esc | закрытие без сохранения |
| Клик по скриму | не закрывает: в окне ввод (триггер с `data-modal-guarded`) |

## Открытые вопросы (Open questions)

1. **Окна «Договор» для типов, кроме НКЛ** не делаются: у разных инструментов свои особенности и набор полей окна, покажем при сборке их страниц (ответ человека 26.10.2026, вопрос 31). До тех пор у типов, кроме НКЛ, кнопка «Заполнить» тайла открывает это окно (допущение, 27.10.2026) — не решено, что открывать.
2. **Роли, правящие договор** — не решено (27.10.2026; ответ человека 26.10.2026, вопрос 22).
3. ~~Как править заполненный договор.~~ Решено 27.10.2026: заполненный договор правится на внутренней странице «Договор и дополнительные соглашения»; из тайла страницы НКЛ окно открывается только для пустого. Окно, сохранённое с пустыми полями, возвращает договор в «не заполнено».
4. **Проверки полей.** Обязательность и формат номера договора, ограничение длины и допустимый диапазон даты подписания не названы — не проверяются, не решено (27.10.2026). Ошибка «Введите дату в формате ДД.ММ.ГГГГ» — текст прототипа, не из макета.
5. **Бизнес-смысл** — не решено (27.10.2026): зачем бизнесу эти реквизиты и кто ими пользуется, кроме тайла договора.
