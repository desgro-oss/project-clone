# Модальное окно «Баланс и валюта»

## Описание (Purpose)

Артефакт тайла «Баланс и валюта». Не компонент: сам по себе не существует и в плоском списке
витрины его нет — он принадлежит своему тайлу. Заголовок окна — «Баланс и валюта».

Окно решает одну задачу: ввести три значения договора займа ([[НКЛ]]) — баланс, валюту и общую
сумму лимита. «Баланс» и «Валюта» выбираются из списков, «Общая сумма лимита» вводится числом;
код выбранной валюты стоит постфиксом поля суммы. Подпись «лемита» на макете — опечатка,
в прототипе «лимита» (ответ человека 26.10.2026, вопрос 6).

Значения окно не хранит и договор не знает сверх стора: при каждом открытии читает раздел
`balanceCurrency` записи (`LoanAgreementStore.get()`), «Сохранить» зовёт
`LoanAgreementStore.setBalanceCurrency` и закрывает окно; тайл перерисовывает страница по событию
стора (`PostModalBalanceAndCurrency.bind(scrim, { get, save })`, `BalanceAndCurrencyModal.js`).

## Поведение (Behavior)

### Правила полей

1. **Списки.** Значение — только из списка: набранный текст, не совпавший с опцией, при уходе с
   поля откатывается к выбранному; пустой текст снимает значение; крестик очистки снимает
   значение.
2. **Сумма.** Набираются цифры, пробелы и одна запятая (точка становится запятой), остальное
   отбрасывается. При уходе с поля сумма приводится к виду `123 456 789,00` (разряды неразрывным
   пробелом, два знака); нечитаемое очищается. В запись уходит число.
3. **Постфикс суммы** — код выбранной валюты; валюта не выбрана — постфикса нет. Меняется сразу
   по выбору в списке «Валюта».
4. **Сохранить.** Значения читаются из окна (списки сначала принимают набранный текст) и уходят
   в `LoanAgreementStore.setBalanceCurrency`; окно закрывается. Если `LoanAgreementStore.isEditable()`
   возвращает `false` (роль, статус сделки, погашенный договор), запись не делается, окно закрывается. Проверки обязательности нет
   (см. раздел «Обязательность»).
5. **Открытие.** Значения подставляются из записи договора заново при каждом открытии;
   несохранённый ввод прошлого открытия не сохраняется. Крестик и Esc закрывают без сохранения,
   клик мимо окна не закрывает (защиту включает `Modal.js`, потому что в окне поля ввода).
