# Модальное окно «Документы по сделке» (CounterpartiesEcmModal) — журнал изменений

Формат записи: что изменилось · почему · по какому требованию.

## Паспорт — 02.11.2026

**Записан второй вход окна: кнопка «Документы по сделке» тайла «Договор и дополнительные соглашения» (страницы «Договор займа (НКЛ)» и «Договор и дополнительные соглашения»).** Виджет не менялся; правка на стороне страниц — программное открытие теперь сопровождается `__dealEcmApi.refresh()`, и окно не открывается пустым: слушатель клика рисовал карточки только у кнопки с `data-modal`. *Почему:* список участников рисуется при открытии, а кнопка тайла открывает окно событием `loanaction`, без клика по `data-modal`. *Требование:* задача RE0047, решения человека 02.11.2026.

## Паспорт — 23.10.2026

**Паспорт приведён к правилам 2.001.** Добавлен раздел «Бизнес-смысл». Виджет не менялся. *Почему:* в паспорте не было бизнес-контекста — зачем компонент существует, кто и когда его заполняет, кто пользуется результатом, какие правила за ним стоят. *Требование:* задача RE0038, правила ДС «Локальные компоненты» 2.001.

## Паспорт — 02.10.2026

паспорта для всех локальных компонентов — 13 разделов шаблона ДС. *Требование:* задача
RE0004, правила ДС «Локальные компоненты» 2.000.
