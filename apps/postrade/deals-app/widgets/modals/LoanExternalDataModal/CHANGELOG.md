# LoanExternalDataModal — журнал изменений

Формат записи: что изменилось · почему · по какому требованию. Без «почему» правку через
месяц откатывают обратно. Новая запись — сверху.

Правка вида, поведения или состава — новая версия: `## М.ммм — ДД.ММ.ГГГГ`. Правка только
описания версию не меняет — запись без номера: `## Паспорт — ДД.ММ.ГГГГ`. Приведение к
новым правилам ДС — тоже отдельная запись с новой `rulesVersion`.

## 1.001 — 02.11.2026

**Общий компонент, потребители.** Категория витрины «НКЛ» → «Общие»; потребитель «tranche» — плюс
поле «CRM ID продукта» (скрыто по умолчанию, показывает окно); страница со своим источником биндит
окно раньше — `bind(scrim, { get, save, consumer })`, авто-бинд возвращает созданный api.
*Почему:* окно — артефакт общего тайла; на странице транша правка живёт в её сессии, стор НКЛ
задевать нельзя. *Требование:* задача RE0049, решение человека 02.11.2026.

## Паспорт — 27.10.2026

Категория витрины «Сделка» → «НКЛ». *Почему:* виджеты страницы НКЛ собраны в своём разделе витрины. *Требование:* поручение человека 27.10.2026, задача RE0041.

## 1.000 — 26.10.2026

**Компонент создан.** Окно «Техническая информация»: два поля ввода и «Сохранить» (LoanAgreementStore.setTechInfo). *Почему:* правка полей тайла «Техническая информация». *Требование:* задача RE0041, макет дизайнера 26.10.2026.
