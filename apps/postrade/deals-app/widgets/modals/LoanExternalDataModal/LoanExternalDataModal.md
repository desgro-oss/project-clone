# Модальное окно технической информации

## Описание (Purpose)

Артефакт тайла «Техническая информация». Не компонент: сам по себе не существует и принадлежит своему
тайлу. Заголовок окна — «Техническая информация». Поля ввода зависят от потребителя
(решение человека 02.11.2026, RE0049): у НКЛ — «ГФО ID» и «ГФО ID фондирующего кредита»;
у транша — плюс «CRM ID продукта». «Сохранить» справа в подвале.

Окно самодостаточно по умолчанию: при каждом открытии читает
`LoanAgreementStore.get().techInfo` (нет записи — поля пустые), «Сохранить» зовёт
`LoanAgreementStore.setTechInfo` и закрывает окно; тайл перерисовывает страница по событию
стора. Страница со своим источником (страница транша — правка живёт в её сессии, отдельного
стора транша нет) биндит окно раньше — `bind(scrim, { get, save, consumer })`, — и
авто-бинд возвращает уже созданный api. Проверки ввода нет — её никто не называл.

Крестик и Esc закрывают без сохранения; клик мимо окна не закрывает (в окне ввод, триггеры тайла
стоят с `data-modal-guarded`). Крестик очистки в поле рисует рантайм ДС по значению.
