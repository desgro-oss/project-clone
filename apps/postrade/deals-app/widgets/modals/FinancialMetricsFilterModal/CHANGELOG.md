## 0.002 — 21.10.2026

**Окно можно показать на месте, без слоя поверх страницы:** `PostFinMetricsFilter.preview(scrim,
{ title?, indicators, value })`. Поля живые, «Применить» только собирает значение. Для этого сеанс и
заполнение окна вынесены из `open` в общую часть; бейдж на табе ищется по классу `.tab__badge`, а не
по id (в копиях витрины id получают суффикс); номера полей индикаторов общие на скрипт (id не
повторяются между окнами); окно, в которое зашли, становится текущим. Вид и поведение окна на
странице не менялись. *Почему:* этап Э9 задачи RE0033 — сценарий демо витрины
(`FinancialMetricsFilterModal.demo.js`): `open` переносит скрим в `body`, и встроенное в стенд окно
не показать. *Требование:* задача RE0033, этап Э9.

## 0.001 — 21.10.2026

на все вкладки отчёта, данные вкладки ему отдаёт страница. *Требование:* задача RE0033, ответы
человека 20.10.2026 и 21.10.2026 (11, 29, 30).
