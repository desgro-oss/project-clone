# Карточка фиксации ЭПС/ВБС

## Описание (Purpose)

Одна фиксация — одного [[ФИ]]. Карточка — подчасть окна «Фиксация ЭПС/ВБС», отдельно на странице не
стоит. Компонент отдаёт **эталон разметки**: корень фрагмента — `<template id="lc-fixtile-tpl">`,
карточек в окне от одной, а значения у них разные. Скрипт окна клонирует шаблон, подставляет
`{uid}` в `id`, `for` и `data-ddl` (у каждой карточки свои) и привязывает рантаймы ДС.

Слева — ввод: «Наименование ФИ», «Дата изменений», «Тип модификации», «Комментарий»; под ним
«ВБС до фиксации» и кнопка «Предварительный расчет», которую после расчёта заменяет чип «Расчет
выполнен». Справа — результат: блоки «Несущественная модификация» и «Существенная модификация» и
блок ЕТС. «⊖» в углу удаляет карточку; пока она единственная, кнопка выключена.

Карточка — `.tile` из ДС, не `.tile--card`: тот кликабелен и подсвечивается при наведении, а
здесь это форма.

## Поля (Fields)

Поля и их источники — в паспорте окна (`../FixationModal.md`, «Поля»): у карточки своих нет.
Хуки блока ЕТС: `data-fx-ets-icon` — слот иконки статуса (иконку кладёт скрипт окна: у тултипа ДС текст
задаётся при привязке), `data-fx-ets-sk` — скелетон, `data-fx-ets-input` — поле ввода, `data-fx-ets-pencil`
и `data-fx-ets-ok` — карандаш и галочка (недоступная выключена `disabled`). Хуки значений — `data-fx-val="<ключ>"` (`gcaBefore`, `nonGca`, `nonDay1`, `nonShare`, `subGca`,
`subEir`, `subEirDelta`, `etsRate`, `etsDelta`); постфикс — `data-fx-aff="<ключ>"`.

## Права (Permissions)

Режима просмотра у карточки нет: окно с карточками открывается только в правке.

## Состояния (States)

| Состояние | Есть в продукте | Вид |
|---|---|---|
| Загрузка (Loading) | да | данные карточки грузятся; `data-fx-ets="loading"`, в блоке ЕТС скелетоны, `aria-busy` |
| Данные есть | да | значения в блоках, `data-fx-prelim="done"` |
| Заполнено частично | да | ФИ и дата выбраны, расчёта нет: ВБС и ЕТС есть, блоки модификации — прочерк |
| Данных нет (Empty) | да | пустая карточка |
| Ошибка (Error) | да | ошибка поля — красная рамка и тултип; ошибка расчёта — алерт окна |
| Обновление | да | `data-fx-prelim="busy"` |
| Редактирование доступно | да | всегда |
| Только просмотр (Disabled) | нет | — |
| Нет права видеть | нет | — |

### Свои состояния

Атрибуты корня `.lc-fixtile` (ставит скрипт окна):

| Состояние | Когда | Вид |
|---|---|---|
| `data-fx-prelim="idle"` | расчёт не запускали или сброшен | кнопка видна; `disabled`, пока нет ФИ и даты |
| `data-fx-prelim="busy"` | расчёт идёт | лоадер на кнопке, `disabled`, `aria-busy` |
| `data-fx-prelim="done"` | расчёт выполнен | кнопка скрыта (и `disabled`), чип «Расчет выполнен» |
| `data-fx-initial="true"` | тип «Первоначальная» | дата пуста и `disabled` вместе с календарём, предрасчёт `disabled`, значения — прочерк |
| `data-fx-ets="idle" · "loading" · "ok" · "empty" · "error" · "manual"` | ЕТС: нет значения · грузится · есть · нет или 0 · ошибка · введена вручную | скелетоны · значение · прочерк с жёлтой иконкой · прочерк с красной иконкой · значение руками |
| `data-fx-ets-edit="true" · "false"` | идёт ручной ввод ЕТС | вместо значения поле с «%», вместо карандаша галочка |

## Обязательность заполнения (Required)

- Обязательные поля внутри: ФИ, дата (кроме «Первоначальная»), тип.
- Что показывает: красная рамка поля и тултип «Обязательное поле» на фокусе.
- Что отдаёт наружу: состояние карточки читает скрипт окна при сохранении.

## Переполнение (Overflow)

| Случай | Правило |
|---|---|
| Длинный текст в поле | наименование ФИ усекается в поле |
| Много строк или записей | комментарий — многострочное поле на 8 строк, длинный текст прокручивается внутри; ресайза нет |
| Узкая ширина | колонки ввода и результата делят окно 7:5; отдельной перестройки нет — окно фиксированной ширины |
| Полная ширина | как есть |
