# Корректировки процентов РСБУ — журнал изменений

Формат записи: что изменилось · почему · по какому требованию.

## 1.000 — 09.10.2026

Тайл заведён локальным компонентом: разметка вынесена со страницы транша
(`Tranche.html`, прототип `drafts/tranche-page-v02`) в `widgets/tiles/`. Три вида по
данным — «Требуется расчёт» (`locked`), «Корректировки отсутствуют» (`none`),
«Внесено корректировок: N» (`filled`). *Почему:* тайл нужен в витрине и переиспользуется
страницей. *Требование:* решение человека 09.10.2026.

## 1.001 — 09.10.2026

Категория витрины — «Транш» (была «Сделка»); у тайла появился связанный артефакт —
окно внесения корректировки `RsbuAdjustmentModal`, вынесенное со страницы корректировок.
Ссылки тайла в собранной странице ведут на `RsbuInterestAdjustments.preview.html`.
*Почему:* страница вшивает окно меткой `ds-include`, а такой источник открывают через
собранный файл. *Требование:* решение человека 09.10.2026.

## 1.002 — 12.10.2026

Вид тайла разложен на три оси, как у соседних тайлов модуля: данные `data-state`
(`data` · `empty`), права `data-mode` (`edit` · `view`) и условия `data-calc` (`done` ·
`required`). Вместо `data-adjustments` у корня. В режиме `view` кнопки «Внести корректировку»
нет, стрелка на страницу корректировок остаётся. API `render` совместим:
`state: locked|none|filled` раскладывается на оси, добавлено `mode`. *Почему:* конструктор
витрины берёт оси из `[data-state]` и `[data-mode]` в CSS — со своим атрибутом состояний
в нём не было. *Требование:* решение человека 12.10.2026.

## 1.003 — 22.10.2026

Добавлена отметка «Не распределено: <сумма> <валюта>» (Alert warning) под текстом тайла —
показывается при нераспределённой дельте индикатора (RE0034); параметр `unallocated`
у `render`. Число корректировок теперь считает число переносов. *Почему:* человек должен
видеть на транше, что остаток дельты ещё не перенесён. *Требование:* ответы человека 11, 17
(22.10.2026).

## 1.004 — 22.10.2026

Отметка «Не распределено» перенесена из тела тайла в штатный Alert-слот Tile (`.tile__alert` между
шапкой и телом: полноширинный, углы прямые); роль Alert — `alert` / `assertive`, как для warning по
ДС. *Почему:* в теле тайла плашка выглядела карточкой внутри карточки, а ДС предписывает слот.
*Требование:* замечание человека 22.10.2026.

## 1.005 — 22.10.2026

Отметка показывает не «Не распределено: <сумма>», а «Расхождение с ДД.ММ.ГГГГ: <сумма> <валюта>» — дельту
на первой дате расхождения с учётом переносов, со знаком; `opts.unallocated` получил поле `date`.
*Почему:* сумма остатков дельты по датам не имеет смысла, дельта на каждой следующей дате — следствие первой.
*Требование:* ответы человека 22.10.2026 (после Э6), решение агента 24 задачи RE0034.
