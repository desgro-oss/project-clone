# Окно предупреждения при пересчёте метрик

## Описание (Purpose)

Пользователь зафиксировал расчёт начисленных процентов РСБУ, внёс платёж, пересчитал метрики и
переносит дельту по датам на странице корректировок. Если он снова нажал «Пересчитать», а дельта
не обнулилась, окно сообщает о расхождении на первой дате, где оно осталось. Подтвердил — пересчёт идёт,
фиксация снимается, подсветка переносов в отчёте остаётся. Отменил — пересчёта нет, фиксация и
переносы на месте. Алерта на странице и тайле нет — его заменило это окно.

Окно не знает ни стора, ни страницы: дату, сумму, валюту и имя ФИ получает при открытии
(`PostRsbuRecalcWarning.open(info) → Promise<boolean>`, `RsbuRecalcWarningModal.js`), решение отдаёт
вызвавшему. Где окно стоит и когда открывается, решает страница.

## Раскладка (Layout)

```
Modal w4 (заголовок «Пересчитать метрики?», IconButton L «Закрыть»), role=alertdialog
├── тело — один абзац: «Расхождение с <ДД.ММ.ГГГГ> не устранено: <сумма> <валюта> по ФИ <имя>. После
│          пересчёта фиксация расчёта будет снята, расхождение останется в отчёте РСБУ.»
└── подвал: «Отменить» (transparent) · «Пересчитать» (accent)
```

## Поля (Fields)

| Поле | Смысл | Тип, единица | Источник | Обязательное |
|---|---|---|---|---|
| Дата | первая дата, где расхождение осталось | `ДД.ММ.ГГГГ` | `FinMetricsStore.rasUnallocated().date` | да |
| Сумма | дельта на этой дате с учётом переносов, со знаком | число, валюта кодом; в тексте `50 526,30 RUB` | `FinMetricsStore.rasUnallocated().amount` | да |
| Валюта | код валюты ФИ | строка (`RUB`) | `rasUnallocated().currencyCode` | да |
| ФИ | имя ФИ, у индикатора которого расхождение не устранено | строка | карточка ФИ по `rasUnallocated().fiId` | да |

Полей ввода нет: все четыре значения только вписываются в текст.

## Переполнение (Overflow)

| Случай | Правило |

| Полная ширина | — |

## Поведение (Behavior)

| Триггер | Результат |
|---|---|
| «Пересчитать» | окно закрывается с результатом «да», вызвавший запускает пересчёт; после него фиксация снята, переносы закрыты, снек «Фиксация расчёта снята» |
| «Отменить», крестик, Esc | окно закрывается с результатом «нет», пересчёта нет |
| Повторный вызов `open`, пока окно открыто | возвращается тот же Promise, второе окно не открывается |
| Нет метки окна на странице или не подключён рантайм Modal | `open` сразу отдаёт «да» — пересчёт идёт без предупреждения. В прототипе обе страницы метку и скрипт подключают |
