## Описание (Purpose)

История фиксаций ЭПС/ВБС по финансовым инструментам (ФИ) сделки. ЭПС — эффективная процентная
ставка, ВБС — валовая балансовая стоимость; фиксация запоминает их значения на дату изменений
и вид модификации (первоначальная, несущественная, существенная). Карточка «История
фиксаций» с переключателем вида в шапке: «По ФИ» — группа на каждый ФИ (название и валюта), в группе его
фиксации; «По дате» — один плоский список всех фиксаций с колонкой «Наименование ФИ» второй.
Вид по умолчанию — «По ФИ». Фильтра у таблицы нет.

В колонке «№» — порядковый номер строки (ответ 13 задачи): в «По ФИ» внутри группы, в «По дате»
сквозной; номер фиксации ФИ не показывается. Порядок строк по умолчанию — дата изменений по
возрастанию; кнопка сортировки даты в шапке идет по кругу «нет → по возрастанию → по
убыванию → нет» (нет — порядок по умолчанию, то есть возрастание). Сортировка и свернутые группы
запоминаются и не сбрасываются при смене вида.

Удалить можно только последнюю фиксацию ФИ, но корзина стоит у каждой строки и активна у всех,
тултипа у нее нет (ответ 33 задачи). Сам виджет ничего не удаляет: клик по корзине отправляет
событие `fmfixationaction`, а решает страница — у непоследней фиксации показывает снек ошибки, у
последней открывает подтверждение и после него удаляет и показывает тост. Пока идет пересчет
метрик, корзины выключены атрибутом `disabled`; в режиме просмотра колонки «Действия» нет в
разметке вовсе.

Новая строка появляется, когда приходит ответ бэка, вместе со снеком о выполненной фиксации
(ответ 32); виджет перерисовывается целиком из списка, который ему передала страница. Что видно,
пока фиксация считается, — вопрос 2.

Вид («По ФИ» / «По дате») переключает SegmentControl ДС размера XS в действиях шапки карточки
(`tile__actions`). Карточка «История
фиксаций» — содержимое вкладки «Фиксации ЭПС/ВБС» страницы «МСФО · РСБУ · KPI · Фиксации ЭПС/ВБС»;
своих вкладок внутри карточки нет, второй уровень навигации не нужен.

Где виджет стоит на странице и какую высоту ему дает страница — решает страница, не он.

## Поля (Fields)

Фиксации приходят как `EirIbsvFixationRsDto` (`data/mock-fin-metrics-calc.js`) плюс три поля,
которые добавляет `FinMetricsStore.fixations()`. Порядок строк — порядок колонок:

| Поле | Смысл | Тип, единица | Источник | Обязательное |
|---|---|---|---|---|
| — («№») | порядковый номер строки в группе («По ФИ») или в списке («По дате») | целое, считает виджет | порядок после сортировки | да |
| `fiName` + `currencyCode` | название ФИ и валюта: в строке группы («По ФИ») и в колонке «Наименование ФИ» («По дате»; в ячейке — название и валюта) | текст, код валюты | `FinMetricsStore.fixations()` (карточка ФИ сделки) | да |
| `changeDate` | дата изменений | ISO-дата, показывается `ДД.ММ.ГГГГ` | `EirIbsvFixationRsDto` | да |
| `eirRate` | значение ЭПС | число, % | `EirIbsvFixationRsDto` | нет — прочерка нет, ячейка пустая |
| `eirDelta` | Δ ЭПС | число со знаком, %; «+» зеленым, «−» красным, 0 — без цвета | `EirIbsvFixationRsDto` | нет — у первоначальной фиксации пусто |
| `etsRate` | значение ЕТС | число, % | `EirIbsvFixationRsDto` | нет |
| `etsDelta` | Δ ЕТС | число со знаком, %; цвета как у Δ ЭПС | `EirIbsvFixationRsDto` | нет |
| `grossCarryingAmount` | ВБС на дату фиксации | число, в валюте ФИ | `EirIbsvFixationRsDto` | нет |
| `grossCarryingImpactRate` | влияние на ВБС | число со знаком, % | `EirIbsvFixationRsDto` | нет |
| `day1PnlAmount` | Day1PnL | число со знаком, в валюте ФИ | `EirIbsvFixationRsDto` | нет |
| `modificationTypeCode` | вид модификации: «Первоначальная», «Несущественная», «Существенная» | `INITIAL` · `NON_SUBSTANTIAL` · `SUBSTANTIAL` | `EirIbsvFixationRsDto`, подписи — `FIN_METRICS_LABELS.modification` | да |
| `comment` | комментарий | текст | `EirIbsvFixationRsDto` | нет |
| `fixationId` | идентификатор; уходит в событие корзины и в `data-fixation-id` | строка | `EirIbsvFixationRsDto` | да |
| `data-view` на корне | текущий вид | `BY_FI` · `BY_DATE` | скрипт, по умолчанию `BY_FI` | да |

Числа — с запятой и неразрывным пробелом между разрядами (`1 500 000,00`; решение агента 8
задачи). Валюта в колонках «в валюте» не повторяется: она в строке группы и в колонке
«Наименование ФИ».

## Поведение (Behavior)

| Триггер | Результат |
|---|---|
| Клик по сегменту переключателя или стрелки, Home / End на нём | `data-view` корня меняется, таблица перерисовывается; к странице виджет не обращается. Сортировка и свернутые группы сохраняются |
| Клик по кнопке сортировки «Дата изменений» | рантайм ДС красит кнопку и шлет `sort`; виджет по нему сам переставляет строки (внутри групп — в дереве `data-sort-rows` ДС переставляет только корни) и считает «№» заново. Круг: нет → по возрастанию → по убыванию → нет |
| Клик по значку группы | группа сворачивается и разворачивается (рантайм ДС) |
| Клик по корзине | с корня уходит `fmfixationaction` с `detail: { action: 'REMOVE', fixationId }`; виджет сам ничего не удаляет. У корзины с `disabled` события нет |
| `render(root, fixations, { mode, busy })` | запоминает список и режим на корне, ставит `data-state`, `data-mode`, `data-busy` и перерисовывает таблицу; вид, сортировка и свернутые группы не сбрасываются |

## Открытые вопросы (Open questions)

Решение человека 29.09.2026: вопросы не закрываются догадкой и не удаляются, пока человек не
разберёт каждый; ответ записывается у вопроса с датой. Вопросы 1–2 перенесены из задачи RE0033
(`docs/tasks/RE0033-deal-financial-metrics.md`, вопросы 19 и 32).

1. **Права** (RE0033, вопрос 19): кто фиксирует, удаляет фиксацию, выгружает отчет — оставлено
   открытым (21.10.2026). В прототипе (допущение 21.10.2026): удалять может тот, кто может
   править сделку по статусу, и роль с правом на расчет; иначе `view` без колонки «Действия»
   (на странице — сценарий панели `?fmMode=view`).
2. **Что видно, пока фиксация считается, и при ошибке расчета** (RE0033, вопрос 32): строка
   появляется, когда приходит ответ бэка, вместе с зеленым снеком о выполненной фиксации
   (ответ 21.10.2026); что видно, пока расчет идет (скелетон строки, отдельное состояние
   таблицы, ничего), и что при ошибке «Расчет фиксации ЭПС/ВБС не выполнен» — оставлено
   открытым. В прототипе сейчас: строка появляется по ответу расчёта фиксации (окно собрано в Э6),
   промежуточного вида нет; вид ошибки получения истории не нарисован.
3. **Что такое «последняя» фиксация.** В прототипе — с самой поздней датой изменений у ФИ
   (допущение 21.10.2026). Не решено: что при равных датах, считает ли признак бэкенд или
   клиент, можно ли удалить последнюю фиксацию «Первоначальная», если по ФИ нет других.
4. **Первый клик по сортировке даты.** По умолчанию строки идут по возрастанию, а кнопка в
   состоянии «нет» (так ведет себя рантайм ДС: нет → по возрастанию → по убыванию → нет), поэтому
   первый клик строки не меняет. Допущение 21.10.2026 по заданию; альтернатива — стартовать с
   «по возрастанию»; нужен ли ответ человека — не решено.
5. **Что меняется после удаления фиксации.** В прототипе из отчетов МСФО, РСБУ и KPI уходит
   колонка даты этой фиксации, если на нее нет другого события (так строит даты мок); пересчет
   метрик не запускается и не требуется. Не решено: влияет ли удаление на значения отчетов и
   метрик, нужен ли пересчет, как это видит пользователь.
6. **Колонка «Комментарий», ширины колонок, единицы значений** (проценты — число без знака
   «%», суммы — без кода валюты) и **длинные значения** — по макету не уточнены; ширины
   колонок в прототипе — допущение 21.10.2026, определяются по размеру заголовков и значений.
7. **Счетчики у сегментов переключателя** («По ФИ» · «По дате») — на макете нет, в прототипе нет; нужны ли
   (например, число ФИ или фиксаций) — не решено (21.10.2026).
8. **Вид по умолчанию и его запоминание.** По умолчанию — «По ФИ» (первая на макете;
   допущение 21.10.2026). Запоминается ли выбор между заходами — не решено.
9. **Закрепление первой колонки, настройка таблицы, ошибка получения истории** — те же вопросы,
   что у `FinancialMetricsTable` (паспорт, «Открытые вопросы»); отдельных ответов для истории
   фиксаций нет (21.10.2026). Закрепленных колонок в прототипе нет: таблица шире экрана
   прокручивается целиком.
