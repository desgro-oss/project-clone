# Фильтр корректировок РСБУ

## Описание (Purpose)

Окно «Фильтр» страницы «Корректировки процентов РСБУ»: открывается кнопкой «Фильтр»
(TableFilter) над таблицей и сужает список корректировок по четырём группам — исходная
дата, целевая дата корректировки, сумма корректировки, наличие комментария. Окно —
связанный артефакт таблицы: кнопка и чип «Применено: N» стоят на странице, не в окне.

Устройство — штатная модалка фильтра ДС (`.modal--w6.tfm`): слева вертикальный таб-раздел
«Корректировки» со счётчиком заполненных групп, справа раздел «Корректировки» с сеткой
полей. Раздел один; заголовок раздела совпадает с подписью таба (правило ДС TableFilter).

## Бизнес-смысл (Business context)

| Вопрос | Ответ |
|---|---|
| Зачем существует | корректировок бывает много (пересчёты накапливаются), а удалить нужно партию одного пересчёта или период: фильтр отбирает строки по исходной дате (отчётный период), целевой дате корректировки (партия пересчёта), сумме и наличию комментария |
| Кто пользуется | сотрудники [[Operations]] (финансисты ДИД) — те же, кто пересчитывает платежи и удаляет корректировки (ответ человека 05.11.2026) |
| Бизнес-правила | фильтр только сужает вид и не меняет данные; пустая группа не ограничивает; «Применено: N» считает заполненные группы, а не отдельные поля пары «От/До» |

Источник: ответы человека 05.11.2026 (вторая волна), задача RE0050.

## Поля (Fields)

| Поле | Ключ | Смысл | Тип, единица | Обязательное |
|---|---|---|---|---|
| Исходная дата, от | `startFrom` | нижняя граница закрытой даты | дата ISO | нет |
| Исходная дата, до | `startTo` | верхняя граница закрытой даты | дата ISO | нет |
| Целевая дата корректировки, от | `targetFrom` | нижняя граница даты переноса | дата ISO | нет |
| Целевая дата корректировки, до | `targetTo` | верхняя граница даты переноса | дата ISO | нет |
| Сумма корректировки, от | `amountFrom` | нижняя граница общей суммы | число | нет |
| Сумма корректировки, до | `amountTo` | верхняя граница общей суммы | число | нет |
| Только с комментарием | `onlyCommented` | оставить строки с непустым комментарием | флажок | нет |

Пустое поле — граница не задана. Пара «От/До» считается одной группой: заполнено хотя бы
одно — группа активна.

### Свои состояния

| Состояние | Когда | Вид |
|---|---|---|

| Фильтр заполнен | заполнена хотя бы одна группа | значения в полях, «Очистить фильтр» активна, бейдж показывает число групп |

## Обязательность заполнения (Required)

- Компонент обязателен к заполнению целиком: нет.
- Обязательные поля внутри: нет.
- Что показывает, когда обязательное не заполнено: не применимо.
- Что отдаёт наружу: значение фильтра; пустой фильтр — все поля пусты.

## Переполнение (Overflow)

| Случай | Правило |
|---|---|
| Длинные значения | поля ввода растягиваются по сетке `.tfm__grid`; числа не переносятся |
| Узкая ширина | окно `modal--w6`; поля занимают всю ширину (`tfm__span-2`) |
| Много полей | раздел один; при добавлении групп — новая секция таба |

## Поведение (Behavior)

| Триггер | Результат |
|---|---|
| «Фильтр» на странице | окно открывается с текущим фильтром |
| «Применить» | окно закрывается, отдаёт значение; страница фильтрует строки и рисует чип «Применено: N» |
| «Очистить фильтр» | поля окна сбрасываются, окно остаётся открытым; «Применить» после него очищает фильтр страницы |
| Крестик, Esc | окно закрывается без применения; значение страницы не меняется |
| Клик по скриму | окно не закрывает — у полей ввода включается защита ДС (guarded-режим) |
| Ввод в поле | бейдж и доступность «Очистить фильтр» обновляются сразу |

## Осознанные отклонения (Deviations)

- Фильтр по двум датам, а не по одной: ответ человека 05.11.2026 — отбирать и отчётный период
  (исходная дата), и партию пересчёта (целевая дата корректировки).
- Наличие комментария — флажок «Только с комментарием», а не выбор «Есть/Нет»: в фильтре
  достаточно отобрать строки с комментарием; обратный отбор не запрашивался.
