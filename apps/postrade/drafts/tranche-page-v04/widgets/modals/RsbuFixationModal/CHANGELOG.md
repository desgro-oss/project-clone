# Окно «Пересчет с фиксацией» (RsbuFixationModal) — журнал изменений

Формат записи: что изменилось · почему · по какому требованию.

## 1.103 — 05.11.2026

Целевая дата корректировки больше не подставляется: при вводе «До» она остаётся пустой, человек
вводит её вручную. Пустое поле «Комментарий» оставляет ячейку комментария в таблице пустой — текст
«Пересчёт процентных платежей» не подставляется. *Почему:* правки человека 05.11.2026 в спеке на
разработку. *Требование:* задача RE0050.

## 1.102 — 05.11.2026

Добавлено необязательное поле «Комментарий»: его текст попадает во все корректировки, созданные
после этого пересчёта; пустое поле даёт прежний «Пересчёт процентных платежей». Окно открывается
и без привязки транша к ФИ — корректировки создаются по траншу. *Почему:* ответы человека
05.11.2026 (вторая волна). *Требование:* задача RE0050.

## 1.101 — 05.11.2026

Поле «Дата корректировки» переименовано в «Целевую дату корректировки» — одна и та же дата во всех
местах называется одинаково. Без ФИ кнопка «Пересчитать с фиксацией» на тайле видна, но
заблокирована; окно в этом состоянии не открывается. Роль окна — operations (финансист ДИД).
*Почему:* ответы человека 05.11.2026 о названии даты, ролях и кнопке без ФИ. *Требование:* задача
RE0050, решения человека 05.11.2026.

## 1.100 — 03.11.2026

Окно стало операцией «Пересчет с фиксацией»: заголовок и кнопка подвала «Пересчитать» (была
«Сохранить»), «Дата фиксации» заменена «Периодом фиксации» — InputDateRange (От/До); дата
корректировки по умолчанию — первое число месяца после конца периода. Окно всегда открывается
пустым: подтверждение сразу запускает пересчёт с созданием корректировок из дельт дат периода.
*Почему:* фиксация и пересчёт платежей слиты в одну операцию — пересчитывается весь срок
отчётности, а значения зафиксированного периода возвращаются корректировками на дату
корректировки. *Требование:* решения человека 03.11.2026, задача RE0050.

## 1.000 — 28.10.2026

Окно заведено в концепте `tranche-page-v04`: две даты — «Дата фиксации» и «Дата корректировки»
(InputDate с календарём), «Отменить» и «Сохранить»; дата корректировки по умолчанию — первое число
месяца после даты фиксации; проверка дат правилами страницы, ошибка — Alert вверху окна. *Почему:*
фиксация РСБУ переехала со страницы отчётов на тайл «Процентные платежи» транша. *Требование:*
решения человека 28.10.2026, задача RE0034 (концепт v4).
