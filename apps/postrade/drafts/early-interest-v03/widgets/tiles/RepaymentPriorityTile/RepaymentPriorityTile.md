# Приоритет погашения

## Описание (Purpose)

Тайл страницы «Досрочное погашение процентов». Сумма досрочного платежа гасит задолженность
по видам в заданном порядке: сначала весь вид с приоритетом 1, остаток — вид с приоритетом 2 и
далее. Видов три: текущие, капитализированные и отложенные начисленные проценты;
по умолчанию они стоят именно в таком порядке. Приоритет один на весь инструмент. Тайл горизонтальный
(стоит над таблицей) и показывает все три вида в ряд: Entity как в v2 — номер приоритета в сером
квадрате и название, без пояснений. Перестановка — в окне «Приоритет погашения», которое
открывает карандаш в шапке (только с правом редактирования).

## Раскладка (Layout)

```
Tile (заголовок «Приоритет погашения»)
├── шапка: IconButton edit «Изменить приоритет погашения» (только data-mode="edit")
└── тело
    └── ряд Entity S по горизонтали: номер приоритета в квадрате (entity__icon--neutral) + название вида
```

## Переполнение (Overflow)

| Случай | Правило |
|---|---|
| Длинный текст в поле | Название переносится на следующую строку внутри своей колонки, номер остаётся по центру высоты строки |
| Много строк или записей | Показываются все виды; колонок в ряду столько, сколько видов |
| Узкая ширина | Названия переносятся |
| Ширина 6 колонок и больше | Без изменений |

## Поведение (Behavior)

- Карандаш «Изменить приоритет погашения» → окно «Приоритет погашения» с перестановкой.
- После «Сохранить» в окне → список показывает новый порядок, страница показывает тост «Приоритет погашения изменен».
