1. Назначение

Бизнес-смысл

Вопрос
Ответ
Зачем существует
Вести расчет FV на дату по ФИ: статусы, значения и файлы инструментов. Отсюда расчет отправляют в LP, обновляют, пересчитывают, утверждают, выгружают в XML и xlsx и правят отдельные ФИ
Кто заполняет и когда
Пользователи двух ролей приходят из реестра расчетов FV: расчет в статусе «Формируется» открыть нельзя, только после «Сформирован». «Финансист и другие» выполняют все действия, кроме «Утвердить»; «Риск-менеджер» — все и «Утвердить». Данные ФИ правят вручную в любом статусе расчета. Права ролей на остальные действия — не решено (08.10.2026)
Кто пользуется результатом
LP получает отправленные ФИ и возвращает расчет; риск-менеджер утверждает рассчитанный расчет; получатели выгруженных файлов XML и xlsx (в сети с шифрованием — выбранные сотрудники). Другие читатели расчета — не решено (23.10.2026)
Бизнес-правила
Статусы расчета: Формируется → Сформирован → Отправлен в LP → Рассчитывается LP → Рассчитан или Ошибка → Утвержден. «Отправить в LP» отправляет только ФИ «Сформирован» с отметкой «Передавать в LP»; нет таких — кнопка выключена; у «Рассчитан» повторная отправка разрешена; у «Ошибка» кнопки нет, сначала «Пересчитать». «Обновить» добавляет ФИ, созданные после последнего расчета, в статусе «Сформирован», текущие не меняются. «Пересчитать» заново считает весь расчет: «Формируется», затем «Сформирован». «Утвердить» — только риск-менеджер и только в «Рассчитан». У ФИ статус «Ошибка», если хоть один его инструмент «Возвращен из LP» или «Ошибка». Правка ФИ доступна в любом статусе; меняется ли при этом статус самого расчета в «Рассчитан» и «Утвержден» — не решено (08.10.2026). Матрица «статус × роль → действия» — одна, в словаре данных

Расчет FV на дату: таблица ФИ с их статусами, значениями и файлами инструментов; кнопки шапки и меню «⋮» зависят от статуса расчета и роли (§6). Попадают сюда из реестра расчетов FV двойным кликом по строке.

Роль пользователя: «Финансист и другие» и «Риск-менеджер». Риск-менеджеру дополнительно доступна кнопка «Утвердить». Права: остальные действия одинаковы для обеих ролей — не решено (08.10.2026).

2. Адрес и навигация

  • Адрес в продукте: не решено (08.10.2026).
  • Параметры демо: ?upload=fail — загрузка файла инструмента не удаётся (Alert «Не удалось загрузить файл» в окне ФИ); ?net=sigma — сеть Сигма, выгрузка с шифрованием (по умолчанию сеть Альфа, без шифрования); ?download=fail — выгрузка не удаётся (снекбар для расчета, алерт в окне ФИ для файла инструмента); ?id=<номер расчета> — расчет из реестра; ?status=<код> — принудительный статус расчета (FORMING, FORMED, SENT_TO_LP, CALCULATING_LP, CALCULATED, ERROR, APPROVED); ?role=<FINANCIER|RISK_MANAGER>. Без них статус берётся из расчета, роль — финансист. Чип статуса в шапке («Отправлен в LP», «Рассчитывается LP»)
демо-триггер: имитирует ответ LP. «Отправлен в LP» → «Рассчитывается LP» → «Рассчитан» (ФИ и инструменты из отправки двигаются вместе, у «Рассчитан» появляются суммы FV). Чип фокусируется и срабатывает по клику, Enter и пробелу; тултип объясняет, что это демо
«Отправить в LP»
окно «Отправка данных в Loan Pricing»; после «Подтвердить» ФИ «Сформирован» с отметкой «Передавать в LP» → «Отправлен в LP», расчет → «Отправлен в LP»; нет таких ФИ — снекбар «Нет данных для отправки в LP»
«Утвердить»
окно «Утверждение расчета FV на ДД.ММ.ГГГГ»; после «Подтвердить» расчет → «Утвержден»
«⋮» → «Обновить»
окно «Обновление данных расчета…»; новые ФИ придут «Сформирован», текущие не меняются; в демо новых ФИ нет — снекбар «Расчет обновлен»
«⋮» → «Пересчитать»
окно «Пересчет расчета…»; все ФИ и инструменты → «Сформирован», расчет → «Формируется», через 2 с (прототип) → «Сформирован»
«⋮» → «Выгрузить в XML / xlsx»
DownloadReportModal: сеть Сигма — окно «Выгрузка расчета на ДД.ММ.ГГГГ» с выбором сотрудников и «Выгрузить»; сеть Альфа — «Подтверждение действия» с «Подтвердить». Ошибка (?download=fail) — снекбар «Не удалось выгрузить файл»
Чекбоксы строк
над пагинацией появляется панель «Выбрано строк: N» с кнопками: «Пересчитать», «Передавать в LP», «Не передавать в LP» (в «Утвержден» — только «Пересчитать»; в «Формируется» кнопки выключены)
«Пересчитать» в панели или в строке
окно «Пересчет выбранных ФИ» / «Пересчет ФИ «…»»; расчет → «Формируется», затем «Сформирован»
«Передавать в LP» / «Не передавать в LP»
окно подтверждения «Включение / Отключение передачи в LP для выбранных ФИ.»; после «Подтвердить» меняется колонка «Передавать в LP» у выбранных строк
Двойной клик по строке, клик по наименованию ФИ или по «Редактировать ФИ»
открывается FairValueUserMetricsModal (правка доступна в любом статусе расчета). После «Сохранить» с подтверждением или действия над файлом инструмента строка таблицы перерисовывается, выбор строк и шапка сохраняются
Выгрузка шаблона файла инструмента в окне ФИ
DownloadReportModal в виде «Подтверждение действия» (как окно без шифрования, сеть не важна), вложенным слоем поверх окна ФИ; ошибка (?download=fail) — Alert «Не удалось выгрузить файл» в окне ФИ
«Фильтр» → «Применить»
выборка по заполненным полям, чип «Применено: N»
Крестик на чипе «Применено» или «Очистить фильтр»
фильтр сбрасывается целиком
«Настроить колонки» (шестерёнка справа в тулбаре)
стандартное окно ДС «Настройка таблицы»: видимость, порядок и закрепление колонок; перерисованные строки повторяют текущую шапку
Клик по «Сортировать»
сортировка по колонке, страница сбрасывается на первую

8. Состояния

Loading

Не решено (08.10.2026): в прототипе данные есть сразу. Статус «Формируется» — отдельное состояние: кнопки и меню выключены.

Empty

После «Применить» без совпадений — EmptyState «ФИ не найдены» с кнопкой «Очистить фильтр». Расчет без ФИ в макетах не нарисован — не решено (08.10.2026). У ФИ без инструментов окно ФИ показывает в таблице строку «Нет данных».

Error

Ошибка выгрузки всего расчета — снекбар «Не удалось выгрузить файл», файла инструмента — Alert в окне ФИ. «Нет данных для отправки в LP» — снекбар. ФИ с ошибкой — статус «Ошибка» в строке.

Disabled

Статус «Формируется»: «Пересчитать» в строках и панели, меню «⋮» и «Отправить в LP» выключены.
