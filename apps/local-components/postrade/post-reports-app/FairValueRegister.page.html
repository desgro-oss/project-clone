1. Назначение

Бизнес-смысл

Вопрос
Ответ
Зачем существует
Вести список расчетов FV по датам: отсюда формируют новый расчет, загружают файлы FV и компонентов FV и переходят на страницу расчета
Кто заполняет и когда
Пользователи обеих ролей, «Финансист и другие» и «Риск-менеджер», приходят сюда с плитки «Расчет FV» на главной. Расчет создают кнопкой «Новый расчет», указав дату; дальше его статус меняется на странице расчета. Права ролей на формирование расчета и загрузку файлов — не решено (08.10.2026)
Кто пользуется результатом
Обе роли, реестр для них одинаков: двойным кликом по строке открывают страницу расчета. У расчета «Формируется» переход закрыт, открыть можно после «Сформирован»
Бизнес-правила
Статусы расчета: Формируется → Сформирован → Отправлен в LP → Рассчитывается LP → Рассчитан или Ошибка → Утвержден; везде «Утвержден», не «Утвержден РМ». Сумма FV есть только у «Рассчитан» и «Утвержден». Расчет на одну дату один: на существующую дату он не формируется, пересчет делают в открытом расчете. Загрузка FV и компонентов FV — альтернатива «Новому расчету»; к какому расчету она привязана — не решено, рисуем только интерфейс (решение человека 08.10.2026). Создается ли расчет на дату или на конец месяца — не решено (08.10.2026)

6. Поведение

Триггер
Результат
Клик «Новый расчет»
открывается CreateFairValueCalculationModal, поле даты пустое
«Сформировать» с новой датой
окно закрывается, строка появляется сверху со статусом «Формируется»; через 2 с (в прототипе) — «Сформирован»
«Сформировать» с датой, на которую расчет есть
окно остаётся открытым, над телом Alert «Не удалось сформировать расчет»
Меню «⋮» → «Загрузить FV» / «Загрузить компоненты FV»
открывается заглушка системного выбора файла (upload-stub-scrim); «Выбрать файл» закрывает её и открывает ReservesFvModal / ReservesFvComponentsModal с предпросмотром; «Отмена» предпросмотр не открывает
«Выбрать файл» при ошибке файла (демо ?file=format|empty|structure|size)
окно предпросмотра не открывается, показывается снекбар с ошибкой: неверный формат, пустой файл, нет обязательных колонок, слишком большой файл
Клик по «Фильтр»
открывается окно фильтра
«Применить»
выборка по заполненным полям, чип «Применено: N», страница сбрасывается на первую
Крестик на чипе «Применено» или «Очистить фильтр»
фильтр сбрасывается целиком
Двойной клик по строке (номер — не ссылка)
страница расчета FairValueCalculation.html?id=<номер> ; у расчета в статусе «Формируется» переход закрыт — открыть можно после «Сформирован»

Счётчик раздела «Основная информация» и чип «Применено» считают заполненные поля: пара «От/До» — одно поле диапазона (вопрос 8 — «9» на макете признано ошибкой).
