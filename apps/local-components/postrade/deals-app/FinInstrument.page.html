1. Назначение

Бизнес-смысл

Вопрос
Ответ
Зачем существует
Показать один ФИ сделки целиком: данные по ФИ, прикреплённые инструменты дерева продуктов, идентификаторы (номера договоров 1С и 1С:УХ, ID аккредитива и счёта эскроу, Murex ID ПФИ, коды для RWA) и переходы в подразделы «Корректировки KPI», «Дефолтные сделки», «Счета для 1С»
Кто заполняет и когда
Финансист ДИД правит данные ФИ окном изменения ФИ (карандаш «Данные по ФИ»); карточку ФИ создают на странице сделки, в тайле «Финансовые инструменты». Кто и когда заполняет идентификаторы и подразделы — не решено (23.10.2026): значения этих блоков — рыба
Кто пользуется результатом
Финансист ДИД; права как на странице сделки. Другие читатели страницы — не решено (23.10.2026): состояния и права по ролям не прорабатывались
Бизнес-правила
Баланс, валюта, сумма, дата подписания, список инструментов и погашение ФИ считаются из узлов дерева продуктов сделки, прикреплённых к карточке ФИ (решение человека 02.10.2026). «Требуется переоценка» — признак-категория ФИ, показывается чипом в шапке блока «Данные по ФИ». Что открывают стрелки подразделов и кнопка «Ещё действия» — не решено (23.10.2026), макет не говорит

Страница одного финансового инструмента сделки: данные по ФИ, прикреплённые инструменты дерева продуктов, идентификаторы и переходы в подразделы. Пользователь попадает сюда стрелкой «→» в шапке карточки ФИ на странице сделки и возвращается кнопкой «В сделку».

Собрана по макету, без локальных компонентов: тайлы собраны прямо на странице из компонентов ДС и помечены Chip «Demo» в шапке. Локальные компоненты — следующий шаг (решение человека 09.10.2026).

Роль пользователя: финансист ДИД Права: как на странице сделки; правка данных ФИ — окном изменения ФИ.

6. Состояния

Состояния данных не прорабатывались: страница показывает данные сразу после загрузки сторов. Нет карточки — пустой каркас. Незаполненные значения — прочерк —. Загрузка, ошибка и права по ролям — следующий шаг вместе с локальными компонентами.
