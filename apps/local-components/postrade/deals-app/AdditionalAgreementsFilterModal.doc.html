Описание

Артефакт кнопки «Фильтр» (ДС-списка страницы «Договор и дополнительные соглашения»). Не компонент: сам по себе не существует и в плоском списке витрины его нет. Заголовок окна — «Фильтр». Кнопка «Фильтр» (TableFilter) и чип «Применено: N» стоят на странице, в окне их нет.

Окно — штатная модалка фильтра ДС: слева вертикальное меню разделов «Основная информация» и «Решение» со счётчиками заполненных полей, справа оба раздела подряд (клик по пункту меню доводит до раздела). В разделе «Основная информация» — номер соглашения, дата подписания (диапазон), тип изменения, ключевые изменения; в разделе «Решение» — номер решения, дата решения (диапазон), уровень одобрения.

Окно не читает стор. Страница при каждом открытии отдаёт текущий применённый фильтр (open(currentFilter)), окно заполняется им; «Сохранить» проверяет формат дат, закрывает окно и отдаёт новый фильтр событием agreementsfilter на document. Стор фильтрует список по этому фильтру (формат — аргумент LoanAgreementStore.agreements()), а число заполненных полей страница показывает чипом «Применено: N».

«Очистить фильтр» очищает только поля окна: окно остаётся открытым, счётчики обнуляются, фильтр не применяется — он меняется только по «Сохранить». Так же устроено окно фильтра FinancialMetricsFilterModal.

Все состояния рядом

Каждая комбинация состояния данных и режима прав — копия фрагмента виджета.

Обязательность заполнения

  • Компонент обязателен к заполнению целиком: нет. Пустой фильтр ({}) допустим: он показывает все ДС.
  • Обязательные поля внутри: нет (ответ человека 26.10.2026, вопрос 28: проверяется только формат дат).
  • Что показывает, когда обязательное не заполнено: не применимо.
  • Что отдаёт наружу (признак для экрана или формы): событие agreementsfilter с detail { filter, count }.

Открытые вопросы

  1. Справочники «Тип изменения», «Ключевые изменения», «Уровень одобрения» неполные: в окне только значения со скринов (ответ человека 26.10.2026, вопрос 12) — не решено (27.10.2026), какие значения есть на самом деле. Окно строит опции из глобалов при привязке; когда справочник изменится — изменится только data/mock-loan-agreements.js.
  2. Состояний «Загрузка» и «Ошибка загрузки» нет: у окна нет сети, на макете их нет. Не решено (27.10.2026), нужны ли они, когда справочники придут от бэкенда.
  3.
