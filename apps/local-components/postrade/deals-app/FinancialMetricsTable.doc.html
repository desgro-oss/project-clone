Описание

Отчет финансовых метрик (МСФО или РСБУ) по финансовым инструментам (ФИ) сделки: по каждому рассчитанному ФИ — группа строк-метрик, по колонкам — даты, в которые у какого-либо ФИ сделки есть финансовое событие (выдача, погашение, начисление процентов, фиксация ЭПС/ВБС и т. п.). Даты общие для всех ФИ отчета, группы прокручиваются вместе — одна таблица на отчет; у ФИ без события на дату ячейка пустая (ответ человека 20.10.2026, вопрос 10 задачи RE0033). ФИ, который не удалось рассчитать, в отчете не появляется (вопрос 4 задачи).

Виджет вшивается на страницу дважды: на вкладку «МСФО» и на вкладку «РСБУ». Какой это отчет, знает не виджет, а данные: страница передает готовый отчет — FinMetricsReportRsDto с кодом IFRS или RAS. Сам виджет не читает стор.

Над таблицей — тулбар: кнопка «Фильтр» (TableFilter) и, если фильтр применен, один чип «Применено: N», где N — число ФИ, выбранных в фильтре. Окно фильтра виджет не открывает: кнопка шлет событие, окно открывает страница. Чиплиста параметров и «+N» нет — на макете устаревший вариант (ответ 30 задачи).

Отчет пуст, когда в нем нет ни одной группы (например, у ФИ нет отчётности РСБУ): колонок дат и шапки нет, по центру «Нет данных», кнопка «Фильтр» заблокирована (ответ 28 задачи).

ЭПС — эффективная процентная ставка, ВБС — валовая балансовая стоимость; в самой таблице этих сокращений нет.

Где виджет стоит на странице, какую высоту ему дает страница и сколько колонок он занимает — решает страница, не он.

Все состояния рядом

Каждая комбинация состояния данных и режима прав — копия фрагмента виджета.

Обязательность заполнения

  • Компонент обязателен к заполнению целиком: нет — он показывает данные, ничего не заполняет.
  • Обязательные поля внутри: Не применимо — в отчете нет полей ввода.
  • Что показывает, когда обязательное не заполнено: Не применимо.
  • Что отдаёт наружу (признак для экрана или формы): события fmtableaction и fmtablefilterreset (см. «Поведение»); признака для формы нет.

Применение фильтра

Фильтр применяет сам виджет, в render; страница хранит значение и перерисовывает. Пустой отчет определяется по report.groups.length === 0, а не по результату фильтра: если фильтр скрыл все группы непустого отчета, «Нет данных» показывается, но «Фильтр» остается доступным.

Данные

API — что нужно от бэкенда

Отчет по коду IFRS или RAS целиком: даты событий всех ФИ и по каждому рассчитанному ФИ — метрики со значениями по датам (поля — раздел «Поля»). Нерассчитанный ФИ в отчет не входит. Состав метрик по типам ФИ, единицы метрик и периодичность дат — не решено (см. «Открытые вопросы»). Имена методов API не придумываются: их выбирает разработка.
