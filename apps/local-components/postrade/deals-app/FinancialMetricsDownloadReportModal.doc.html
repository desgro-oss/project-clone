Выгрузка отчета

Вы выгружаете документ, содержащий данные К2

Нажимая кнопку «Выгрузить», вы подтверждаете, что осведомлены о следующих ограничениях:

  • данные только для внутреннего использования;
  • данные необходимо использовать строго в соответствии с бизнес-процессом;
  • данные нельзя передавать лицам, не задействованным в бизнес-процессе.

Информация о выгрузке документа будет зафиксирована и направлена в службу безопасности.

Выберите сотрудников, которым будет доступен файл после его создания. Данный файл будет доступен для работы в доменах Сигма и Альфа/Омега только у указанных ниже сотрудников. Если вы добавили сотрудника по e-mail, то файл будет доступен только в том домене, которому соответствует e-mail.

Описание

Окно перед скачиванием файла XLSX со всем отчётом финансовых метрик сделки (МСФО, РСБУ, KPI и фиксации ЭПС/ВБС): файл содержит данные К2, поэтому окно предупреждает об ограничениях и просит подтвердить выгрузку. Открывается пунктом «Выгрузить в XLSX» кебаба над вкладками страницы: кебаб стоит выше вкладок и вкладками не управляется, поэтому окно одно на всю страницу и не знает, какая вкладка открыта (ответ 12).

Вид окна зависит от сети, из которой открыта страница (ответ 21, как в расчёте FV, RE0012):

  • Сигма — сеть банка с выходом в интернет: файл шифруется, окно просит выбрать сотрудников, которым он будет доступен;
  • Альфа / Омега — внутренние сети без интернета: шифрования нет, окно только предупреждает.

В продукте сеть определяется по логину (на каждую сеть свой логин). В прототипе её переключает адрес страницы: по умолчанию Альфа, ?net=sigma — Сигма.

Заголовок и пара кнопок «Отменить» / «Выгрузить» у обоих видов одинаковые, вид с шифрованием отличается только блоком выбора сотрудников (ответ 31, решение агента 11).

Все состояния рядом

Каждая комбинация состояния данных и режима прав — копия фрагмента виджета.

Обязательность заполнения

  • Компонент обязателен к заполнению целиком: нет — вид без шифрования не требует ничего; вид с шифрованием требует хотя бы одного отмеченного получателя.
  • Обязательные поля внутри: нет, см. «Поля».
  • Что показывает, когда обязательное не заполнено: «Выгрузить» выключена, текста ошибки нет.
  • Что отдаёт наружу (признак для экрана или формы): opts.run(ctx, recipients) — контекст, переданный в api.open, и отмеченные получатели (в виде без шифрования — пустой список).
