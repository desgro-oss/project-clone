Описание

Окно с данными фонда — второй шаг добавления фонда и окно правки фонда страницы «Фонды». Одно окно, четыре варианта (закрытый список variants):

Пользователь заполняет псевдоним, бенефициара, комментарий и приоритет; у фонда не из ЕПК — ещё и название. Основная кнопка проверяет форму и отдаёт её странице (onSave), окно закрывается; «Отменить», крестик и Esc закрывают окно без сохранения.

Все состояния рядом

Каждая комбинация состояния данных и режима прав — копия фрагмента виджета.

Обязательность заполнения

  • Компонент обязателен к заполнению целиком: нет — это окно, его можно закрыть без сохранения.
  • Обязательные поля внутри: «Название фонда» (см. «Поля»).
  • Что показывает, когда обязательное не заполнено: при уходе из поля и по основной кнопке — ошибка поля (.inp--error + тултип при фокусе); окно не закрывается, фокус — на первое поле с ошибкой. Пометки обязательности у подписи нет — её нет на макете (вопрос ниже).
  • Что отдаёт наружу: onSave(form) зовётся только для формы без ошибок.
