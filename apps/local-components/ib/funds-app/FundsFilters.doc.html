Описание

Ряд фильтров списка фондов страницы «Фонды». Своей карточки нет: ряд стоит в тулбаре таблицы «Список фондов», слева от шестерёнки настройки (решение человека 30.10.2026). Три поля размера S (32px): тип и приоритет — одной ширины, по самому длинному значению справочников (берётся большее из двух); поиск тянется, но не шире двух этих полей вместе.

  1. Поиск (smartSearch) — иконка лупы слева, плейсхолдер «по атрибутам фонда...», справа информер с подсказкой: «Поиск записей осуществляется по атрибутам:» и строки атрибутов с маркером «•» — «Название Фонда», «Псевдоним», «Бенефициар», «ИНН Фонда» (тексты и регистр — с макета «Tooltip»).
  2. Тип фонда (typeCodes) — плейсхолдер «Все типы», множественный выбор из справочника типов: список с чекбоксами и строкой «Выбрать всё», выбранные типы — сводкой в поле («PE, +1»: первый выбранный и число остальных).
  3. Приоритет (priorityCodes) — плейсхолдер «Все приоритеты», множественный выбор, как у типа: список с чекбоксами, выбранные — сводкой «Высокий, +1» (решение человека 30.10.2026: приоритетов можно выбрать несколько). «Выбрать всё» нет — опций меньше четырёх (DropdownList).

Фильтры сразу применяются к списку фондов: кнопки «Применить» нет. Когда фондов нет вовсе, все три поля выключены — фильтровать нечего (макет «Список фондов - Empty state»).

Скрипт компонента

FundsFilters.js — глобальный window.FundsFilters, подключается после ds-body.js:

  • init(root, { types, priorities }) — справочники { code: подпись }, строит опции, привязывает поля к DSDropdownList и тултип информера к DSTooltip, ставит ширину полей data-ff-fit;
  • fit(root) — пересчитать ширину: тип и приоритет — одной ширины по большему, поиск — от ширины плейсхолдера до суммы ширин типа и приоритета с зазором (виджет перенесли, догрузился шрифт; скрытое поле досчитывается при показе);
  • setDisabled(root, bool) — выключает или включает все три поля;
  • value(root) → { smartSearch, typeCodes, priorityCodes };
  • setValue(root, filters, { silent }) — значения кодом (демо витрины);
  • событие fundsfilters:change с корня (bubbles), detail — { smartSearch, typeCodes, priorityCodes }.
