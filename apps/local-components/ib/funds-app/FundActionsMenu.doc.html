Описание

Контекстное меню строки списка фондов (FundsTable): действия над одним фондом. Два варианта — по тому, есть ли фонд в ЕПК (partyId строки): у фонда из ЕПК последний пункт «Перейти на страницу клиента», у фонда не из ЕПК — «Связать с базой ЕПК». Каждый вариант — одно меню на все кнопки «⋮» своего вида: ContextMenu ДС помнит, какая кнопка его открыла, у кнопки — data-fund-id.

Поведение

  • Клик по «⋮» строки → меню открывается у кнопки (выравнивание по правому краю); Esc, клик вне, выбор пункта — закрывают, фокус возвращается на кнопку (ContextMenu ДС).
  • Клик по пункту «Редактировать» или «Удалить фонд» → меню закрывается, страница открывает окно фонда (сценарий страницы по data-fund-action и data-fund-id открывшей кнопки). Остальные пункты только закрывают меню.
