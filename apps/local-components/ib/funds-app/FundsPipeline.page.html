Зачем существует
Вести список фондов и их активов: найти фонд по атрибутам, отобрать по типу и приоритету, посмотреть активы фонда
Кто заполняет и когда
Руководитель IB добавляет фонды вручную («Добавить фонд» → поиск в базах → форма фонда). Первичную загрузку из .xls делает администратор IB при первом запуске системы — у Руководителя IB импорта нет (решение человека 30.10.2026)
Кто пользуется результатом
Руководитель IB (director_ib) — раздел «Origination» главной. Другие роли — не решено (30.10.2026)
Бизнес-правила
Фонд бывает из ЕПК (связан с клиентом — есть partyId) и не из ЕПК: меню строки у них разное. Активы — только вложенная таблица фонда; отдельного поиска актива нет (решение человека 30.10.2026). Права на действия (создать, редактировать, удалить фонд, добавить актив) — во фронтенде флагами usePermissions; состав прав ролей — не решено (30.10.2026)

Источники: задача docs/tasks/MS0020-funds-pipeline.md (решения человека 30.10.2026), фронтенд funds-app (pages/FundsPipeline, shared/hooks/useFundActions.tsx).

Страница раздела «Фонды»: Руководитель IB приходит с плитки или пункта меню «Фонды» главной, ищет фонд и смотрит его активы.

8. Поведение

Страница связывает виджеты по их API (скрипт в конце FundsPipeline.html):

Триггер
Результат
Ввод в поиск, выбор типа или приоритета
fundsfilters:change → FundsTable.applyFilters: список сужается; совпадений нет — пустое состояние таблицы
Клик по строке фонда
fundstable:select → строка выделена, справа открываются сплиттер и «Активы <фонд>» (AssetsTable.render); клик по другому фонду меняет содержимое панели
Крестик в «Активы <фонд>»
assetstable:close → панель и сплиттер скрыты, выделение строки снято
Перетаскивание сплиттера
меняет доли панелей (35–75%); доля запоминается до перезагрузки
Шестерёнка «Настроить колонки» фондов или активов
стандартное окно ДС «Настройка таблицы» по колонкам своей таблицы: видимость, порядок, закрепление; «Применить» меняет таблицу, вид держится до закрытия вкладки
«⋮» в строке
меню фонда (из ЕПК / не из ЕПК) или актива
«Добавить фонд» (шапка, пустой список)
окно AddFundEntityFromUcpModal: поиск в базе фондов и в ЕПК
«Продолжить» с выбранным клиентом ЕПК
EditFundModal «Добавить фонд» (название, ИНН, КПП из ЕПК); «Добавить» → фонд появляется в списке и выбирается
«Новый фонд» (ничего не найдено)
EditFundModal «Новый фонд» с названием из поиска; «Сохранить» → фонд в списке
Меню фонда → «Редактировать»
EditFundModal «Редактировать фонд»; у фонда не из ЕПК — предупреждение «Клиент не привязан…» с «Привязать» (воркфлоу не делается); «Сохранить» → строка обновлена
Меню фонда → «Удалить фонд»
DeleteFundModal; «Подтвердить» → фонд убран из списка, панель активов закрыта, если был выбран он
«Связать с базой ЕПК», «Добавить актив», «Перейти на страницу клиента»
окон нет: воркфлоу ЕПК, окна активов и страница клиента не делаются (решения 30.10.2026)
Демо-адрес ?modal=add · ?modal=edit&fund=<id> · ?modal=delete&fund=<id>
окно открыто при загрузке — для показа и проверок; с fund заодно открыта панель активов этого фонда
Таб System панели прототипа → «Список фондов»
«Есть фонды» / «Фондов нет» — перезагрузка с ?state=empty (служебный переключатель не стоит в интерфейсе, скилл proto-panel §9)
Сценарии показа

10. Состояния

Loading

Не показывается в прототипе: данные демо приходят сразу. Во фронтенде — загрузка таблицы uikit. Вид загрузки — не решено (30.10.2026).

Empty

Фондов нет (?state=empty): FundsTable в состоянии empty (EmptyState «Здесь пока ничего нет» и «Добавить фонд»), поля фильтров выключены (disabled). У фонда нет активов (?fund=fnd-004): AssetsTable в состоянии empty. Тексты — паспорта виджетов.

Error

Не решено (30.10.2026): в макетах ошибки загрузки нет.

Disabled

Нет прав на действия — во фронтенде кнопки и пункты меню не показываются (usePermissions); в прототипе права не моделируются.

Выбран фонд

Строка фонда выделена, правая панель сплиттера открыта (?fund=fnd-001).
