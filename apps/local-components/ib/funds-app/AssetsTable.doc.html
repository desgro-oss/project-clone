Описание

Правая панель страницы «Фонды»: активы фонда, выбранного в списке фондов. Панель появляется по клику на строку фонда и закрывается крестиком в шапке — тогда страница прячет панель и сплиттер и снимает выбор фонда. Заголовок — «Активы <название фонда>».

Таблица — колонки фронтенда (AssetsTable.config.ts): название актива с аватаром-инициалами и ИНН/КПП второй строкой, псевдоним, дата приобретения, Enterprise Value, MCAP / 100% equity, доля владения, стоимость доли, отрасль и закреплённая справа колонка меню «⋮». Сортировка по клику в шапке, ширина колонок тянется, колонки переносятся — штатно Table ДС. Видимость, порядок и закрепление колонок меняет стандартное окно ДС «Настройка таблицы» (TableSettings) по шестерёнке в тулбаре; настройка держится на время сессии и переживает выбор другого фонда. Вид по умолчанию — как во фронтенде: «Псевдоним» скрыт (в окне выключен), «Действия» закреплена; «Сбросить настройки» в окне возвращает этот вид (Table ДС 1.025). EV и MCAP показываются в миллионах: значение данных / 1000.

У фонда нет активов — пустое состояние: «Здесь пока ничего нет», под ним «<название> · ИНН <ИНН>» и кнопка «Добавить актив»; «Настроек таблицы» в шапке нет.

Оговорки: «Добавить актив» и пункты меню строки окон не открывают — окна активов не делаются (решение человека 30.10.2026). Двойной клик по строке во фронтенде ведёт на страницу актива — здесь не делается (страницы актива нет, решение человека 30.10.2026).

Скрипт компонента (API)

AssetsTable.js (подключается после ds-body.js), глобальный window.AssetsTable:

Функция
Что делает
render(root, { fund, assets })
заголовок «Активы <fund.name>», таблица assets, пустое состояние при пустом массиве; ставит data-state data / empty, прячет шестерёнку настройки при empty (hidden); заново связывает рантаймы ДС (иконки, таблица, закрепление, меню, тултипы, TableSettings bind кнопки); сбрасывает снимок окна настройки и зовёт DSTableSettings.restore(tbl)

Своего API колонок нет (getColumns / setHiddenColumns убраны в 1.001); columns — описание колонок, только чтение.

Событие assetstable:close (CustomEvent, bubbles: true, detail: {}) — крестик шапки. Кнопка «⋮» строки: data-menu="assetActionsMenu" (есть partyId) или "assetActionsMenuCustom", data-menu-align="end", data-asset-id="<objectId>"; строка — data-asset-id. Кнопка настройки — data-table-settings (без значения: таблицу рантайм находит по .dtable).
