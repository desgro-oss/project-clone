Описание

Контекстное меню строки таблицы «Активы фонда»: действия над одним активом. Одно меню на все кнопки «⋮» строк своего вида — триггер несёт data-menu с id меню, рантайм ContextMenu ДС открывает его у нажатой кнопки и возвращает фокус ей же.

Два файла — два набора пунктов:

  • AssetActionsMenu.html (#assetActionsMenu) — актив связан с клиентом ЕПК (partyId есть): «Редактировать», «Удалить актив из фонда», «Перейти на страницу клиента» — по макету «ContextMenu / ContextMenu»;
  • AssetActionsMenuCustom.html (#assetActionsMenuCustom) — partyId нет: без «Перейти на страницу клиента» (во фронтенде пункт строится только при partyId; допущение 30.10.2026).

Какое меню у строки, решает AssetsTable по partyId актива. Пункты окон не открывают — окна активов не делаются (решение человека 30.10.2026); страница клиента в прототипе не связана. Клик по пункту только закрывает меню.
