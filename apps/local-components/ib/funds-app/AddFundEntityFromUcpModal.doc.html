Описание

Первый шаг добавления фонда. Прежде чем завести фонд, пользователь проверяет, нет ли его уже в базе фондов IB и есть ли такое юр. лицо в ЕПК. Слева — параметры поиска (Название, ИНН, ОГРН, КПП, КИО и «Скрывать клиентов без CRM ID»), по «Поиску» средняя колонка «Найдено» показывает две группы карточек: «В базе фондов» и «В базе юр. лиц Сбера (ЕПК)». Выбранная карточка раскрывается справа деталями.

  • Выбран фонд — фонд уже заведён: добавлять нечего, «Продолжить» выключена. У фонда без связи с ЕПК (partyId: null) — предупреждение «Клиент не привязан к базе юр. лиц Сбера (ЕПК).» с кнопкой «Привязать».
  • Выбран клиент ЕПК — «Продолжить» включена и передаёт клиента в окно фонда (EditFundModal, режим «добавить из ЕПК»).
  • Ничего не найдено — «Новый фонд» открывает окно нового фонда (не из ЕПК) с названием из поля «Название».

Над колонками — Alert уровня окна про распоряжение № 524/3-Р: часть клиентов в ЕПК скрыта.

Поведение

Поиск

  • «Поиск» или Enter в любом поле → поиск по базам. Подстрока без учёта регистра; запись найдена, если совпало хотя бы одно заполненное поле (ИЛИ) — допущение 30.10.2026, вопрос 2.
  • База фондов: «Название» — по name и alias, ИНН — по inn, КПП — по kpp; ОГРН и КИО у фонда нет.
  • ЕПК: «Название» — по shortName и fullName, ИНН, ОГРН, КПП, КИО — по своим полям. Клиенты, уже заведённые фондом (их partyId есть у фонда), в группу не попадают — по тултипу «Юр. лица из этого списка не добавлены в базу фондов». «Скрывать клиентов без CRM ID» убирает crmId: null.
  • Нашлось → data и выбрана первая карточка (фонд, если есть); не нашлось ничего → empty; все поля пусты → ничего не происходит.

Выбор карточки

Карточки — один role="radiogroup" на обе группы: выбрана всегда одна. Клик, Enter или Пробел — выбор; стрелки — соседняя карточка.

Осознанные отклонения

Правило
Как сделано
Почему
Фронтенд: в режиме create слева в подвале кнопка «Create fund» (transparent, Add)
кнопки в подвале нет; «Новый фонд» — только в состоянии «ничего не найдено»
так в макетах (решение: где макет и фронтенд расходятся — по макету)
Макет: подзаголовок карточки фонда «Юридическое лицо»
подзаголовок — типы фонда (types)
в FundItemDto нет поля «вид лица», а фонд бывает семейным офисом и холдингом; вопрос 5
Макет: группа «В базе фонов»
«В базе фондов»
опечатка макета
Макет: чипы отраслей в разных тонах (серый, фиолетовый, оранжевый)
чипы без тона
правила выбора тона по отрасли нет; вопрос 6
Макет: тултип «Юр. лица из этого списка не добавлены в базу фондов» стоит у ⚠ карточки
тултип — у ⓘ заголовка группы ЕПК; у ⚠ фонда — «Клиент не привязан к базе юр. лиц Сбера (ЕПК).»
по смыслу текст про список ЕПК, а ⚠ — про фонд без связи с ЕПК; вопрос 4
Карточка Card: реквизиты «подпись — значение» в строку
своя раскладка dl на токенах (Body S)
плотного инлайнового ReadOnlyField в ДС нет (так же у карточки контрагента модуля postrade)
Оси data-state локальных компонентов
своё значение idle
состояние «поиск не выполнялся» не сводится к осям данных (как choose/preview у окон модуля postrade)
