# Меню фонда

## Описание (Purpose)

Контекстное меню строки списка фондов (FundsTable): действия над одним фондом. Два варианта —
по тому, есть ли фонд в [[ЕПК]] (`partyId` строки): у фонда из ЕПК последний пункт «Перейти на
страницу клиента», у фонда не из ЕПК — «Связать с базой ЕПК». Каждый вариант — одно меню на все
кнопки «⋮» своего вида: ContextMenu ДС помнит, какая кнопка его открыла, у кнопки — `data-fund-id`.

## Бизнес-смысл (Business context)

| Вопрос | Ответ |
|---|---|
| Зачем существует | действия над фондом из реестра: добавить актив, править, удалить фонд, связь с [[ЕПК]] (макеты «ContextMenu», задача MS0020) |
| Кто заполняет и когда | — |
| Кто пользуется результатом | Руководитель IB (`director_ib`); права по пунктам — не решено (30.10.2026) |
| Бизнес-правила | «Перейти на страницу клиента» — только у фонда с `partyId` (`useFundActions.tsx`); «Связать с базой ЕПК» — у фонда без него (макет); привязка к ЕПК — отдельный воркфлоу поиска, в задаче не делается (решение человека 30.10.2026) |

Источники: задача MS0020 (решения человека 30.10.2026), макеты «ContextMenu / Фонд из ЕПК»,
«ContextMenu / Фонд не в ЕПК (Custom)», фронтенд `useFundActions.tsx`.

## Поведение (Behavior)

- Клик по «⋮» строки → меню открывается у кнопки (выравнивание по правому краю); Esc, клик вне, выбор пункта — закрывают, фокус возвращается на кнопку (ContextMenu ДС).
- Клик по пункту «Редактировать» или «Удалить фонд» → меню закрывается, страница открывает окно фонда (сценарий страницы по `data-fund-action` и `data-fund-id` открывшей кнопки). Остальные пункты только закрывают меню.
