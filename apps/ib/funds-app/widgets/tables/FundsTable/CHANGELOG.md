# FundsTable — журнал изменений

Формат записи: что изменилось · почему · по какому требованию. Без «почему» правку через
месяц откатывают обратно. Новая запись — сверху.

Правка вида, поведения или состава — новая версия: `## М.ммм — ДД.ММ.ГГГГ`. Правка только
описания версию не меняет — запись без номера: `## Паспорт — ДД.ММ.ГГГГ`. Приведение к
новым правилам ДС — тоже отдельная запись с новой `rulesVersion`.

## 1.006 — 30.10.2026

**Колонка «Действия» — по ширине иконки.** Шапка помечена `.th--actions` (TableCell ДС 2.028, Table 1.026): ширину по иконке (16 + 20 + 16 = 52px) ставит рантайм ДС, трек в разметке тоже 52px вместо 96px; подпись «Действия» в одну строку и не рвёт слово — в узкой колонке остаётся «…», полное название в тултипе. *Почему:* правило человека 30.10.2026 — колонка из одних иконок шириной по иконке + 16px по бокам, подпись, которая не влезает, уходит в «…» (была «Действи / я»). *Требование:* задача MS0020, доработка после Э3.

## 1.005 — 30.10.2026

**Тулбар: фильтры внутри таблицы, шестерёнка вместо «Настройки таблицы».** Заголовок «Список фондов» убран; слева в тулбаре — слот `data-fundstable-filters`, страница ставит туда виджет FundsFilters новым методом `placeFilters`; справа — шестерёнка `ibtn ibtn--neutral ibtn--m` с глифом `settings` (хук `data-table-settings` тот же). `applyFilters` понимает `priorityCodes` (несколько приоритетов, FundsFilters 3.000) и по-прежнему `priorityCode`. *Почему:* правки человека 30.10.2026 к экрану «Фонды»: фильтры — из внешней карточки внутрь таблицы, заголовок «Список фондов» убрать, настройка таблицы — как в ДС, шестерёнкой. **Разноцветные аватарки:** у аватара `data-av-seed` = objectId (актива/фонда) — страница включает автоокраску Avatar ДС 1.006 (`data-av-tones`), один объект всегда одного цвета. *Почему:* решение человека 30.10.2026 — механизм разноцветных аватарок, модуль «Фонды» — разноцветный. *Требование:* задача MS0020, доработка после Э3.

## 1.001 — 30.10.2026

**«Настройка таблицы» — стандартное окно ДС, все колонки видны, пустой список без импорта.** Кнопка «Настройки таблицы» несёт хук ДС `data-table-settings` вместо `data-table-setup` (окно TableSettings строит рантайм ДС из шапки); на `.tbl` — `data-table-persist="FundsTable"`, после каждой перерисовки `init` сбрасывается снимок окна и зовётся `DSTableSettings.restore`, кнопка привязывается `DSTableSettings.bind`. Колонки «Контактные лица» и «Комментарий» больше не скрыты по умолчанию (в т. ч. в скелетоне «Загрузки»); API `getColumns` / `setHiddenColumns` и своя логика скрытых колонок удалены; из fixtures убран ключ `hidden`. Текст пустого списка — «Добавьте первый фонд, чтобы начать работу со списком» (без .xls и импорта, допущение). Кнопка остаётся текстовой, как на макете (отклонение от шестерёнки — в паспорте). *Почему:* своё окно TableSetupHiddenColumnsModal удаляется — стандарт ДС; окно ДС видит только колонки шапки, скрытых по умолчанию колонок в ДС нет; импорт только у администратора IB. *Требование:* MS0020 Э2, решения человека 30.10.2026.
