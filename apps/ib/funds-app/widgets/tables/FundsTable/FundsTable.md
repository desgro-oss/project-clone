# Список фондов

## Описание (Purpose)

Таблица «Список фондов» страницы «Фонды» (своего заголовка нет — в тулбаре таблицы фильтры и шестерёнка настройки, решение человека 30.10.2026): реестр фондов, с которыми работает IB. Строка — фонд:
аватар с инициалами, название и под ним ИНН и КПП, псевдоним, бенефициары, типы, приоритет и
число активов. Клик по строке выбирает фонд — страница открывает справа его активы
(AssetsTable), строка остаётся подсвеченной. Кнопка «⋮» в конце строки открывает меню фонда
(FundActionsMenu) — его вид зависит от того, есть ли фонд в [[ЕПК]].

Порядок, видимость и закрепление колонок меняет стандартное окно ДС «Настройка таблицы»
(TableSettings) по шестерёнке справа в тулбаре; настройка держится, пока открыта вкладка
браузера. Вид по умолчанию — как во фронтенде: «Контактные лица» и «Комментарий» скрыты
(в окне выключены, включаются там же), «Действия» закреплена; «Сбросить настройки» в окне
возвращает этот вид (Table ДС 1.025).

Значения строк — из списка фондов бэкенда; фильтр (поиск, типы, приоритет) задаёт FundsFilters
в тулбаре таблицы (слот `data-fundstable-filters`, `placeFilters`), строки фильтрует этот виджет.

## Поведение (Behavior)

- Клик по строке (кроме колонки «⋮») → строка выделяется, событие `fundstable:select` с `{ objectId }`; страница открывает активы фонда справа.
- Клик по «⋮» → меню фонда (ContextMenu ДС); строка не выбирается.
- Клик по заголовку колонки с сортировкой (Название фонда, Псевдоним, Приоритет, Активов, Комментарий — `sortingEnabled` конфига) → сортировка строк: нет → по возрастанию → по убыванию; приоритет сортируется Высокий → Средний → Низкий, пустые — внизу.
- Ширина и порядок колонок — штатные ручки Table ДС.
- Шестерёнка в тулбаре → стандартное окно ДС «Настройка таблицы» (TableSettings): видимость, порядок, закрепление колонок, применяется по «Применить»; «Сбросить настройки» — сразу к виду по умолчанию (скрыты контакты и комментарий, закреплена «Действия», сортировки нет). Своего обработчика у кнопки нет.
- Вид колонок и сортировка живут на время сессии (`data-table-persist="FundsTable"`): после каждой перерисовки (`init` — обновление списка) скрипт сбрасывает снимок окна и зовёт `DSTableSettings.restore` — настройка возвращается на новую таблицу.
- Двойной клик по строке (во фронтенде — переход на страницу фонда) не делается: страниц фонда нет (решение человека 30.10.2026).

### Фильтрация

`applyFilters(root, { smartSearch, typeCodes, priorityCodes })` прячет строки, не прошедшие
фильтр: `smartSearch` — подстрока без учёта регистра в названии, псевдониме, именах бенефициаров
и ИНН (атрибуты подсказки поиска, макет «Tooltip»); `typeCodes` — у фонда хотя бы один из типов;
`priorityCodes` — приоритет фонда — один из выбранных (`priorityCode` фронтенда понимается как
массив из одного). Пустое значение условия не ограничивает. Выбранный фонд, который
фильтр спрятал, остаётся выбранным.
