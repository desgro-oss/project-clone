# Фильтры списка фондов

## Описание (Purpose)

Ряд фильтров списка фондов страницы «Фонды». Своей карточки нет: ряд стоит в тулбаре таблицы
«Список фондов», слева от шестерёнки настройки (решение человека 30.10.2026). Три поля размера
S (32px): тип и приоритет — одной ширины, по самому длинному значению справочников (берётся
большее из двух); поиск тянется, но не шире двух этих полей вместе.

1. **Поиск** (`smartSearch`) — иконка лупы слева, плейсхолдер «по атрибутам фонда...», справа
   информер с подсказкой: «Поиск записей осуществляется по атрибутам:» и строки атрибутов с
   маркером «•» — «Название Фонда», «Псевдоним», «Бенефициар», «ИНН Фонда» (тексты и регистр —
   с макета «Tooltip»).
2. **Тип фонда** (`typeCodes`) — плейсхолдер «Все типы», множественный выбор из справочника
   типов: список с чекбоксами и строкой «Выбрать всё», выбранные типы — сводкой в поле
   («PE, +1»: первый выбранный и число остальных).
3. **Приоритет** (`priorityCodes`) — плейсхолдер «Все приоритеты», множественный выбор, как у
   типа: список с чекбоксами, выбранные — сводкой «Высокий, +1» (решение человека 30.10.2026:
   приоритетов можно выбрать несколько). «Выбрать всё» нет — опций меньше четырёх (DropdownList).

Фильтры сразу применяются к списку фондов: кнопки «Применить» нет. Когда фондов нет вовсе,
все три поля выключены — фильтровать нечего (макет «Список фондов - Empty state»).

| Компонент | Откуда | Варианты и ключевые параметры |

## Поля (Fields)

| Поле | Смысл | Тип, единица | Источник | Обязательное |
|---|---|---|---|---|
| `smartSearch` | Запрос поиска по атрибутам фонда | строка; пустая — без поиска | ввод пользователя | нет |
| `typeCodes` | Выбранные типы фонда | `FundTypeCode[]`; пустой — все типы | справочник типов `FUND_TYPE_LABELS` (во фронтенде `DictionariesApi.useGetFundTypesDictionaryQuery`) | нет |
| `priorityCodes` | Выбранные приоритеты фонда | `FundPriorityCode[]`; пустой — все приоритеты | справочник приоритетов `FUND_PRIORITY_LABELS` (во фронтенде `useGetFundPrioritiesDictionaryQuery`) | нет |

Порядок строк — порядок отображения. Имена — `FundFiltersDto` фронтенда (`Pick<FundFilterRqDto,
'smartSearch' | 'priorityCode' | 'typeCodes'>`), кроме приоритета: во фронтенде `priorityCode` — один,
в прототипе `priorityCodes` — массив (см. «Осознанные отклонения»).

### Свои состояния

| Состояние | Когда | Вид |
|---|---|---|
| Фильтры заданы | выбран тип, приоритет или введён запрос | сводки типов и приоритетов в полях, текст запроса; у поиска — крестик очистки |
| Поля выключены | `setDisabled(root, true)` — страница, когда фондов нет | `disabled` у контролов и кнопок полей, `.inp--disabled`; списки не открываются, крестиков нет |

## Переполнение (Overflow)

| Случай | Правило |
|---|---|
| Длинный текст в поле | запрос прокручивается внутри поля, поле не растёт |
| Много строк или записей | выбранные типы и приоритеты — сводка «первое, +N» одной строкой; список опций — `ddl--scroll` |
| Узкая ширина | тип и приоритет держат свою ширину; поиск не уже своего плейсхолдера с обвязкой поля (min-width ставит `fit`), а когда места не хватает, ряд переносит поля на следующую строку (`flex-wrap: wrap`) |
| Полная ширина | поиск тянется, но не шире суммы ширин типа и приоритета с зазором между ними; дальше ряд не растёт, шестерёнка таблицы остаётся справа |
| Ширина типа и приоритета | одна на оба поля — по большему из них (решение человека 30.10.2026); у каждого по самому широкому содержимому: плейсхолдер или сводка «подпись, +N» для каждой подписи справочника — скрипт мерит текст шрифтом поля, прибавляет обвязку поля; сводка не обрезается ни при каком выборе |

## Поведение (Behavior)

| Триггер | Результат |
|---|---|
| Ввод в поиск | через 300 мс — событие с новым `smartSearch`; 1–2 символа событие не дают, фильтр остаётся прежним (как во фронтенде) |
| Крестик в поиске | поле очищается, событие с `smartSearch: ''` сразу |
| Клик по полю типа, шеврону, ↓ | раскрывается список типов (DropdownList) |
| Чекбокс типа · «Выбрать всё» | тип добавляется или снимается, список остаётся открытым, сводка в поле обновляется, событие с новым `typeCodes` |
| Ввод в поле типа | опции фильтруются по подстроке, совпадение подсвечено; закрытие списка стирает запрос |
| Снять все типы | снять чекбоксы в списке или «Выбрать всё» до пустого — событие с `typeCodes: []`. Крестик у поля типа виден только при набранном запросе и стирает запрос: сводку рантайм ДС значением поля не считает (см. «Открытые вопросы») |
| Чекбокс приоритета | приоритет добавляется или снимается, список остаётся открытым, сводка в поле обновляется, событие с новым `priorityCodes` |
| Ввод в поле приоритета | опции фильтруются по подстроке; закрытие списка стирает запрос |
| Снять все приоритеты | снять чекбоксы — событие с `priorityCodes: []`, в поле плейсхолдер «Все приоритеты» |
| Наведение или фокус на информер | тултип: «Поиск записей осуществляется по атрибутам:» и четыре строки атрибутов; Esc и уход курсора скрывают |

### Скрипт компонента

`FundsFilters.js` — глобальный `window.FundsFilters`, подключается после `ds-body.js`:

- `init(root, { types, priorities })` — справочники `{ code: подпись }`, строит опции, привязывает
  поля к `DSDropdownList` и тултип информера к `DSTooltip`, ставит ширину полей `data-ff-fit`;
- `fit(root)` — пересчитать ширину: тип и приоритет — одной ширины по большему, поиск — от ширины плейсхолдера до суммы ширин типа и приоритета с зазором (виджет перенесли, догрузился шрифт;
  скрытое поле досчитывается при показе);
- `setDisabled(root, bool)` — выключает или включает все три поля;
- `value(root)` → `{ smartSearch, typeCodes, priorityCodes }`;
- `setValue(root, filters, { silent })` — значения кодом (демо витрины);
- событие `fundsfilters:change` с корня (`bubbles`), `detail` — `{ smartSearch, typeCodes, priorityCodes }`.
