# FundsFilters — журнал изменений

Формат записи: что изменилось · почему · по какому требованию. Без «почему» правку через
месяц откатывают обратно. Новая запись — сверху.

Правка вида, поведения или состава — новая версия: `## М.ммм — ДД.ММ.ГГГГ`. Правка только
описания версию не меняет — запись без номера: `## Паспорт — ДД.ММ.ГГГГ`. Приведение к
новым правилам ДС — тоже отдельная запись с новой `rulesVersion`.

## 3.001 — 30.10.2026

**Тип и приоритет — одной ширины, поиск — с пределом.** Оба поля получают одну ширину — большую из двух нужных; поиску `fit` ставит max-width = ширина типа + зазор ряда + ширина приоритета: на широком экране ряд дальше не растёт, шестерёнка таблицы остаётся справа. *Почему:* правки человека 30.10.2026 — «фильтры и приоритеты одинаковой ширины, по большему», «максимальная ширина поиска — как ширина двух дропдаунов». *Требование:* задача MS0020, доработка после Э3.

## 3.000 — 30.10.2026

**Фильтры — в тулбаре таблицы, приоритет — несколько значений, ширина по значению.** Своей карточки (Tile Headless) больше нет: корень — ряд `role="group"`, страница ставит его в тулбар таблицы «Список фондов» (`FundsTable.placeFilters`). Приоритет — множественный выбор, как тип: чекбоксы в списке, сводка «Высокий, +1», значение `priorityCodes: string[]` вместо `priorityCode` (несовместимо — поэтому мажорная версия; `FundsTable.applyFilters` понимает оба). Тип и приоритет — шириной по самому длинному значению справочника (`data-ff-fit`, новый метод `fit`), поиск тянется на остальное место, но не уже своего плейсхолдера (min-width из `fit`); в узкой панели ряд переносит поля на следующую строку. *Почему:* правки человека 30.10.2026 к экрану «Фонды» — «все фильтры уберём из внешней карточки и поставим внутрь таблицы», «дропдаун по ширине самого широкого значения», у приоритетов «можно выбрать несколько значений». *Требование:* задача MS0020, доработка после Э3.

## 2.000 — 30.10.2026

**Новый вид фильтров по макету.** Все три поля — размер S (`inp--s`, 32px) вместо M; выбранные типы — сводкой «первое, +N» (`.inp__summary`) вместо чипов в поле: у InputAutocomplete S в ДС показ выбора только сводкой; подсказка поиска — своя разметка Tooltip ДС: «Поиск записей осуществляется по атрибутам:» и строки «Название Фонда», «Псевдоним», «Бенефициар», «ИНН Фонда» с маркером «•» (было — перечисление через запятую в `data-tooltip`); привязка тултипа — в `init`. API (`init`, `setDisabled`, `value`, `setValue`, событие `fundsfilters:change`) не менялся. *Почему:* ответ человека 30.10.2026 на вопрос 3 задачи — «для фильтров на этой странице будет новый компонент»: фильтры собираются по макету, отклонения от ДС (S вне Table Edit, список в тултипе) — осознанные, записаны в паспорте. *Требование:* задача MS0020 Э2 (макеты «Funds pipeline / Fund list», «Tooltip»).

## 1.000 — 30.10.2026

**Компонент создан.** Карточка Tile Headless с тремя полями в ряд: поиск по атрибутам фонда (InputText M, информер с тултипом атрибутов), тип фонда (InputAutocomplete M, множественный выбор чипами), приоритет (InputAutocomplete M, одиночный выбор, «Все приоритеты» сбрасывает); скрипт `FundsFilters.js` — `init`, `setDisabled`, `value`, `setValue`, событие `fundsfilters:change` (FundFiltersDto). *Почему:* страница «Фонды» — список фондов с фильтрами, пара во фронтенде `widgets/tables/FundsFilters`. *Требование:* задача MS0020 Э1 (макеты «Funds pipeline / Fund list», «Tooltip», «Фонды / Список фондов - Empty state», решения человека 30.10.2026).
