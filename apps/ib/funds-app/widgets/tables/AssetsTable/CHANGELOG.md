# AssetsTable — журнал изменений

Формат записи: что изменилось · почему · по какому требованию. Без «почему» правку через
месяц откатывают обратно. Новая запись — сверху.

Правка вида, поведения или состава — новая версия: `## М.ммм — ДД.ММ.ГГГГ`. Правка только
описания версию не меняет — запись без номера: `## Паспорт — ДД.ММ.ГГГГ`. Приведение к
новым правилам ДС — тоже отдельная запись с новой `rulesVersion`.

## 1.007 — 30.10.2026

**Шестерёнка — перед крестиком.** Порядок справа в тулбаре: «Добавить актив» → шестерёнка «Настроить колонки» → крестик закрытия (было: шестерёнка первой). *Почему:* правка человека 30.10.2026 — «иконка настроек таблицы должна стоять перед крестиком закрытия, после кнопки добавить актив». *Требование:* задача MS0020, доработка после Э3.

## 1.006 — 30.10.2026

**Колонка «Действия» — по ширине иконки.** Шапка помечена `.th--actions` (TableCell ДС 2.028, Table 1.026): ширину по иконке (16 + 20 + 16 = 52px) ставит рантайм ДС, трек в разметке тоже 52px вместо 96px; подпись «Действия» в одну строку и не рвёт слово — в узкой колонке остаётся «…», полное название в тултипе. *Почему:* правило человека 30.10.2026 — колонка из одних иконок шириной по иконке + 16px по бокам, подпись, которая не влезает, уходит в «…» (была «Действи / я»). *Требование:* задача MS0020, доработка после Э3.

## 1.005 — 30.10.2026

**Настройка таблицы — шестерёнка ДС.** Текстовая кнопка «Настройки таблицы» (`btn--transparent btn--xs`) заменена шестерёнкой `ibtn ibtn--neutral ibtn--m` с глифом `settings` и подписью для чтения «Настроить колонки»; хук `data-table-settings` и окно ДС те же. Отклонение от ДС из паспорта снято. *Почему:* правка человека 30.10.2026 «настройка таблицы — как в ДС, шестерёнка, просто иконка» — сделана и в активах, чтобы обе таблицы экрана были одинаковыми. **Разноцветные аватарки:** у аватара `data-av-seed` = objectId (актива/фонда) — страница включает автоокраску Avatar ДС 1.006 (`data-av-tones`), один объект всегда одного цвета. *Почему:* решение человека 30.10.2026 — механизм разноцветных аватарок, модуль «Фонды» — разноцветный. *Требование:* задача MS0020, доработка после Э3.

## 1.001 — 30.10.2026

**«Настройка таблицы» — стандартное окно ДС; EV и MCAP в миллионах.** Кнопка «Настройки таблицы» несёт хук ДС `data-table-settings` вместо `data-table-setup`; на `.tbl` — `data-table-persist="AssetsTable"`, после каждой перерисовки (выбор фонда) сбрасывается снимок окна и зовётся `DSTableSettings.restore`, кнопка привязывается `DSTableSettings.bind`. Псевдоним больше не скрыт по умолчанию (в т. ч. в скелетоне «Загрузки»); API `getColumns` / `setHiddenColumns` удалены. EV и MCAP показываются как значение / 1000 (245 000 000 → 245 000), сортировка — по показанному значению; подписи «Enterprise Value, млн RUB», «MCAP / 100% equity, млн RUB», «Стоимость доли, млн RUB» («руб.» — блокер Б26, вопрос в паспорте). Данные не менялись. *Почему:* своё окно TableSetupHiddenColumnsModal удаляется — стандарт ДС; значения EV и MCAP в данных на три разряда больше подписи «млн». *Требование:* MS0020 Э2, решения человека 30.10.2026.
