# Добавить фонд — поиск в базах

## Описание (Purpose)

Первый шаг добавления фонда. Прежде чем завести фонд, пользователь проверяет, нет ли его уже
в базе фондов IB и есть ли такое юр. лицо в [[ЕПК]]. Слева — параметры поиска (Название, ИНН,
ОГРН, КПП, КИО и «Скрывать клиентов без CRM ID»), по «Поиску» средняя колонка «Найдено»
показывает две группы карточек: «В базе фондов» и «В базе юр. лиц Сбера (ЕПК)». Выбранная
карточка раскрывается справа деталями.

- Выбран **фонд** — фонд уже заведён: добавлять нечего, «Продолжить» выключена. У фонда без
  связи с ЕПК (`partyId: null`) — предупреждение «Клиент не привязан к базе юр. лиц Сбера (ЕПК).»
  с кнопкой «Привязать».
- Выбран **клиент ЕПК** — «Продолжить» включена и передаёт клиента в окно фонда
  (EditFundModal, режим «добавить из ЕПК»).
- **Ничего не найдено** — «Новый фонд» открывает окно нового фонда (не из ЕПК) с названием из
  поля «Название».

Над колонками — Alert уровня окна про распоряжение № 524/3-Р: часть клиентов в ЕПК скрыта.

## Поведение (Behavior)

### Поиск

- «Поиск» или Enter в любом поле → поиск по базам. Подстрока без учёта регистра; запись найдена,
  если совпало хотя бы одно заполненное поле (ИЛИ) — допущение 30.10.2026, вопрос 2.
- База фондов: «Название» — по `name` и `alias`, ИНН — по `inn`, КПП — по `kpp`; ОГРН и КИО у фонда нет.
- ЕПК: «Название» — по `shortName` и `fullName`, ИНН, ОГРН, КПП, КИО — по своим полям. Клиенты,
  уже заведённые фондом (их `partyId` есть у фонда), в группу не попадают — по тултипу «Юр. лица из
  этого списка не добавлены в базу фондов». «Скрывать клиентов без CRM ID» убирает `crmId: null`.
- Нашлось → `data` и выбрана первая карточка (фонд, если есть); не нашлось ничего → `empty`;
  все поля пусты → ничего не происходит.

### Выбор карточки

Карточки — один `role="radiogroup"` на обе группы: выбрана всегда одна. Клик, Enter или Пробел —
выбор; стрелки — соседняя карточка.

| `search(scrimOrId)` | поиск по полям окна; `false` — пустой запрос |
| `select(scrimOrId, 'fund' \| 'client', id)` | выбрать карточку (`objectId` / `partyId`) |
| `setState(scrimOrId, 'loading' \| 'error', message?)` | показать загрузку или ошибку (витрина) |

Обработчики вешаются один раз на скрим; после перерисовки карточек и деталей скрипт сам зовёт
`dsIcons.apply`, `DSTooltip.bindAll` и `DSTable.wire(...).rowsChanged()`.

Проверка без браузера — `AddFundEntityFromUcpModal.kit.scenario.mjs` (поиск, группы, CRM ID, выбор,
«Продолжить», «Новый фонд», загрузка, ошибка) на странице витрины через `page-run.mjs --scenario`.

## Осознанные отклонения (Deviations)

| Правило | Как сделано | Почему |
|---|---|---|
| Фронтенд: в режиме create слева в подвале кнопка «Create fund» (transparent, `Add`) | кнопки в подвале нет; «Новый фонд» — только в состоянии «ничего не найдено» | так в макетах (решение: где макет и фронтенд расходятся — по макету) |
