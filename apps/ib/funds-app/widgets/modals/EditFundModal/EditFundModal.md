# Форма фонда

## Описание (Purpose)

Окно с данными фонда — второй шаг добавления фонда и окно правки фонда страницы «Фонды». Одно
окно, четыре варианта (закрытый список `variants`):

| Вариант | Когда | Заголовок | Основная кнопка | Название, ИНН, КПП | Предупреждение ЕПК |
|---|---|---|---|---|---|
| `add-ucp` | в окне поиска выбран клиент [[ЕПК]] и нажато «Продолжить» | Добавить фонд | Добавить | из клиента ЕПК, выключены | нет |
| `create-custom` | в окне поиска нажато «Новый фонд» | Новый фонд | Сохранить | название — из строки поиска, можно править; ИНН и КПП нет | нет |
| `edit-ucp` | «Редактировать» в меню фонда с `partyId` | Редактировать фонд | Сохранить | из фонда, выключены | нет |
| `edit-custom` | «Редактировать» в меню фонда без `partyId` | Редактировать фонд | Сохранить | название можно править; ИНН и КПП нет | «Клиент не привязан к базе юр. лиц Сбера (ЕПК).» + «Привязать» |

Пользователь заполняет псевдоним, бенефициара, комментарий и приоритет; у фонда не из ЕПК —
ещё и название. Основная кнопка проверяет форму и отдаёт её странице (`onSave`), окно
закрывается; «Отменить», крестик и Esc закрывают окно без сохранения.

показывается пустым на своём месте и уходит в форму как `null`.

## Обязательность заполнения (Required)

- Компонент обязателен к заполнению целиком: нет — это окно, его можно закрыть без сохранения.
- Обязательные поля внутри: «Название фонда» (см. «Поля»).
- Что показывает, когда обязательное не заполнено: при уходе из поля и по основной кнопке —
  ошибка поля (`.inp--error` + тултип при фокусе); окно не закрывается, фокус — на первое поле
  с ошибкой. Пометки обязательности у подписи нет — её нет на макете (вопрос ниже).
- Что отдаёт наружу: `onSave(form)` зовётся только для формы без ошибок.

## Переполнение (Overflow)

| Случай | Правило |
|---|---|
| Длинный текст в поле | однострочные поля — прокрутка текста внутри поля (поведение InputText); «Комментарий» — многострочное поле, растёт по содержимому (InputText); лимит 254 — проверкой, а не обрезкой ввода |
| Много строк или записей | тело окна прокручивается само, шапка и подвал закреплены (Modal); список приоритетов — три значения |
| Узкая ширина | окно не уже `calc(100vw − 48px)` (Modal); ряды ИНН \| КПП и «Приоритет» остаются 1 : 1 |
| Полная ширина | ширина фиксирована шагом `--modal-w-5` |

## Поведение (Behavior)

| Триггер | Результат |
|---|---|
| `EditFundModal.open('editFundModal', opts)` | вариант по `mode`, `source`, `fund.partyId`; поля заполнены; окно открыто рантаймом ДС (`DSModal.open(scrim, { keep: true })`), фокус — на первое доступное поле |
| Выбор в «Приоритете» (клик, клавиши) | значение — подпись из справочника, в форме — код |
| Ввод текста в «Приоритет» и уход из поля | совпал с подписью целиком — выбор; не совпал — возвращается прежний выбор |
| Крестик очистки «Приоритета» | выбор сброшен (`priorityCode: null`) |
| Уход из «Названия фонда» или «Комментария» | проверка поля; ошибка уходит, как только поле исправлено |
| «Добавить» / «Сохранить» | проверка; ошибки — окно остаётся открытым; без ошибок — `onSave(form)`, окно закрывается |
| «Отменить», крестик, Esc | окно закрывается, ничего не сохраняется; клик по скриму окно не закрывает (форма) |
| «Привязать» (edit-custom) | ничего: воркфлоу не делается (решение 30.10.2026) |

### Проверка ввода

Схема `EditFundModal.tsx`: `name` — обязательно; `comment` — не длиннее 254 символов, текст
«Максимальная длина – 254 символов. Указано N символов.» (перевод фронтенда). Проверка — при уходе
из поля (`mode: 'onBlur'` фронтенда) и по основной кнопке.
