## Как теперь писать спеки

- Новая спека страницы модуля — `scaffold.mjs page` по `template.md`
  (заготовка уже каноническая). Свои темы — `###` внутри канонического
  раздела; неприменимый раздел — строка «Не применимо: …». Правила —
  `screen-spec/SKILL.md`, 12 и 15.
- Правка спеки модуля → пересборка `node .agents/tools/kit-build.mjs`
  (КТ3/КТ5). Гейт ловит неканон руками Б50.
- Концепты (drafts) — при своих форматах, Б50 их не трогает.
