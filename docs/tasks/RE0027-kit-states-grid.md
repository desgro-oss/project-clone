# Витрина: «Все состояния» сеткой по осям и минимальная высота тайла (RE0027)

## Коротко

В витрине локальных компонентов у тайла «Корректировки процентов РСБУ» есть пробный
вид зоны демо «Одно состояние | Все состояния». Копии стоят одной лентой, у каждой
длинная подпись в две строки, тайлы ниже, чем на странице. Нужна сетка, которая
зависит от тайла (у других тайлов свои оси и число состояний), и минимальная высота
тайла 200px — как на странице сделки. Проба — только на этом тайле.

## Решения человека (17.10.2026)

| Вопрос | Решение |
|---|---|
| Сетка | матрица по осям: колонки — одна ось (права), строки — другая (данные / условия); подписи осей — заголовками строк и колонок, а не над каждой копией. Оси и порядок задаёт сценарий тайла |
| Сочетание, на которое ось не влияет | одна ячейка на всю строку («Условия не выполнены» — права на вид не влияют) |
| Минимальная высота | 200px везде в витрине тайла: одно состояние, «Все состояния» в зоне демо, «Все состояния рядом» в документации. Меньше — исключение, задаётся отдельно |
| Подсветка | ячейка матрицы, совпавшая с выбором в конструкторе, подсвечена бледным фоном под тайлом (17.10.2026) |
| Охват | только тайл РСБУ, пока проба |

## Как сейчас (17.10.2026)

- Вид «Все состояния» — `.kit-gallery` в `apps/local-components/kit.css`: flex-wrap,
  пять копий в ряд, подпись над каждой («Условия выполнены · Есть данные · Редактирование
  доступно»).
- Минимум 200px задаёт страница сделки (`apps/postrade/deals-app/pages/Deal.html`,
  `.screen__content .tile`); в витрину правило не попадает — тайл по содержимому (~140px).

## Решение

- **Рантайм витрины** (`kit-docpage.js`): новое поле сценария `matrix` — `{ cols, rows }`,
  у строки `label`, `note`, `cells` (`{ st, span }`). Из матрицы выводится плоский список
  копий (подпись — строка · колонка), поле `cases` не нужно. Одна функция рисует матрицу
  и в зоне демо, и в разделе «Все состояния рядом». Ширина ячейки — со слайдера
  конструктора; ячейка на всю строку держит тайл той же ширины.
- **Минимальная высота**: 200px по умолчанию, поле сценария `minHeight` — исключение.
  На время пробы включается только у сценариев с `gallery: true`.
- **Стили** (`kit.css`): `.kit-matrix` — грид на токенах ДС; тайлы в ряду одной высоты.
- **Сценарий** `RsbuInterestAdjustmentsTile.demo.js`: `cases` → `matrix` 2×3.
- **Документация витрины** (`apps/local-components/README.md`): поля `matrix`, `minHeight`.

## Вне задачи

- Перенос матрицы и минимума на другие тайлы витрины — после пробы, отдельным решением.
- Сам тайл (`widgets/tiles/RsbuInterestAdjustmentsTile/`) и страница сделки.

## Критерии приёмки

- «Все состояния» у РСБУ — 2 колонки («Редактирование доступно / недоступно») × 3 строки
  («Есть данные», «Нет данных», «Условия не выполнены»); последняя — одна ячейка.
- Все копии и одиночное демо — не ниже 200px; тайлы в ряду одной высоты.
- Слайдер ширины меняет ширину ячеек; широкая сетка прокручивается, не обрезается.
- Контролы конструктора перерисовывают сетку; раздел «Все состояния рядом» — та же матрица.
- Подсвечена ровно одна ячейка — та, что совпала с конструктором; при «Условия: не выполнены» — ячейка на всю строку при любых данных и правах; в зоне демо и в разделе «Все состояния рядом».
- Подложка не сдвигает раскладку; у ячейки на всю строку — ровно по тайлу.
- Другие страницы витрины (без `gallery`) не изменились; ошибок JS нет.
- `node .agents/tools/lessons-cli.mjs gate` — `ВЕРДИКТ: OK`.
