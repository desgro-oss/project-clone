# Улучшение Devmode (RE0031)

## Коротко

Devmode из RE0030 работает, но интерфейс неудобен: всё собрано в длинной плотной
панели, блоки плохо разделены, панель тёмная, код не подсвечен, в box model нет
радиусов. Нужно взять у VisBug и Screen Ruler решения, которых нам не хватает, и
сделать их на нашей ДС: светлая панель, разделённая на секции, тулбар инструментов на
странице, направляющие и измерения, подсказки у элемента с закреплением.

## Как сейчас (замер 19.10.2026)

- **Панель Devmode** (`dev-pane.js`): одной колонкой идут режим и оверлеи, «кто это»,
  крошки, кнопки переходов текстом, States, Box model, Layout, Style, Colors, Typography,
  Accessibility, HTML, селектор, ширина кадра, помощь. Секции разделены только
  промежутком; блоки CSS — строки «ключ — значение», без подсветки.
- **Тема.** Корни панели помечены `data-theme="service"` — служебная тёмная тема (`ui.js`,
  решение RE0005). Содержимое Devmode наследует её.
- **Box model** (`.pp-bm`): вложенные пунктирные рамки margin, border, padding, content,
  залитые полупрозрачными тонами. Радиусов нет; margin внутри общей рамки, а не на
  выносных линиях.
- **Слой на странице** (`.pp-insp`, `dev-inspect.js`): margin и padding — залитые
  полупрозрачные рамки, числа — плашками; ярлык `тег.класс` над рамкой; плашка размера
  одной строкой; красные линии расстояний; `Alt` — расстояние до элемента под курсором.
- **Управление**: режимы «Inspect / View» и оверлеи «Rulers / Layout» — кнопками в панели;
  кнопки масштаба — отдельным рядом по центру снизу (`dev-zoom.js`).
- **Чего нет**: тулбара инструментов на странице, направляющих через страницу, подсказки у
  курсора, закрепления подсказок, мультивыбора.
- **Референсы**: снимки Dev Mode в Pixso — `tmp/dev/` (вне git, в задачу и `refs/` не
  копируются); код VisBug — `tmp/ProjectVisBug-main/` (вне git).

## Решение

### Что берём из образцов

| Откуда | Решение |
|---|---|
| Pixso (снимки) | Светлая панель. Секции разделены линиями. CSS — блоком кода с подсветкой: комментарий, свойство, значение, `var(--…)`. «Копировать» у блока. Цвета: кружок образца, имя токена, hex справа, группы «фон / обводка / текст». Box model: светлая рамка border, padding залит, размер в пунктирной рамке, margin — плашками на выносных линиях, **радиусы в углах**, подпись `border-box`. На странице: штриховка padding, плашки чисел у сторон, ярлык компонента над рамкой, плашка `W … / H …` под ней. Тулбар — плавающий ряд снизу по центру |
| VisBug | Тулбар инструментов с клавишами-буквами. Подсказка у курсора: место — по четверти окна, клик закрепляет, закреплённых может быть несколько, Esc снимает все. Направляющие от краёв элемента через всю страницу. Shift+клик — мультивыбор (не берём, 19.10.2026). Обход: Tab / Shift+Tab — соседи, Enter / Shift+Enter — ребёнок / родитель |
| Screen Ruler | После выбора расстояние до элемента под курсором видно **без Alt**. Выбранный элемент подсвечен другим цветом, чем наведённый. Перекрестие на линейках идёт за курсором |

Файлы VisBug не переносятся как есть: это ES-модули со сборкой (по `file://` модули не
грузятся, рантайм панели — обычные скрипты), слой на веб-компонентах с Shadow DOM (панель
его не использует: рантаймы ДС ищут разметку в `document`), цвета литералами и внешние
библиотеки (у нас только токены, ПН10, и без зависимостей); большая часть кода — правка
вёрстки, которую мы не берём. Лицензия VisBug — Apache-2.0: дословный кусок кода требует
шапки с источником; перед этим сверить с правилом нейтральности (`vendor-scan`).
Код Screen Ruler закрыт — берём только принципы.

### Э1 · каркас панели

- Светлая панель: содержимому Devmode ставится `data-theme` светлой темы ДС (блоки
  `[data-theme="legacy"]`, `[data-theme="ibp-neo-light"]` в `Themes.css` действуют и на
  вложенном узле). Хром панели (шапка, рельс) остаётся служебным. Переключатель «светлая /
  как панель» — в шапке Devmode, хранится в `pp.prefs`.
- Порядок сверху вниз: шапка (имя, тип, ссылки); крошки одной строкой; Box model (Э2);
  CSS — «Layout» и «Style» блоками кода с подсветкой, переключатель «код / список»;
  «Colors» — «образец · токен · hex»; «Typography»; свёрнутые по умолчанию «States»,
  «Accessibility», «HTML» (с подсветкой), «Selector и ссылка». Сворачивание помнится.
- Секции разделены линией `--border-light`; переходы по дереву — IconButton со стрелками;
  режим и оверлеи уходят в тулбар на странице (Э3).
- Подсветка синтаксиса — только токенами (ПН10): свойство — `--text-primary`, значение —
  `--warning-dark`, `var(--токен)` — `--primary`, комментарий — `--success-dark` курсивом,
  тег и атрибут HTML — `--primary-dark` и `--text-secondary`. Моноширинного токена в ДС
  нет — тот же набор, что у комментариев панели.
- Переиспользуется: `P.build`, `P.blockCss`, `P.code` (`dev-props.js`), `T.resolve`
  (`dev-tokens.js`), `PP._ds` (`dev-ds.js`), копирование и тосты `dev-pane.js` / `ui.js`.

### Э2 · box model и вид слоя на странице

- Панель: margin — плашками на выносных линиях; border — светлая рамка со значениями;
  padding — залитый прямоугольник; размер — пунктирная рамка `W × H`; в четырёх углах —
  радиусы (`border-*-radius`, токен — в подсказке и в копии); подпись `box-sizing`.
- Страница: padding и margin — штриховка; плашки чисел у каждой стороны; выбранный обведён
  другим цветом, чем наведённый; ярлык компонента со знаком типа; плашка размера в две
  строки `W Fixed 320` / `H Hug 48`; радиус в плашке, если он не 0. Всё на токенах.

### Э3 · тулбар инструментов и измерения

- Плавающий ряд по центру снизу; кнопки масштаба (`.pp-zoom`, `dev-zoom.js`) — его правая
  часть.

  | Клавиша | Инструмент | Что делает |
  |---|---|---|
  | `V` | Inspect | выбор и наведение |
  | `H` | Hand | перемещение; пробел — временно |
  | `G` | Guides | направляющие |
  | `M` | Measure | измерения |
  | `C` | Columns | колонки сетки ДС (`.grid12`, `.tile-row`), в которой лежит элемент: с номерами, занятые элементом подсвечены |

  Там же «Rulers» и «Layout». Буквы работают, только когда включён Devmode и фокус не в
  поле ввода.
- Guides: от краёв наведённого элемента — линии через всю видимую область; на линейках —
  перекрестие за курсором и подсвеченный диапазон.
- Measure: после выбора расстояние до элемента под курсором видно сразу, без Alt (в Inspect
  Alt остаётся). Esc — снять выбор. Shift в Inspect, как раньше, пропускает клик на страницу.
- Обход дерева: к стрелкам — Tab / Shift+Tab, Enter / Shift+Enter.
- Переиспользуется: `M.between`, `M.relations`, `M.gaps` (`dev-measure.js`), `drawRuler`,
  `frame`, `chip`, `lines` (`dev-inspect.js`), `Z.level()` (`dev-zoom.js`).

### Э4 · подсказки с закреплением

- В Inspect у курсора — карточка: имя компонента; `W × H` и режим по оси; padding, gap,
  radius токенами; фон и цвет текста образцами с токеном; токен типографики; контраст.
  Только значения, отличные от умолчания. Место — по четверти окна, в пределах области у
  панели (`PP._ui.winSize()`).
- Клик закрепляет карточку у элемента, Shift+клик — ещё одну; закреплённые идут за
  элементом при прокрутке и масштабе; Esc снимает все; «Open in panel» выбирает элемент в
  панели; карточку можно перетащить за шапку; наведение на `.класс` в шапке подсвечивает
  все элементы с ним.
- Карточка — светлая поверхность ДС (`--bg-popup`, `--elevation-2`), в `OWN`.
- Тумблер «Tips» в тулбаре, по умолчанию включён.

### Э6 · секция Media

- Секция «Media» между «Typography» и «States»; открыта по умолчанию, сворачивание помнится
  (`devFolds`); справа в заголовке — число медиа. Нет медиа внутри выбранного — секции нет.
- Сбор (`dev-pane.js`, `mediaList`): выбранный элемент и потомки с `[data-icon]` и
  `.illu[data-illu]`, слои панели не берутся (`M.own`); повторы схлопываются по имени и цвету
  (иллюстрации — по адресу файла), у карточки счётчик `×N`.
- Сетка — две колонки; карточка — превью, имя, тип (`SVG · #hex` или «Иллюстрация»), по
  наведению — глиф скачивания. Показаны первые 12, «Показать ещё» добавляет по 24 (защита от
  `body` на реестре).
- Скачивание по клику: иконка — живой `<svg>` узла, `currentColor` → hex цвета на странице,
  файл `icon-<имя>.svg`; иллюстрация — `fetch` файла ДС и сохранение как есть, `<имя>.svg`
  (`-dark`, если на странице подставлен тёмный вариант). По `file://` чтение закрыто —
  открывается вкладка с файлом и тост-подсказка. Сохранение — `PP._store.downloadText`
  (прежняя внутренняя функция вынесена в API).
- Вид — `panel.css` (`.pp-media*`), токены ДС; строки — `strings.js` (`media.*`).

## Критерии приёмки

- Содержимое Devmode светлое на любой теме страницы; секции разделены линиями; Layout,
  Style и HTML — блоками кода с подсветкой токенами ДС.
- В box model видны радиусы четырёх углов, margin — на выносных линиях, размер — в
  пунктирной рамке, подпись `box-sizing`.
- На странице padding и margin заштрихованы, у каждой стороны — плашка с числом; выбранный
  и наведённый элементы различимы.
- Тулбар по центру снизу: инструменты с клавишами `V H G M C`, «Rulers», «Layout», масштаб;
  буквы не срабатывают в полях ввода.
- Guides рисует линии от краёв элемента через всю область; Measure показывает расстояние
  до элемента под курсором без Alt; Columns рисует колонки сетки с номерами и подсвечивает
  занятые наведённым элементом; Shift+клик, как раньше, идёт на страницу.
- Секция Media: иконки и иллюстрации выбранного элемента сеткой 2×N; клик скачивает SVG
  (иконка — с цветом страницы, не `currentColor`); нет медиа — нет секции.
- Подсказка у курсора не уходит за край области у панели; клик закрепляет, Esc снимает
  все.
- После выхода из Devmode на странице нет слоёв, карточек и `.is-*`.
- Числа слоя совпадают с DevTools при 100 % и 200 %.
- `node .agents/tools/proto-panel.mjs --check` и `--selftest` — `ВЕРДИКТ: OK`.
- `node .agents/tools/lessons-cli.mjs gate` — `ВЕРДИКТ: OK`.

## Риски

- Клавиши-буквы могут совпасть с обработчиками страниц прототипа — ловить только в
  Devmode, вне полей ввода, с `stopPropagation`.
- Подсказка у курсора на большой таблице может тормозить — перерисовка в цикле кадра,
  как у слоя инспектора; замер на реестре pipelineManager.
- Светлая тема внутри служебной: плавающие слои ДС из содержимого Devmode (тултипы, меню)

Сдвиг только по вертикали; под масштабом Devmode такие элементы масштабируются со страницей. Метки и перенос снимаются при откреплении.
