# Фонды — FundsPipeline (MS0020)

## Коротко

Раздел «Фонды» главной Руководителя IB (`director_ib`) ведёт на `#`. Нужна страница
`FundsPipeline` в модуле `apps/ib/funds-app`: список фондов с фильтрами, панель активов
выбранного фонда, контекстные меню, пустые состояния, настройка таблицы и окна
добавления, создания, редактирования и удаления фонда. Имена страниц и блоков — из
фронтенда `funds-app` (`tmp/funds-app/src`, `PROJECT_STRUCTURE.md`).

## Критерии приёмки

- Страница открывается двойным кликом и с плитки «Фонды» главной Руководителя IB.
- Клик по фонду открывает справа активы фонда; у РФПИ — пустое состояние; крестик закрывает панель.
- Меню фонда отличается для фонда из ЕПК и не из ЕПК, как в макетах.
- Все компоненты, классы и токены — из ДС; имена страниц и виджетов — из фронтенда.
- Новые виджеты прошли приёмку отдельным субагентом.
- `node .agents/tools/lessons-cli.mjs gate` — `ВЕРДИКТ: OK`.
