# RE0044a — три отдельные роли: handoff

- **Дата:** 30.10.2026
- **Статус:** исправлено, на просмотре человека

## Цель

Вернуть Аналитика ДИД в Pre с прежней главной, сохранить нового Аналитика Core отдельно: всего три роли.

## Этапы

- ✓ plan — уточнение пользователя
- ✓ build — отдельные каталоги и восстановленный старый вход
- ✓ review — все три роли и 12 модульных прогонов
- ✓ close — урок, гейт, review и handoff

## Принятые решения

- Пользователь: «Его верни в Pre как был, 3 роли теперь».
- Старый analyst/Analyst принадлежит Аналитику ДИД в Pre; director_ib остаётся в IB.
- Новая роль Аналитика Core — отдельный прототипный код core_analyst/CoreAnalyst; пара во фронтенде неизвестна.
- Объединение ролей в RE0044 было ошибкой агента, а не решением человека.

## Что сделано

- `host-app/data/authentication.js` — три записи, старые коды не переиспользованы.
- `host-app/data/{navigation,dashboard}.js` — раздельные ключи и ссылки analyst/core_analyst.
- `host-app/pages/HomePage.html` — analyst снова 6 групп/20 плиток, перенаправляется только core_analyst.
- `dashboard-app/pages/HomePage.html` — новая роль Core и её ссылки.
- `clients-app/data/nav-links.js`, `tasks-app/data/nav-links.js` — контекст каждой из трёх ролей.
- `project.json`, `hub.js` — восстановлена главная Аналитика ДИД в Pre, дашборд остался в Core.
- Текущие спеки и README — схема трёх ролей; задача RE0044 помечена уточнением.
- Журнал уроков — Л284 с регрессией сохранения прежней роли.
