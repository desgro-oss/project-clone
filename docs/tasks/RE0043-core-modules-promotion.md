# Перенос задач и клиентов (RE0043)

## Коротко

Перенести часть `apps/core/drafts/ibp-redesign-v1` в `core/tasks-app` и
`core/clients-app`. Подключить модули к плиткам и меню главной `core/host-app`
и к колонке «Проекты» хаба. Сохранить действующие сценарии и текущие правки.

## Решения человека (30.10.2026)

| Вопрос | Решение |
|---|---|
| Источник | `apps/core/drafts/ibp-redesign-v1` |
| Задачи | `apps/core/tasks-app` |
| Клиенты | `apps/core/clients-app` |
| Точки входа | Главная и соответствующие ссылки в проектах хаба |

## Решение

Частичный перенос: `TasksPage`; `MyClientsPage`, `ClientInfoPage`,
`ClientComments`; зависимости виджетов и демо-данных. Общие виджеты используются
страницами Core по относительным путям. Исходные страницы удаляются после
переноса, preview пересобираются. Остальные разделы концепта остаются на месте.
Трек `product` соответствует запрошенной колонке «Проекты».

## Критерии приёмки

- Главная для обеих представленных ролей ведёт в задачи и клиенты из плиток и меню.
- Хаб содержит два проекта с рабочими входами `.preview.html`.
- Страницы открываются через `file://`, не берут виджеты из `drafts/`.
- Крошки ведут на главную host-app; переходы клиент → задачи и из черновика сохранены.
- `node .agents/tools/lessons-cli.mjs gate` — вердикт отражён в итоге.

спек сохраняются без переинтерпретации.
