# Главная Аналитика — дашборд (RE0044)

**Уточнение:** прежний `analyst` — Аналитик ДИД в Pre. Его замена новой ролью
в этом заходе была ошибкой агента, исправленной в `RE0044a-three-separate-roles.md`.
Актуальная схема содержит три роли; новая роль дашборда — `core_analyst`.

## Коротко

`core/dashboard-app` становится главной роли `analyst` («Аналитик») в Core.
Для этой роли `host-app/HomePage.html` направляет на дашборд. Нужны переходы
в существующие клиенты и задачи, обратные ссылки и смена роли, название
в хабе «Главная - Аналитик (Дашборд)», верхнее поле 24px.

## Решения человека (30.10.2026)

| Вопрос | Решение |
|---|---|
| Главная Аналитика | `apps/core/dashboard-app` вместо host-app для этой роли |
| Раздел | Core |
| Хаб | «Главная - Аналитик (Дашборд)» |
| Доступные разделы | Клиенты и задачи — связать с дашбордом |
| Отступ | Исправить верхнее поле 24px |

## Решение

Существующий код роли `analyst` сохраняется; подпись — «Аналитик», команда —
Core. Главная `director_ib` остаётся в host-app. Контекст роли передаётся
параметром `role` в переходах Core. Дашборд использует существующий профиль
Анны Ким; доменные данные, статусы и права не расширяются.

Причина дефекта отступа: экран без крошек наследует `--layout-pad-top: var(--space-8)`
каркаса Layout. Исправление — локальное поле через `var(--space-24)`, без правки ДС.
