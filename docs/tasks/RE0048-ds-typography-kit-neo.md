# Типографика: имена UI-kit, тема NEO, переключатели (RE0048)

## Коротко

ДС и кит разработчиков называют одни и те же текстовые стили по-разному
(`--type-h3-strong` против `H3StrongSmb`). Переезжаем на имена кита целиком
(этапы 1–4 плана со страницы типографики), добавляем 7 недостающих стилей кита
и заводим типографские темы: копия типографики NEO с уплотнённым трекингом и
переключателями в протопанели и на странице «Темы». Таблица сверки на странице
типографики остаётся — по ней сверяем токены в Pixo вручную.

## Решения человека (02.11.2026)

| Порядок переезда | Полный переезд на имена кита по плану со страницы типографики; в итоге остаются только имена кита, старые удаляются. Таблицу сравнения на странице типографики в документации ДС оставить — для сверки при ручной смене токенов в Pixo |

## Как сейчас (замер 02.11.2026)

- `foundations/Typography/Typography.css` 1.002: 26 токенов рампа `--type-*`
  (10 заголовков, 9 боди, 3 кнопки + семейства и веса), letter-spacing 0
  задан явно; H1/H2 — вес 300.
- Сверка с UI-kit на `Typography.html` (снимок `src/styles/theme/typography.ts`
  от 11.10.2026): 29 стилей кита, совпадают 20. Единственное расхождение
  значений — вес H1/H2 (в ките 400). 7 стилей кита в ДС нет: `H4StrongExtensiveSmb`,
  `BodyMExtensive`, `BodyXSExtensive`, `ButtonL`, `DisplayL/M/S` (последние —
  семейство SB Sans Text Cond, которого в ДС нет).
- Потребители `var(--type-*)` — ~442 файла (ДС ~181, из них 58 CSS компонентов;
  apps ~250). Классы `.ds-*` — 57 HTML в apps и страницы ДС.
- Темы (`foundations/Themes/`) — только цветовые; в `Themes.md` зафиксировано
  «Типографика — шрифты ДС сохраняются».

## Решение

### 1. Имена и значения (Typography.css 2.000, страница, спека)

Таблица соответствия — массив `uikit` в `Typography.html:352–382`. Правило имени:
префикс `--type-` + имя стиля кита в кебаб-кейсе; класс — `.ds-` + то же.

- 19 переименований: `--type-h1 → --type-h1-light` (вес 300→400),
  `--type-h2 → --type-h2-light` (→400), `--type-h3-strong → --type-h3-strong-smb`,
  `--type-h3 → --type-h3-reg`, h4/h5/h6 аналогично, `--type-body-{xl,l,m,s} → …-reg`,
  `…-strong → …-strong-smb`, `--type-body-xs → --type-body-xs-reg`.
  Кнопки `button-m/s/xs` не меняются.
- +7 токенов и классов: `--type-h4-strong-extensive-smb` (Display 600 22/28),
  `--type-body-m-extensive` (Text 400 16/24), `--type-body-xs-extensive`
  (Text 400 12/20), `--type-display-l/m/s` (TextCond 400 36/48 · 24/40 · 20/32),
  `--type-button-l` (Screen 400 24/32). Для Display — токен
  `--font-text-cond: "SB Sans Text Cond", var(--font-text)` без @font-face
  (файлов шрифта нет, фолбэк).
- В `:root` добавляется `--type-ls: 0`; утилити-классы — `letter-spacing: var(--type-ls)`.
- `Typography.html`: секции и таблица на новые имена; 7 строк кита — фон
  `var(--st-red-light)` (16%, палитра статусов) и подпись «есть в ките, в макетах
  не используется»; колонка «Имя ДС после переезда» → «Имя ДС»; счётчик;
  «Расхождения»/«Как переехать»/«Открытые вопросы» → фактическое состояние.
  Таблицу не удалять. `Typography.md` и `CHANGELOG.md` ДС — обновить.

### 2. Перевод потребителей и удаление старых имён

- One-off Node-скрипт (tmp/, вне git, пишется файловым редактором, UTF-8):
  замена 19 токенов + 19 классов, длинные имена раньше коротких, имя только
  целиком (после него не `-`, буква, цифра). Зоны: CSS, спеки и чит-шит ДС →
  страницы документации ДС → apps (модули, потом концепты) → оснастка
  `.agents/` → `docs/index.md`.
- Не переписывать историю: `docs/tasks/**`, `*.handoff.md`, `lessons-raw.md`.
- Второй проход: `letter-spacing: 0` → `letter-spacing: var(--type-ls)` в CSS ДС
  (компоненты, docs-kit) и apps — иначе тема NEO не достанет до ~20 файлов
  компонентов с явным `letter-spacing: 0`. Намеренные `.04em` не трогать.
- Старые имена-ссылки удаляются из Typography.css, версия Typography — 2.000.
- Проверка: grep 19 старых имён по живым файлам = 0 вхождений.

### 3. Типографские темы (механизм)

- Новые `foundations/Typography/Typography.themes.css` и `Typography.themes.js`.
- CSS: `:root[data-typography="neo"], [data-typography="neo"] { --type-ls: -0.02em; letter-spacing: -0.02em; }`
  — токен для явных правил, свойство на корне — наследование тексту без правил.
  Без атрибута ничего не меняется (базовая тема).
- JS: `window.DSTypography` по контракту `DSTheme` (`Themes.js`): get/set/list,
  атрибут `data-typography`, localStorage `ds.typography`, событие
  `ds:typographychange`, `?typography=`; темы зашиты: base («Базовая», без
  атрибута) и neo («NEO»). Безопасен при отсутствии рантайма.
- Подключение: `@import` в `ds.css` рядом с Themes.css; `Typography.themes.js`
  в цепочку `ThemeBoot.js` после `Themes.js`.
- Ранняя установка атрибута: `docs-kit/ds-theme-boot.js` (страницы ДС) и шаблон
  `.agents/tools/boot-build.mjs` (генерат `apps/ds-config.js`) + регенерация.
- `Themes.md`: «Типографика — шрифты ДС сохраняются» → цветовые темы
  типографику не меняют, типографские темы — отдельное измерение.
  `MAINTAINING.md` — абзац «Типографские темы».

### 4. Переключатели UI

- Протопанель `.agents/proto-panel/ui.js`, `renderThemePane()` (~1029–1053):
  под списком тем подзаголовок «Типографика» и кнопки в тех же классах
  `.pp-theme__list/.pp-theme__item` (base/neo), вызов `DSTypography.set`,
  перерисовка по `ds:typographychange`, скрыть блок без рантайма; лейблы в
  `strings.js`; при необходимости `panel.css`; точечно README панели.
- Страница «Темы»: группа в theme-bar (`Themes.html:28–49`) с переключателем
  двух тем по образцу segctrl этой же страницы; логика в `Themes.page.js`,
  вёрстка в `Themes.page.css`. Демо-компоненты реагируют через атрибут и `--type-ls`.

### 5. Сторожа старых имён

- `tools/ds-lint.js` + `ds-lint.md`: WARN на 19 старых имён в файлах ДС.
- `.agents/tools/layout-check.mjs`: BLOCKER на старые имена в экранах apps —
  после 2.000 это гарантированно битая ссылка.
- После правки каждого сторожа — прогон с непустым результатом на заведомо
  подходящем файле (process.md §8).
