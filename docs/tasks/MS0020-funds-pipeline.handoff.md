## Принятые решения
- Всё из Э1 в силе: окон активов, импорта, воркфлоу ЕПК нет; страницы фонда/актива/клиента — `#` — пользователь
- «Настройка таблицы» — стандартное окно ДС `TableSettings` (хук `data-table-settings`, вид держит `data-table-persist`); своё окно `TableSetupHiddenColumnsModal` удалено (копия — scratchpad сессии, в git его не было) — пользователь, вопрос 2
- Все колонки видимы: у `TableSettings` нет признака «скрыта по умолчанию» (контакты, комментарий, псевдоним актива) — агент, открытый вопрос в паспортах
- FundsFilters 2.000: поля S, подсказка поиска списком (`<br>` в `.tip`), типы — сводкой «PE, +1» (в ДС нет чипов в поле S) — пользователь (вопрос 3) + агент
- Пустой список: «Добавьте первый фонд, чтобы начать работу со списком» — агент, допущение
- EV и MCAP — значение / 1000; подписи «млн RUB» (правило ДС Б26) — пользователь: «пока как в ДС»
- «Связать с базой ЕПК», «Привязать» — есть, без обработчика — пользователь, вопрос 7
- Окна: `AddFundEntityFromUcpModal` (поиск ИЛИ по полям в базе фондов и ЕПК, `modal--w9`), `EditFundModal` (варианты add-ucp, create-custom, edit-ucp, edit-custom; заголовок edit-custom — «Редактировать фонд», в макете «Новый фонд»), `DeleteFundModal` (Inset без сворачивания) — агент, расхождения в паспортах
- «Действия» — обычная колонка с подписью, закреплённая по умолчанию (можно открепить, перенести, скрыть в окне ДС); обход служебной колонки убран, таблицы 1.003 — пользователь, урок Л285
- «Стоимость доли» тоже / 1000 — суммы одного порядка — пользователь
- Демо-адреса окон: `?modal=add`, `?modal=edit&fund=<id>`, `?modal=delete&fund=<id>` — агент
- Э3: раздел витрины «Фонды» для всех виджетов модуля (`project.json → localKit.kits[ib].categories`) — пользователь («уникальный модуль со своими локальными компонентами»)
- Э3: панель прототипа включена, `proto-panel/flows.yaml` — 5 сценариев (список и активы, добавить из ЕПК, новый фонд, редактировать и удалить, фондов нет); «Фондов нет» — переключатель таба System (`PP_SYSTEM`, `reload: true`) — агент
