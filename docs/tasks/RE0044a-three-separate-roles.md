# Три отдельные роли (RE0044a)

## Коротко

Исправление неверной интерпретации RE0044: новый Аналитик Core добавляется
отдельно, прежний Аналитик ДИД не заменяется. Ответ человека 30.10.2026:
«Его верни в Pre как был, 3 роли теперь».

## Решения человека

| Роль | Команда | Главная |
|---|---|---|
| Аналитик ДИД | Pre | Прежняя плиточная главная host-app |
| Руководитель IB | IB | Прежняя главная host-app |
| Аналитик | Core | Дашборд dashboard-app |

Старые `analyst` / `Analyst` сохраняются за ДИД. Для новой роли введён отдельный
прототипный код `core_analyst` / `CoreAnalyst`; соответствие нового кода фронтенду
не установлено и не выдаётся за известный контракт.

## Критерии приёмки

- В каталоге ровно три роли; в Pre снова Аналитик ДИД (`analyst`).
- `host-app?role=analyst` строит прежние 6 групп и 20 плиток без редиректа.
- `core_analyst` открывает дашборд, `director_ib` сохраняет главную IB.
- Все три роли доступны в переключателях обеих главных и сохраняются в клиентах/задачах.
- В хабе есть главная Аналитика ДИД в Pre и дашборд Аналитика в Core.
- Гейт — `ВЕРДИКТ: OK`.

## Открытые вопросы

Пара новой роли `core_analyst` во фронтенде не установлена; код прототипный.
