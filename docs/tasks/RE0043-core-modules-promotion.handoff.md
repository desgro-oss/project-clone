# RE0043 — перенос задач и клиентов: handoff

- **Дата:** 30.10.2026
- **Статус:** сделано, на просмотре человека

## Цель

Выделить задачи и клиентов из IBP Redesign v1 в модули Core и связать с главной и хабом.

## Этапы

- ✓ plan — границы и зависимости
- ✓ build — перенос, навигация, паспорта и генераты
- ✓ review — DOM-сценарии, независимая приёмка и гейт
- ✓ close — задача, отчёт приёмки и handoff

## Смета

`ctx-budget.mjs --stage build --out-lines 150` — `ВЕРДИКТ: OK`, короткий маршрут.

## Принятые решения

- Пользователь: источник `apps/core/drafts/ibp-redesign-v1`; задачи → `apps/core/tasks-app`, клиенты → `apps/core/clients-app`; обновить главную и проекты хаба.
- По запрошенной колонке хаба модули получили трек `product`; дальнейшие правки — с разрешения человека по правилам проекта.
- Имена и визуальная структура перенесены без переименования и редизайна.
- «Статусы задач» относятся к администрированию и остались в концепте.
- Неизвестное в бизнес-смысле паспортов не уточнялось и не достраивалось.

## Что сделано

- `apps/core/tasks-app/` — TasksPage и четыре виджета, локальные демо-данные.
- `apps/core/clients-app/` — реестр, карточка, комментарии, 26 зависимостей и панель со state 7.
- `apps/core/host-app/data/{dashboard,navigation}.js` — рабочие ссылки плиток и меню обеих ролей.
- `apps/core/drafts/ibp-redesign-v1/` — оставшиеся экраны берут общие виджеты из модулей; старые страницы перенесённых частей удалены.
- `hub.js`, витрина, README модулей и каталог документации — пересобраны штатными инструментами.
- `docs/tasks/RE0043-core-modules-promotion.scenario.mjs` — общий сценарий переноса; рядом с четырьмя страницами — именованные входы сценария.
- `ClientCreditsList.js`, `TaskHistoryTable.js` — привязка таблиц, появляющихся после загрузки, по существующему правилу Л93.
