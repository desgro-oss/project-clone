# Паспорт страницы на карте экранов (RE0039)

## Коротко

У локальных компонентов есть документация (страница витрины), у страниц модулей её нет: спека `<Имя>.screen.md` лежит рядом с HTML, а на хабе её не открыть. Нужно место и способ показывать описание страницы. Решение человека: вход — карта экранов. На плитке страницы — кебаб-меню с пунктами «Открыть страницу» и «Паспорт страницы»; паспорт — отдельная страница, собранная из спеки.

## Решения человека (23.10.2026)

| Вопрос | Решение |
|---|---|
| Идея | Выпадающий список на плитках карты с пунктом «Паспорт страницы» и собственной страницей для паспорта |
| Где показывать | Только карта экранов; в меню витрины страниц нет |
| Названия | Пункты меню «Открыть страницу» и «Паспорт страницы»; заголовок паспорта — название страницы из спеки (`title`), над ним подпись «Паспорт страницы · <модуль>» |
| «Открыть страницу» на паспорте | Файл страницы из поля `file` спеки (собранная `.preview.html`, если есть), без параметров: генератор витрины карту не читает |

## Как сейчас (замер 23.10.2026)

- Карта: `apps/screen-map/<раздел>/map.yaml` → `map-data.js` (генератор `.agents/tools/screen-map.mjs`); карты есть у Post (`deals-app`, `post-reports-app`: 8 страниц) и IB (`banker-app`: 2 страницы). Отрисовку майндмапа делает `.agents/proto-panel/map-view.js` (режим `mind`): узел — карточка Tile Card с Entity, вся карточка кликабельна и ведёт на страницу; в режиме `tree` (шторка панели) — дерево строк ProductRow. Подписи интерфейса отрисовщику передаёт страница карты (своих строк у него нет). Страница карты — `apps/screen-map/<раздел>/index.html`, руками.
- У главной Core (`dashboard-app`) карты нет.
- Спека страницы — `pages/<Имя>.screen.md` рядом с HTML (обязательна: иначе проверка экранов краснит); соответствие спеки странице — поле `file` в её шапке (у `banker-app/index.html` спека называется `HomePage.screen.md`).
- Витрина локальных компонентов: `kit-build.mjs` собирает `<Имя>.doc.html` из паспортов виджетов; в нём уже есть разбор Markdown (`mdSections`, `dsTable`, `inline`), разбор шапки, ссылки на страницы ДС и витрины; расхождение страницы с источником ловит шаг гейта `kit` (страница устарела — кодом КТ3, лишняя страница удалённого виджета — КТ5).
- Меню плитки: в ДС есть `ContextMenu` (`data-menu`, `.menu`, пункты с иконкой) и `IconButton`; глифы `more-dots` (кебаб, уже используется в дереве продуктов) и `passport`.

## Решение

### Где хранится и как собирается

- Источник — существующая спека `pages/<Имя>.screen.md`; новых файлов-описаний нет.
- Страницу паспорта собирает `kit-build.mjs` в папку витрины рядом со страницами компонентов: `apps/local-components/<раздел>/<модуль>/<Имя>.page.html`. В реестр и меню витрины паспорт не входит. Расхождение со спекой и паспорт удалённой страницы ловит уже существующий шаг гейта `kit`; новой проверки не заводим.
- Охват — страницы модулей разделов с картой (Post 8, IB 2). Спека находится по полю `file` шапки, как у сенсора.
- Что на странице: каркас как у страниц витрины (NavPanel — хаб и карта раздела, оглавление справа), без демо и вкладок; шапка — название и назначение, «Открыть страницу», «На карте»; карточка «Паспорт» из шапки спеки (файл, адрес, пара во фронтенде, источник, версия; компоненты ДС → их страницы; виджеты → страницы витрины); дальше разделы спеки по порядку — «Бизнес-смысл» (RE0038) первым блоком §1.

### Карта

- `screen-map.mjs` кладёт у узла в `map-data.js` адрес паспорта; нет файла — заметка, не дефект.
- `map-view.js` (режим `mind`): в карточке — кебаб `more-dots` (IconButton + ContextMenu `data-menu`), пункты «Открыть страницу» и «Паспорт страницы» (иконка `passport`); подписи пунктов передаёт страница карты (`apps/screen-map/{postrade,ib}/index.html`). Остальная карточка кликается по-прежнему. Дерево в шторке панели не меняется.

### Документы

Указатели: `apps/local-components/README.md` (раздел «Паспорта страниц»), `apps/screen-map/README.md`, `process.md` §2 (строки о витрине и карте).

## Вне задачи

- Паспорта страниц концептов: на карте только модули.
- Содержание паспортов: это спеки страниц и раздел «Бизнес-смысл» (RE0038).
- Страница «Все страницы» в меню витрины.
- Паспорт главной Core — пока нет карты Core.

## Критерии приёмки

- Для каждой страницы модулей Post и IB на карте есть кебаб с пунктами «Открыть страницу» и «Паспорт страницы»; «Паспорт страницы» открывает страницу паспорта в витрине.
- Страница паспорта показывает шапку спеки (файл, адрес, пара во фронтенде, источник, версия), ссылки на компоненты ДС и виджеты витрины и все разделы спеки по порядку.
- Правка спеки без пересборки даёт красный шаг `kit` гейта; пересборка исправляет.
- Паспорт удалённой страницы удаляется пересборкой; без пересборки гейт показывает лишнюю страницу.
- Остальные клики по плитке карты работают как прежде; дерево в шторке панели не изменилось.
- `node .agents/tools/kit-build.mjs --selftest`, `screen-map.mjs --selftest` — OK; `screen-map.mjs --check` — `ВЕРДИКТ: OK`.
- `node .agents/tools/lessons-cli.mjs gate` — `ВЕРДИКТ: OK`.

## Риски

- Рантайм панели `map-view.js` общий для страницы карты и шторки: правка меню не должна менять дерево.
- Страниц модулей будет больше — паспортов столько же; генерат лежит в git, как и остальные страницы витрины.
- Лёгкий разбор спек: у части спек нестандартные заголовки («1. Назначение» без скобок) — генератор не должен на них падать.
