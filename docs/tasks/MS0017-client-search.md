# Поиск клиентов — с каким клиентом работать (MS0017)

## Коротко

Цель – дать пользователям инструмент поиска с каким клиентом работать.

Сделать макет страницы с таблицей по всем клиентам (~100.000) с фильтрацией и сортировкой.
Используем клиентские атрибуты с Клиенты + данные с ПКАП + приоритет от движка.

## Как сейчас (описание пользователя, 26.10.2026)

Сейчас пользователь может только поискать по различным айдишникам клиента для добавления в сделку, когда он уже знает с кем работать.

Процесс поиска с кем работать сейчас внесистемный. Пользователь приходит в платформу только постфактум оформить лид/встречу/сделку с клиентом, которого он нашел через интернет, через заказ различных выгрузок и т.д.

## Решение (исходное описание)

Если взять всех клиентов ККСБ, отсечь черную зону проблемности, отсечь тех, у кого нет выручки ФОК или ФНС, отсечь выручку менее 1 млрд, то получаем всего единицы тысяч клиентов. Добавляем фильтр на отрасль и регион – сотни. С этим уже можно работать как с таблицей.

Варим витрину по всем клиентам ЕПК, добавляем аналитические атрибуты:

- которые уже собрали в рамках карточки клиента;
- дополнительные, которые указали пользователи как важные для поиска клиентов (провели серию встреч);
- опционально считаем некий синтетический «приоритет» - интегральную оценку перспективности клиента.

Грузим в кэш, позываем на табличке где-то в районе Моих клиентов.

По дефолту показываем только «приоритетных», но фильтрами можно посмотреть всех.

Делаем кнопку «Взять клиента в работу»
