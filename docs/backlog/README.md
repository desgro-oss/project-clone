# Бэклог

Место, куда скидывают то, что делать не сейчас: идею, задачу, замечание по проекту.
Не задача: ни этапов, ни критериев приёмки, ни затрат. Созрело — заводится задача
в [docs/tasks/](../tasks/README.md), а запись отсюда получает `status: promoted` и
ссылку на неё.

## Как добавить

1. Создай `<ID>-<slug>.md`.
   - `ID` — префикс автора и следующий номер **своих** записей бэклога: `RE-001`, `MS-001`.
     Префикс — автор, как у задач (RE — Roes, MS — mikhail). Дефис в ID отличает
     запись бэклога от задачи (`RE0042`): номера не пересекаются.
   - `slug` — латиницей через дефис: `concept-archive`.
2. Шапка — три поля: `title`, `author`, `created`. Остальное — как удобно:
   - одно слово или одна строка — нормально, пиши только `title`;
   - есть что сказать — под шапкой свободный текст: зачем, что известно, ссылки.
3. Пустых разделов и шаблонов нет: формы не требуем, чтобы запись не откладывали.

Минимальная запись:

```md
---
title: 'Архив концептов'
author: RE
created: 2026-10-28
---
```

## Статус

Поле `status` необязательно. Нет поля — запись лежит в бэклоге. Бывает
`promoted` — превращена в задачу (в тексте ссылка) — и `dropped` — отказались
(в тексте почему). Удалять записи не нужно: бэклог — ещё и память о том, что
обсуждали.
